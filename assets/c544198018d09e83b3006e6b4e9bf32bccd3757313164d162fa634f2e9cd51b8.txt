# oh_clockor

`oh_clockor` combines `N` one-bit clock inputs into output `clkout`. Parameters are `N = 2`, `SYN = "TRUE"`, and `TYPE = "DEFAULT"`.

When `SYN` is `"TRUE"`, `clkout` is the combinational reduction OR of `clkin[N-1:0]`. For any other `SYN` value, the module instantiates `asic_clockor` with parameters `TYPE` and `N` and connects the same input vector and output. The latter configuration therefore requires that submodule to be supplied. The module has no reset or internal sequential state.
