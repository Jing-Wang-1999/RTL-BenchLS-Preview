### Module Specification

This module is a conditional pipeline register that propagates write-stage control and data signals from a processor's execution stage to the writeback stage, with synchronous reset and debug enable features. It operates on the negative edge of the clock.

**Inputs:**
-   `clk`: System clock.
-   `reset`: Synchronous reset signal (active high).
-   `resetDebug`: An alternate synchronous debug reset signal (active high).
-   `enableDebug`: Enables the latching of inputs to outputs (active high). When low, outputs hold their previous state.
-   `regWrite_in`: A control signal indicating whether the destination register should be written.
-   `memToReg_in`: A control signal selecting the source of the data to write back (ALU result or memory data).
-   `eop_in`: End-of-program flag.
-   `writeReg_in` (5-bit): The address of the destination register.
-   `aluOut_in` (32-bit): The computed result from the ALU.
-   `readData_in` (32-bit): Data read from the memory unit.

**Outputs:**
-   `regWrite_out`: Latched version of `regWrite_in`.
-   `memToReg_out`: Latched version of `memToReg_in`.
-   `eop_out`: Latched version of `eop_in`.
-   `writeReg_out` (5-bit): Latched version of `writeReg_in`.
-   `aluOut_out` (32-bit): Latched version of `aluOut_in`.
-   `readData_out` (32-bit): Latched version of `readData_in`.

**Functional Behavior:**
All outputs are initialized to zero on power-up. On every negative clock edge:
1.  If either `reset` or `resetDebug` is asserted, all outputs are cleared to zero.
2.  Otherwise, if `enableDebug` is asserted, all output registers are updated with their corresponding input values, thereby passing the pipeline stage data forward.
3.  If `enableDebug` is not asserted, all outputs retain their current value (i.e., the register holds its state).

**Allowed Sub-modules:**
The design is a simple register and requires no sub-modules.
