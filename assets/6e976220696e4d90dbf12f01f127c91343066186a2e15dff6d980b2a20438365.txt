# Specification

`mg_08290` has parameters `data_width=32`, `pipe_steps=0`, and `keep_register_names="YES"`; input `CLK`, input `data[data_width-1:0]`, and output `piped_data[data_width-1:0]`. If pipe_steps is zero or negative, piped_data combinationally equals data. If pipe_steps>0, a chain of that many unreset registers shifts data on each rising CLK edge, and piped_data is the last stage, giving an exact pipe_steps-cycle delay after initialization. Register contents before sufficient clock edges are unspecified. keep_register_names supplies the synthesis KEEP attribute.
