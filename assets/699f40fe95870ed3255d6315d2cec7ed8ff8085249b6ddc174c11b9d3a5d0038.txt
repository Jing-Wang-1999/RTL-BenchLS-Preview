# `origen_150263` registered MPI command decoder

Implement `origen_150263` with parameters `NODE_ADDR=0`, `AWIDTH=16`, and `IWIDTH=9`. Inputs are `i_clk`, active-high asynchronous reset `i_reset`, `i_pe_writedata[IWIDTH-1:0]`, and `i_pe_address[AWIDTH-1:0]`. Outputs are eleven one-bit registers: `o_mpi_init_rank`, `o_mpi_init_comm_size`, `o_mpi_finalize`, `o_mpi_send`, `o_mpi_recv`, `o_mpi_comm_size`, `o_mpi_rank`, `o_mpi_status`, `o_mpi_bad_msg`, `o_mpi_bcast`, and `o_mpi_reduce`.

On reset, clear every output. On each rising edge of `i_clk`, replace every output with its current decode condition: init-rank is address `16'h0004` and data `9'h000`; init-comm-size is address `16'h0008` and data `9'h000`; finalize, send, and receive are data `9'h005`, `9'h003`, and `9'h004`; comm-size, rank, and status are addresses `16'h000c`, `16'h0010`, and `16'h0014`; bad-message is data greater than `9'h101`; broadcast is data equal to `9'h100`; reduce is data equal to `9'h101`. Address comparisons use the stated 16-bit constants and data comparisons use the stated values, irrespective of parameter overrides and with normal Verilog sizing/truncation rules. `NODE_ADDR` is unused.

There is no write-enable input: inputs are decoded on every clock edge. Each output therefore reflects the condition sampled at the most recent rising edge and stays high across consecutive matching samples; it is a one-cycle pulse only when its condition is true for one sampled cycle.
