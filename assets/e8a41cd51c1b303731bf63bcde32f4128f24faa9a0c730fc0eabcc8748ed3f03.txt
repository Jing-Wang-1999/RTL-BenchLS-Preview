**Module Specification: Time-Based Alarm Tone Generator**

**Overview**  
This module generates alarm tones based on specific time conditions. It uses clock division to create two audio-frequency signals and activates an alarm output when the input time matches predefined trigger points.

**Inputs**  
- `clk`: System clock input.  
- `rst_n`: Active-low reset signal.  
- `minute1` (4-bit): Tens digit of minutes (0–5).  
- `minute0` (4-bit): Units digit of minutes (0–9).  
- `second1` (4-bit): Tens digit of seconds (0–5).  
- `second0` (4-bit): Units digit of seconds (0–9).

**Outputs**  
- `alarm_radio`: Alarm output signal; pulses at either 500 Hz or 1 kHz depending on the triggered time condition.

**Internal Clock Division**  
The module contains two independent counters that divide the system clock to produce:  
- A 500 Hz square wave (`F500HZ`).  
- A 1 kHz square wave (`F1KHZ`).  
Each counter resets after reaching a predefined maximum value derived from the system clock period. The divided frequencies are generated by toggling their respective signals at the appropriate intervals.

**Alarm Trigger Conditions**  
The alarm output is activated only when the input time matches one of the following patterns:  

1. **Time 59:56 or 59:58** – Activates the 500 Hz tone.  
   (Minutes = 5 and 9, seconds tens = 5, seconds units = 6 or 8.)  

2. **Time 00:00** – Activates the 1 kHz tone.  
   (Minutes = 0 and 0, seconds tens = 0, seconds units = 0.)  

For all other times, the alarm output remains low.

**Reset Behavior**  
On active-low reset, all internal counters and the alarm output are cleared to zero.

**Allowed Sub-modules**  
None
