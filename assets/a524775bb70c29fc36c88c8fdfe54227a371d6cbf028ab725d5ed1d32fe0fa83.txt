# mg_00802

This FSM has one-bit inputs `x`, `y`, and `Clk`, and registered output/state `state[1:0]`. It has no reset port. A simulation initial assignment sets state to `00`; thereafter state updates on rising clock edges.

For input `{x,y}=00`, next states for current 00,01,10,11 are 00,10,00,10. For input 01 they are 00,11,00,11. For input 10 they are 01,10,10,00. For input 11 they are 01,11,11,00. The current state is directly observable. There are no parameters or submodules.
