# Implement the FTDI245 FIFO controller project
Read the complete original manual in specification/project.md and implement the eleven required design modules with ftdi_245fifo_top as the integration top. Declaration-only interfaces retain the source parameters and port widths. The public README is the original paired specification; the clarifications below describe this benchmark configuration.

- This frozen case selects FTx232H (one-byte chip interface), with the README AXI-stream send/receive interfaces. The source parameter declarations retain FT600/FT601 options, but those options are outside the qualified case: expanded unchanged-reference probes reported byte-order failures and are preserved separately. Stream words and FTDI words are little-endian; tkeep selects valid bytes, and tlast flushes a partial send word rather than transporting a packet boundary to the host.
- tx_clk, rx_clk and ftdi_clk are independent. Use asynchronous FIFO crossings and local synchronized reset release. rstn_async is active-low; this case REQUIRES an initial asserted reset spanning multiple edges of all clocks. Behavior when power-up reset is omitted is outside this case, even though the original manual permits tying reset high.
- The FTDI bus is half-duplex. rxf_n low means read data available; txe_n low means write space available. Assert oe_n low before reading; rd_n low accepts incoming words on FTDI rising edges. During writes, drive data/byte enables and assert wr_n low; release the bidirectional bus while reading/idle as required by the selected chip interface. Avoid simultaneous read/write drive. Scheduling may insert legal idle cycles and must eventually make progress in both directions.
- Preserve stream order under backpressure and support packing/removing arbitrary tkeep holes, FIFO buffering and width resizing described in the manual. rx_tlast follows the manual's chunk/timeout behavior and is not a host packet delimiter. The scored upstream loopback bench, augmented with a public receive-stream byte-order monitor, checks end-to-end byte order under randomized FTDI availability with USER_EW=0 and USER_EW=2 (equal and differing stream/chip widths). It is one whole bench point with two parameter configurations, not several independent cases.
- Submodules: resetn_sync provides asynchronous assertion and local synchronized release; fifo_async crosses a ready/valid data queue; fifo2/fifo4 are small synchronous elastic queues; fifo_delay_submit buffers a stream with delayed submission; axi_stream_packing removes invalid-byte holes and flushes on last; axi_stream_upsizing/downsizing/resizing convert stream widths with keep/last; ftdi_245fifo_fsm schedules the external bidirectional interface. Implement the complete closure, including the branches selected by the declared defaults.
- SIMULATION=0 is the generated-design contract. The upstream assertion helper is private test support; do not implement it as benchmark RTL. Reference-only initial assignments duplicating explicit reset values are removed for this reset-required case; all original RTL is retained privately and the exact changes are recorded. No logic equations or reset assignments are changed.

Implement every required path in output_contract.json. Declaration-only ports
are in interfaces/modules.v. No initial/final, delays, simulation system tasks,
force/release or external includes are permitted. Only declared RTL is collected.
Missing files, forbidden constructs or failed top compilation score zero. Each
private point has equal weight and requires all of its checks to pass. Use
terminal/file_editor, iverilog, vvp and Python iteratively; finish by saving RTL.
Run `python3 checks/check.py` for public compilation feedback.
