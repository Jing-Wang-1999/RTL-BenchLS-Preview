The synchronizer module is designed to safely transfer data between two clock domains. It uses a parameterized width and number of stages to manage data synchronization. The module has two clock inputs, `clk_in` and `clk_out`, and two asynchronous reset inputs, `arst_in` and `arst_out`. The data input, `dat_in`, is a vector with a width defined by the `WIDTH` parameter. The output, `dat_out`, is also a vector of the same width.

The module consists of a launch register and multiple capture registers. The launch register captures the input data on the rising edge of `clk_in` or when `arst_in` is asserted, resetting the register to zero. The capture registers are organized in a shift register configuration, with the number of stages defined by the `STAGES` parameter, which must be at least 2. These registers capture and shift the data on the rising edge of `clk_out` or when `arst_out` is asserted, resetting the registers to zero.
