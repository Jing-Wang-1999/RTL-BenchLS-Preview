This module implements a state machine with a 10-bit counter. It operates on a clock and active-low reset.

**Inputs:**
- Clock signal.
- Active-low reset (asserted low to reset).
- Start signal to initiate operation.
- Valid signal to enable counting.
- Done signal to indicate completion.

**Outputs:**
- Valid_out: asserted when in the final state and the valid input is high.
- A 10-bit counter value.

**Behavior:**
The system has four states: idle (S0), a transient state (S1), counting (S2), and completion (S3). On reset, it enters the idle state with the counter set to all ones.

From idle, a high start signal moves to the counting state. In counting, the counter increments by one on each clock cycle only when the valid input is high. Counting continues until the counter reaches the specific decimal value 262 (binary 0100000110). Upon reaching this value, it transitions to the completion state.

In the completion state, it waits for the Done input to be high before returning to idle. The valid_out output is high only when the system is in the completion state and the valid input is simultaneously high.

The counter is cleared to zero in the idle and transient states. In the counting and completion states, it holds its value unless the valid input is high, in which case it increments.

**Allowed Sub-modules:**
None; the design is a standalone state machine with integrated counter logic.
