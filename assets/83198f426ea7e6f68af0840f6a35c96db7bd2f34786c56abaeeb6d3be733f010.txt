The module "Summodule" is a digital logic circuit designed to process and combine several 4-bit inputs and a single binary input to produce a 4-bit output and a single binary output. 

### Inputs:
1. **E**: A 4-bit input vector.
2. **D**: A 4-bit input vector.
3. **C**: A 4-bit input vector.
4. **M**: A single binary input.

### Outputs:
1. **F**: A 4-bit output vector.
2. **AEB**: A single binary output.

### Internal Operations:
- **EXD Calculation**: Each bit of the 4-bit vector EXD is calculated by performing a bitwise XOR operation between the corresponding bits of inputs E and D. This results in a new 4-bit vector EXD.
  
- **CM Calculation**: Each bit of the 4-bit vector CM is calculated by performing a bitwise OR operation between the corresponding bits of input C and the binary input M. This results in a new 4-bit vector CM.

- **F Calculation**: Each bit of the 4-bit output vector F is determined by performing a bitwise XOR operation between the corresponding bits of the vectors EXD and CM. This results in the final 4-bit output vector F.

- **AEB Calculation**: The binary output AEB is determined by performing a logical AND operation across all bits of the output vector
