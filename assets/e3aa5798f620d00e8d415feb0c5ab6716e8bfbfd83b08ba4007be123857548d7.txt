# Implement the Programmable Interval Timer project

Read specification/project.txt and the unchanged original PIT specification PDF.
Implement the five-file Verilog project headed by pit_top at the paths and
declaration-only interfaces in output_contract.json and interfaces/modules.v.
The separate SystemVerilog implementation is not part of this case.

Curator clarifications from the pinned RTL and original manual:
- The main counter is 16 bits and the prescaler 15 bits. This case retains the
  upstream bench's four interacting PIT instances: master/slave, synchronous and
  asynchronous resets, 16/8-bit Wishbone buses, and default one-wait-state accesses.
  Preserve the declared parameters; arbitrary reduced counter widths are outside
  qualification, as the manual itself says COUNT_SIZE support is incomplete.
- The actual interrupt port is pit_irq_o; the PDF calls it pit_int_o. wb_rst_i is
  synchronous active high; arst_i has the ARST_LVL polarity (default active low).
  Allow two clocks for synchronous reset propagation. COUNT resets/holds at 1.
- For DWIDTH=16, Wishbone word addresses 0,1,2 are control, modulo, count. For
  DWIDTH=8, byte addresses 0/1,2/3,4/5 select their low/high bytes. wb_sel_i is
  unused in this revision and may be tied high. Out-of-map read data is zero.
  COUNT is read-only despite the PDF's RW label. Modulo and writable control
  fields reset to zero; control also reads the immutable capability bits, so
  the default full control reset readback is 0x4000, not the PDF's generic 0000h.
- Control [15] selects slave mode, [14] reads DECADE_CNTR, [13] NO_PRESCALE,
  [11:8] selects prescale, [2] reads the sticky rollover flag and writes one to
  clear it, [1] enables interrupt, [0] controls counting and cnt_sync_o.
  Reserved bits read zero. NO_PRESCALE forces prescale readback zero.
- Master counting is enabled by control bit 0; slave counting follows ext_sync_i.
  Disabling counting restores counter state and clears the rollover flag.
  Main count advances on prescale ticks and wraps from modulo to 1; modulo 0/1
  means divide by one. pit_o pulses for rollover while enabled. The sticky flag
  persists until explicit clear or disable; pit_irq_o registers flag AND enable.
  Clearing the flag has priority over coincident rollover. A valid control write
  replaces all its writable bits, so software preserves the enable bits on clear.
- The prescale divisors follow manual table 3: binary 1,2,4,...,32768; decade
  1,2,4,8,10,100,1000,10000,20000 (codes 8..15 saturate at 20000).
  NO_PRESCALE bypasses this stage. The optional SINGLE_CYCLE mode acknowledges
  combinationally; default accesses latch the address and alternate acknowledge
  with the wait state. Reads use a combinational mux of the selected register;
  the PDF's blanket statement that all outputs are registered is too broad.
- pit_wb_bus translates bus transfers into control/modulo write strobes and a
  register read mux; pit_regs holds the programmable fields and interrupt;
  pit_prescale implements enable/slave synchronization and programmable division;
  pit_count implements main modulo counting, flag and pulse outputs. pit_top
  connects this entire hierarchy. Internal signal/state names are unrestricted.

Scoring uses the complete original Verilog system bench as one Boolean testpoint,
including its four parameterized instances; individual register checks are not
separate cases or points. The alternative SV bench targets a separate SV source
implementation and requires unsupported interface syntax in the retained toolchain.
