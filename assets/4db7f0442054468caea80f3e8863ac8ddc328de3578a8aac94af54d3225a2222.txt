# Hardware Specification: AutoVCoder 101203

## Overview
The AutoVCoder 101203 is a combinational lookup table module that performs a fixed substitution mapping operation. It accepts a 6-bit address input and produces a 4-bit output value based on predefined substitution tables.

## Functional Description
The module implements a two-level addressing scheme to access four separate 16-entry lookup tables. The 6-bit input address is decomposed into two components:

- **Row Selection**: Determined by bits 5 and 0 of the input address, creating a 2-bit row index that selects one of four lookup tables (rows 0-3).
- **Column Selection**: Determined by bits 4 through 1 of the input address, creating a 4-bit column index that selects one of 16 entries within the chosen table (columns 0-15).

## Input/Output Specification

**Input:**
- `address` (6 bits): The lookup address that selects both the table row and the entry within that table.

**Output:**
- `sout` (4 bits): The substitution value retrieved from the selected lookup table entry. Output values range from 0 to 15.

## Lookup Table Behavior
Each of the four rows contains a complete permutation of values 0 through 15. The module performs a substitution operation by mapping the column index to its corresponding value in the selected row:

- **Row 0**: Maps column indices 0-15 to values {2, 12, 4, 1, 7, 10, 11, 6, 8, 5, 3, 15, 13, 0, 14, 9}
- **Row 1**: Maps column indices 0-15 to values {14, 11, 2, 12, 4, 7, 13, 1, 5, 0, 15, 10, 3, 9, 8, 6}
- **Row 2**: Maps column indices 0-15 to values {4, 2, 1, 11, 10, 13, 7, 8, 15, 9, 12, 5, 6, 3, 0, 14}
- **Row 3**: Maps column indices 0-15 to values {11, 8, 12, 7, 1, 14, 2, 13, 6, 15, 0, 9, 10, 4, 5, 3}

## Operational Characteristics
- **Combinational Logic**: The output responds immediately to address changes with no clock or sequential behavior.
- **Substitution Cipher**: The module functions as a substitution box (S-box), commonly used in cryptographic algorithms for non-linear transformations.
- **Permutation Property**: Each lookup table is a complete permutation, ensuring every output value 0-15 appears exactly once per row.

## Sub-modules
This module contains no sub-modules. It is implemented entirely using combinational logic with nested case statements for table lookup.
