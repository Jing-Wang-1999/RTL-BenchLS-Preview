# gf_mult_by_5e

This combinational block has input `i[7:0]` and output `o[7:0]`. Output bits 0 through 7 XOR input-index sets `{2,4,5}`, `{0,3,5,6}`, `{0,1,2,5,6,7}`, `{0,1,3,4,5,6,7}`, `{0,1,6,7}`, `{1,2,7}`, `{0,2,3}`, and `{1,3,4}` respectively. There is no parameter, clock, reset, state, latency, or submodule.
