This module converts an 8-bit Gray code input to its binary equivalent. It has one input, 'gray', and one output, 'bin', both 8 bits wide. The most significant bit of the binary output is directly assigned from the Gray code input. For the remaining bits, each binary bit is computed by XORing the next higher binary bit with the corresponding Gray code bit. The module uses a generate block to iterate through the bits, ensuring efficient conversion. No sub-modules are required. The module is parameterized by 'WIDTH', allowing for flexibility
