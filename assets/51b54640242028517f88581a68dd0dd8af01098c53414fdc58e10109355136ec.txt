# gf_mult_by_7c

Input `i[7:0]` and output `o[7:0]` are unsigned bit vectors. This is a fixed combinational GF(2) linear transform with no parameters, clock, reset, state, latency, or submodule. For each output bit k from 0 through 7, XOR the following input-bit indices: o[0]={2,3,4,5}, o[1]={3,4,5,6}, o[2]={0,2,3,6,7}, o[3]={0,1,2,5,7}, o[4]={0,1,4,5,6}, o[5]={0,1,2,5,6,7}, o[6]={0,1,2,3,6,7}, o[7]={1,2,3,4,7}. Here braces denote XOR reduction, not concatenation.
