# twenty_to_eight

Parameter `WORD_LEN=66`. Inputs are `clk`, active-high asynchronous `arst`, `din[20*WORD_LEN-1:0]`, `din_valid`, and `dout_ready`; outputs are `din_ready`, registered `dout[8*WORD_LEN-1:0]`, and registered `dout_valid`. A one-hot five-state rotor represents surplus sizes 0,12,4,16,8. States 0 and 2 require input valid and assert din_ready unless output is stalled; all states wait while valid output lacks ready. On each unblocked transaction the state rotates and emits the low eight words: state0 emits din words0..7 and saves 8..19; state1 emits saved words8..15 leaving 16..19; state2 emits saved 16..19 followed by new din0..3 and saves din4..19; state3 emits saved4..11 leaving12..19; state4 emits saved12..19. dout_valid holds with data while stalled and clears on a consumed output unless replaced same edge. Reset selects state0, clears dout/valid, and leaves surplus unspecified.
