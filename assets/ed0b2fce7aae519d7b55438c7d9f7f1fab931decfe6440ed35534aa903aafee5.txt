The `gearbox_20_67` module is a digital hardware component designed to convert a stream of 20-bit input words into a stream of 67-bit output words. This module is particularly useful in applications where data needs to be restructured or reformatted from one bit-width to another, such as in communication systems or data processing pipelines.

### Inputs:

1. **clk**: This is the clock signal input. The module operates synchronously with the rising edge of this clock signal.
   
2. **arst**: This is an asynchronous reset input. When asserted, it resets the internal state of the module, initializing all registers and control signals to their default states.

3. **din**: This is a 20-bit wide data input. The module continuously accepts new 20-bit data words from this input.

4. **slip_to_frame**: This is a control signal input. When set to 1, it instructs the module to adjust the data processing to ensure that the output words are properly framed. This is useful in scenarios where data alignment is critical.

### Outputs:

2. **dout_valid**: This is a validity signal for the `dout` output. It indicates when the data on `dout` is valid and ready for use by downstream components.

- On each clock cycle, the module accepts a new 20-bit word from `din` and appends it to the internal buffer.

- The module checks if there are enough bits in the buffer to form a complete 67-bit word. If so, it extracts the necessary bits according to the current schedule and updates the output `dout`.
