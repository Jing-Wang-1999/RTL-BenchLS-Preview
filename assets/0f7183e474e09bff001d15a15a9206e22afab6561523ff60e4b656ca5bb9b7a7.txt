# FPGA programmable-I/O project
Implement the complete9-module PIO project described by the original README, with pio as its integration top. This is the pinned incomplete FPGA recreation, using its documented custom host-control interface; full Raspberry Pi RP2040 peripheral/register compatibility is not claimed. Keep NUM_MACHINES=4, matching its fixed four-machine status/mindex ports. The current examples exercise machine0.

Curator interface and scope clarification from pinned RTL:
- Rising clk and synchronous active-high reset. Load program/configuration before enable. Shared instruction RAM has32 words of16 bits; action1 writes din[15:0] at index. Each machine has X/Y scratch registers, ISR/OSR, independent TX/RX FIFO and program counter.
- Host action0 reports version0x01000000 in dout;2 writes execution configuration for mindex,3 pops its RX FIFO to dout,4 pushes din to TX FIFO,5 configures GPIO groups,6 writes enable/restart/divider-restart masks,7 writes16.8 fixed-point divider,9 executes din[15:0] immediately even while disabled,10 sets shifts/autopush/autopull. Action8 is reserved/unimplemented. Hold din through the following control cycle for PUSH/immediate data, whose strobes are registered.
- Action2 fields: status threshold[3:0], status source[4], wrap target[11:7], program end[16:12], sticky output[17], inline output enable[18], output-enable source[23:19], JMP pin[28:24], side-set direction[29], optional side-set flag[30], execution stall[31]. Some stored compatibility fields are not functionally implemented; do not claim untested full RP2040 behavior.
- Action5 fields: OUT base[4:0], SET base[9:5], side-set base[14:10], IN base[19:15], OUT count[25:20], SET count[28:26], side-set count[31:29]. Action6 uses enable[3:0], restart[7:4], divider-restart[11:8]. Action7 stores24-bit divider and enables division only for values>=0x200; action10 stores autopush16,autopull17,input direction18,output direction19, ISR threshold[24:20],OSR threshold[29:25]. Initialize required groups before running.
- Instruction opcode[15:13]:0 JMP,1 WAIT,2 IN,3 OUT,4 PUSH/PULL,5 MOV,6 IRQ,7 SET. Operand1[7:5] and operand2[4:0] select condition/source/destination/immediate or bit count; instruction[12:8] is shared by delay and side-set fields. Zero shift count denotes32. JMP supports unconditional, X/Y zero and decrement conditions, X!=Y, selected GPIO and OSR-not-empty. SET selects pins/X/Y/pin directions; MOV selects pins/X/Y/null/status/ISR/OSR with identity/invert/bit reversal. IN/OUT shift configured directions and FIFO thresholds; PULL block waits for TX data, noblock substitutes X; PUSH block waits for space. Side-set and delay execute with the instruction, including documented stalled side-set behavior.
- The selected documented programs require exact cycle timing: fractional divider2.5 alternates2/3 host-clock phases, delay1 doubles each SET duration, UART uses8N1 frames, stepper emits packed nibbles, I2S sends16-bit left/right channels and WS2812 distinguishes0/1 pulse widths. Original assembly/program files are supplied as specification examples; implement programmable behavior, not a fixed waveform generator.
- GPIO updates are registered; when machines change the same output on one edge, the highest machine index wins. Reset clears enable/configuration/output state; instruction RAM must be loaded by host. IRQ0/IRQ1, unrestricted multi-machine interactions, and unsupported host compatibility fields are outside the qualified envelope; upstream leaves the two IRQ top outputs undriven.
- Ten usable original program benches form ten points. The original SPI receive bench fails unchanged reference and is retained as an explicit excluded exception in testbench_inventory.json; it is not a required passing behavior. The copybit bench observes the first9 of10 queued words because the last lies beyond its original finish time. This is a documented observation limit, not another testpoint.

Simulation I/O, delays, force/release, final blocks and external includes are forbidden. Constant elaboration functions ($clog2, $unsigned, $signed, $bits) and synthesizable storage initialization are permitted. Save all RTL under the exact required paths; only those files are collected.

Compile this original Verilog project as Verilog2005 (-g2005); its source uses null as an ordinary identifier, which is reserved in SystemVerilog.
