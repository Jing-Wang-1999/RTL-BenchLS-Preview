# `origen_107840` three-state controller

The interface comprises inputs `clk`, active-high asynchronous `reset`, and `ok`, plus combinational outputs `keep` and `shot`. On `reset`, the state immediately becomes S0. Otherwise state changes on each rising edge of `clk`.

From S0, `ok=1` selects S1 and `ok=0` holds S0. From S1, `ok=1` selects S2 and `ok=0` holds S1. S2 is terminal. Outputs are `(keep,shot)=00` in S0, `10` in S1, and `11` in S2. An invalid encoded state selects S0 as the next state and drives both outputs low.
