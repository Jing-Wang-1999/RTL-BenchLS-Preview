This specification describes four modules that function as data registers with synchronous behavior. Each module is designed to capture and hold data on the rising edge of a clock signal. They are initialized to zero at the start.

1. **Module: origen_071564**
   - **Inputs:**
     - `clk`: A clock signal that triggers data capture.
     - `data_in`: A 64-bit wide input data bus.
   - **Outputs:**
     - `data_out`: A 64-bit wide output data bus.
   - **Behavior:** On each rising edge of the `clk`, the module captures the `data_in` and updates `data_out` with this value. Initially, `data_out` is set to zero.

2. **Module: id_ex**
   - **Inputs:**
     - `clk`: A clock signal for synchronization.
     - `data_in`: A 178-bit wide input data bus.
   - **Outputs:**
     - `data_out`: A 178-bit wide output data bus.
   - **Behavior:** The module updates `data_out` with the value of `data_in` on the rising edge of the `clk`. Initially, `data_out` is set to zero.
