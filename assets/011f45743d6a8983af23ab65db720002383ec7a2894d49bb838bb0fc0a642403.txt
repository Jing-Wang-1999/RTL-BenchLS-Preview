# Rv32i execution alu

Module interface:

module rv32i_execution_alu
(
  input clk,
  input reset_n,
  input stall,
  input [31:0] a_decode,
  input [31:0] b_decode,
  input [31:0] offset_decode,
  input [4:0] a_rs_idx,
  input [4:0] b_rs_idx,
  input [4:0] regfile_rd_idx,
  input [31:0] regfile_rd_val,
  input [31:0] pc_in,
  input [4:0] rd_in,
  input branch_in,
  input jump_in,
  input system_in,
  input load_in,
  input store_in,
  input [2:0] ld_store_width,
  input cancelled,
  input add_nsub,
  input arith,
  input cmp_unsigned,
  input cmp_is_lt, cmp_is_ge, cmp_is_eq, cmp_is_ne,
  input bit_is_and, bit_is_or, bit_is_xor,
  input shift_arith, shift_left, shift_right,
  input extm_update_rd,
  input [4:0] extm_rd_idx,
  input [31:0] extm_rd_val,
  input clr_load_op,
  output reg [4:0] rd,
  output reg update_pc, load, store,
  output reg [31:0] pc, c, addr,
  output reg [3:0] st_be,
  input [31:0] ld_data,
  output reg retired_instr,
  output misaligned_load, misaligned_store,
  output [31:0] misaligned_addr
);

## Exact cycle and priority contract

All register updates occur on posedge clk; reset_n is synchronous active-low.
Reset clears rd, load, store, update_pc, ld_width and retired_instr only. Other
registers retain their previous/uninitialized values. Outside reset,
retired_instr becomes NOT stall AND NOT cancelled. Cancellation affects only
this output; stall does not globally gate all updates.

Forward each source operand from regfile_rd_val when its source index equals
nonzero regfile_rd_idx; otherwise use the decoded operand. add_nsub selects
addition when high, subtraction when low. Comparison predicates are OR-combined
when several enables are asserted, with signed comparison unless cmp_unsigned.
Enabled bitwise operations are OR-combined, as are enabled left/right shifts.
Right shifts use sign fill iff shift_arith; shift count is b[4:0].

The result c update priority is: extension writeback, an already pending load,
arithmetic, any bitwise enable, any comparison enable, any shift enable, jump
link (pc_in+4), store data, otherwise hold. This applies even while stalled.
Load data uses the saved address low bits and saved ld_width: right-shift ld_data
by eight times addr_lo. If width bit 1 is set, take the full shifted word;
otherwise bit 0 selects halfword versus byte. Extend with zeros when bit 2 is
set, otherwise sign-extend. Codes 0/1 are signed byte/half, 4/5 unsigned byte/half;
codes with bit 1 set select words. The width is latched whenever not stalled.

The effective address is a+offset_decode; misaligned_addr exposes it continuously.
Misalignment occurs for a requested load or store when width bit 0 and address
bit 0 are both one, or width bit 1 and either address low bit is one, provided
there is no already pending load. Each misaligned output also requires its own
load_in/store_in. If a load/store is requested and not stalled, save the aligned
word address and original low address bits; otherwise retain both.
Byte enables update each nonreset edge: all four if width bit 1, a two-byte pair
selected by effective-address bit 1 if bit 0, otherwise the selected single byte.
Store data shifts b by eight times the effective low address bits masked by
{NOT width bit 1, NOT width bit 0}, truncating to 32 bits.

next_pc is a+b for jump or system, otherwise pc_in+offset_decode. pc updates
unless stalled. branch_taken requires branch_in and comparison result true.
update_pc holds under stall, otherwise becomes (jump OR system OR branch_taken)
AND NOT previous update_pc. rd chooses the extension destination first, holds
under stall second, otherwise chooses rd_in unless previous update_pc is set or
jump/branch_taken has a non-word-aligned next_pc; in those cases rd becomes zero.
load becomes the stalled previous load or the unstalled load_in gated by NOT
previous update_pc, then is suppressed by clr_load_op or misaligned_load.
store becomes store_in AND NOT previous update_pc AND NOT misaligned_store,
independent of stall. All references to register values in these rules mean
values before the edge.
