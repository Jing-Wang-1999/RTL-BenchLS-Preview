# Three-phase space-vector PWM generator

Implement `svpwm`. Inputs: active-low asynchronous `rstn`, rising-edge `clk`, unsigned `v_amp[8:0]`, `v_rho[11:0]`, `v_theta[11:0]`. Outputs: registered scalar `pwm_en`, `pwm_a`, `pwm_b`, `pwm_c`. There are no parameters or input handshakes. Each carrier frame lasts2048 clocks. All fixed-width arithmetic wraps; use truncation, not saturation. The following abstract pipeline defines precise output timing for any changing inputs.

Use an11-bit counter cnt reset0 and increment each edge modulo2048. Registers rom_x(12), multiplier inputs A(9),B(12), multiplier output P(12), phase signs sa/sb/sc, saved magnitudes ya/yb(9), duties da/db/dc(10), lower/upper bounds for each phase(11), and active reset to zero. P updates each edge to bits20:9 of unsigned A*B. All updates below use pre-edge values and otherwise hold.

| Pre-edge cnt | Update |
|---|---|
| 2037 | rom_x=v_theta; A=v_amp; B=v_rho |
| 2038 | rom_x=rom_x-1365 modulo4096 |
| 2039 | rom_x=rom_x-1365; B=P+8 modulo4096 |
| 2042 | A=rom_y; sa=rom_sign |
| 2043 | A=rom_y; sb=rom_sign |
| 2044 | A=rom_y; sc=rom_sign; ya=P[11:3] |
| 2045 | yb=P[11:3] |
| 2046 | da=512+(sa ? -ya : ya); db=512+(sb ? -yb : yb); dc=512+(sc ? -P[11:3] : P[11:3]), each modulo1024 |
| 2047 | lower phase bound=duty; upper phase bound=-duty modulo2048; active=1 |

Outputs reset to pwm_en0, pwm_a/b/c1. Each nonreset edge, pwm_en takes old active; each phase output takes (!active or cnt<=lower or cnt>upper), all pre-edge. Thus the first frame prepares bounds and the following edge enables PWM. Inputs are sampled only at cnt2037.

The waveform ROM is a four-register-stage pipeline, which is clocked even during reset and has no reset guarantees: first x1(12)=rom_x when rom_x<2048 else -rom_x modulo4096. Second, z2=(x1==1024), sign2=(x1>1024), x2(10)=x1[9:0] when x1<=1024 else -x1[9:0] modulo1024. Third, z3=z2, sign3=sign2, y3=ROM[x2]. Fourth, rom_sign=sign3 and rom_y=(z3 ? 0 : y3). Updates are concurrent, always from pre-edge values. Startup unknown ROM registers are harmless to enabled outputs because control waits almost a whole frame before using them. Asserting reset again immediately disables output and restarts that warmup; no assumption that v inputs are constant during reset is needed.

ROM entries below are unsigned9-bit integers in address order0..1023,32 entries per line. These constants, including their quantization, are normative; do not substitute an approximate sine function.
