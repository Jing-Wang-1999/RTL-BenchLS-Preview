# `SDP_X_X_trt_core_staller`

The complete interface is: `input nvdla_core_clk;; input nvdla_core_rstn;; output core_wen;; input chn_trt_in_rsci_wen_comp;; output core_wten;; input chn_trt_out_rsci_wen_comp;`. Combinational behavior is: `assign core_wen = chn_trt_in_rsci_wen_comp & chn_trt_out_rsci_wen_comp;`. The sequential assignments are: `core_wten <= 1'b0;; core_wten <= ~ core_wen;`. The sensitivity list in the implementation gives an active-low asynchronous reset and rising-edge normal updates. Unassigned state holds its prior value. No external submodule is required.
