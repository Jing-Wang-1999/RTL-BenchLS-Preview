# Module Specification: autovcoder_024406

## Overview
This module implements a single-stage synchronous register (flip-flop) that captures and holds a 15-bit data value on each clock cycle.

## Inputs
- **clock**: The clock signal that triggers data capture on its rising edge
- **io_d**: A 15-bit input data bus that provides the value to be registered

## Outputs
- **io_q**: A 15-bit output data bus that presents the registered value from the previous clock cycle

## Behavior
On every rising edge of the clock signal, the module captures the current value present on the io_d input and stores it in an internal 15-bit register (sync_0). This stored value is continuously driven onto the io_q output. This creates a one-cycle delay between the input and output, effectively synchronizing the input data to the clock domain.
