# mg_05792

`mg_05792` is a positive-edge-triggered register with parameter `BITS = 1`. Input `d[BITS-1:0]` is the data input, input `clk` is the clock, and registered output `q[BITS-1:0]` holds the stored value.

On each rising edge of `clk`, `q` captures `d`. Between rising edges it holds its previous value. There is no reset, initialization, enable, or submodule, so the initial value of `q` is unspecified until the first rising clock edge.
