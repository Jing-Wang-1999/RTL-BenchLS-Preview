# Unsigned maximum-index selector (`origen_090636`)

Inputs `mac0` through `mac9` are ten unsigned 8-bit values. Output `calculated_class[7:0]` is combinational and encodes indices zero through nine. There are no parameters, clocks, or resets.

The block starts with temporary maximum zero and class zero, then visits inputs in ascending order. It replaces both only when the current input is strictly greater than the saved maximum. Consequently the result is the lowest index holding the maximum value. If every input is zero, the result remains zero. Unknown four-state comparisons follow Verilog procedural-if semantics.
