This module is a 16-location, 32-bit wide register file with two independent read ports and one write port. It operates on a single clock and an active-low reset.

**Inputs:**
- Clock (clk) and active-low reset (rst_n).
- Write Port: A write enable signal (write_enable), a 4-bit address (write_select), and a 32-bit data value (write_value).
- Read Port A: A read enable signal (read_a_enable) and a 4-bit address (read_a_select).
- Read Port B: A read enable signal (read_b_enable) and a 4-bit address (read_b_select).

**Outputs:**
- Read Port A: A 32-bit output (read_a_value).
- Read Port B: A 32-bit output (read_b_value).

**Behavior:**
On reset, all 16 internal registers are cleared to zero.
A write operation occurs on the rising clock edge when write_enable is high, storing write_value into the register addressed by write_select.

Read operations are combinational (asynchronous). Each read port behaves identically:
- If the read enable signal is high, the output presents the data from the addressed register.
- Register 0 is hardwired to always read as zero, regardless of its stored value.
- If the read enable signal is low, the output is driven to a high-impedance state (all bits 'z').
