# `autovcoder_086108` directional state machine

Inputs are active-high `RESET`, `CLOCK`, and `PUSH_BUTTONS[3:0]`; output `STATE_OUT[1:0]` is the current state. Reset is sampled synchronously on the rising edge of `CLOCK` and has priority over normal state updates. A sampled reset sets the state to right (`2'b00`).

The states are right=`00`, down=`01`, up=`10`, and left=`11`. From right, button 1 has priority and selects down, then button 2 selects up; otherwise the state holds. From down, button 0 has priority and selects right, then button 3 selects left; otherwise it holds. From up, button 0 has priority and selects right, then button 3 selects left; otherwise it holds. From left, button 1 has priority and selects down, then button 2 selects up; otherwise it holds. `STATE_OUT` continuously reflects the registered state.
