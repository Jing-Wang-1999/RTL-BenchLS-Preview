# `mg_06230`

This module has scalar inputs `clk`, active-high asynchronous `rst`, and `clk_ena`, with scalar output `d`. Asserting reset asynchronously clears the internal register and output to zero. On a rising edge of `clk` while reset is low, `clk_ena` high sets the register to one; when `clk_ena` is low it holds its prior value. No operation clears the register except reset. There is no specified initial value before reset or an enabled clock edge.
