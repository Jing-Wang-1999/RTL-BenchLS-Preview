The origen_097574 module is a priority-encoded keyboard controller. It accepts seven input keys (A, S, D, F, G, H, J) and produces three outputs: a 4-bit note identifier, an 8-bit volume level, and a 7-bit key array.

When a key is pressed, the module assigns a unique note identifier and sets the volume to maximum (255). The key array is a binary representation of the pressed key, with each bit corresponding to a specific key.

The module prioritizes key presses in the order A, S, D, F, G, H, J. If multiple keys are pressed simultaneously, the module will only recognize the highest-priority key. If no keys are pressed, the outputs default to zero.
