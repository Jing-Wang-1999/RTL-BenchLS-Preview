The `cntr_modulus` module is a counter with configurable width and modulus value. It operates based on a clock signal and several control inputs. The module has a parameter `WIDTH` that defines the bit-width of the counter, and `MOD_VAL` which specifies the modulus value, determining the counter's maximum count before resetting to zero.

Inputs:
- `clk`: Clock signal for synchronization.
- `ena`: Enable signal to allow counting.
- `rst`: Reset signal to initialize the counter to zero.
- `sload`: Signal to load a specific value into the counter.
- `sdata`: Data input for loading a specific value when `sload` is active.
- `sclear`: Signal to clear the counter to zero.

Output:
- `q`: Current value of the counter, with a width defined by the `WIDTH` parameter.
