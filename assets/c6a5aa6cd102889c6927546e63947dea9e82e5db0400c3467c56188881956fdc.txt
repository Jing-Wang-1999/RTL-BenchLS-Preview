# `origen_028849`

This seven-state FSM has clock `clk`, asynchronous active-low reset `rst`, and registered-state-derived output `light[5:0]`. When `rst` is low, the state immediately becomes S0. Otherwise each rising clock edge advances S0→S1→S2→S3→S4→S5→S6→S0. An illegal state transitions to S0 on the next rising edge.

The combinational output patterns are S0=`111111`, S1=`101010`, S2=`100011`, S3=`100111`, S4=`100101`, S5=`100100`, and S6=`000000`. An illegal or unknown unmatched state uses default output `111111`. Reset establishes S0 and therefore the S0 output pattern.
