**Module Specification: Instruction Decoder**

**Overview**  
This module is a combinational instruction decoder that examines a 6-bit opcode and a 6-bit function code to determine the type of instruction being executed. It asserts exactly one of twelve output signals corresponding to a specific instruction, based on predefined opcode and function code patterns.

**Inputs**  
- `op` (6 bits): The primary opcode field of the instruction.  
- `func` (6 bits): The function code field, used only for R-type instructions (when `op` is `000000`).

**Outputs**  
Twelve single-bit control signals, each active high (1) when the corresponding instruction is identified, otherwise low (0). Only one output may be active at a time. The outputs are:  
- `addu`: Unsigned addition (R-type).  
- `subu`: Unsigned subtraction (R-type).  
- `ori`: Logical OR immediate.  
- `lui`: Load upper immediate.  
- `lw`: Load word.  
- `sw`: Store word.  
- `beq`: Branch if equal.  
- `j`: Unconditional jump.  
- `jal`: Jump and link.  
- `jr`: Jump register (R-type).  
- `blezals`: Branch if less than or equal to zero and link? (custom or extended instruction).  
- `rev`: Reverse operation (custom R-type instruction).

**Behavior**  
The decoder continuously evaluates `op` and `func`. Each output is set to 1 if the input codes match a specific combination, and 0 otherwise. The matching conditions are:  
- `addu`: `op` = `000000` and `func` = `100001`.  
- `subu`: `op` = `000000` and `func` = `100011`.  
- `sw`: `op` = `101011`.  
- `lw`: `op` = `100011`.  
- `ori`: `op` = `001101`.  
- `beq`: `op` = `000100`.  
- `lui`: `op` = `001111`.  
- `j`: `op` = `000010`.  
- `jal`: `op` = `000011`.  
- `jr`: `op` = `000000` and `func` = `001000`.  
- `blezals`: `op` = `011000`.  
- `rev`: `op` = `000000` and `func` = `010100`.  

All outputs are initialized to 0 at startup. The decoding is purely combinational; no internal state or clock is used.

**Allowed Sub-modules**  
None. The module must be implemented as combinational logic only.

**Notes**  
- The `blezals` and `rev` outputs correspond to non-standard or custom instructions, as their opcode/function combinations are not typical
