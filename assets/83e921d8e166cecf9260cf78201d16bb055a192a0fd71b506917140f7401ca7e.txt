The module converts a 3‑bit binary number into an 8‑bit one‑hot encoded output.

**Inputs:**  
- `x_num`: A 3‑bit unsigned binary number ranging from 0 to 7.

**Outputs:**  
- `x_num_expand`: An 8‑bit one‑hot signal where exactly one bit is high. The position of the high bit corresponds to the decimal value of `x_num`. For example, if `x_num` is 3, then bit 3 of `x_num_expand` is set to 1 and all other bits are 0.

**Function:**  
The module performs a simple decoder operation: it compares the input value against each possible integer from 0 to 7 and activates the matching output bit. No internal registers, clocks, or sub‑modules are used; the logic is purely combinational.

**Allowed sub‑modules:** None.
