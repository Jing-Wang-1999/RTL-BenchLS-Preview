**Specification: ALU Operation Decoder**

This module decodes ALU operations based on instruction type and function code. It takes a 2-bit **ALUOp** input (indicating instruction type) and a 6-bit **Funct** input (specifying the operation for R-type instructions). It outputs a 4-bit **ALUOperation** signal selecting the appropriate ALU action.

For **ALUOp = 00**, it defaults to addition (memory/immediate operations). For **ALUOp = 01**, it selects subtraction (branches). For **ALUOp = 10** (R-type instructions), it maps the **Funct** field to the corresponding operation (add, subtract, AND, OR, set-less-than, shifts, or move-from-HI/LO). Undefined inputs produce an invalid output.

Allowed sub-modules: None. This is a combinational decoder.
