# Four signed-value decimal UART monitor

Implement `uart_monitor` with parameter `CLK_DIV[15:0]=217`, active-low asynchronous input `rstn`, rising-edge clock `clk`, input `i_en`, four signed16-bit inputs `i_val0` through `i_val3`, and scalar output `o_uart_tx`. Startup and reset drive TX high. Reset clears every other functional register, fills the six-character buffer with zeros and the12-bit transmit shift register with ones, and starts in IDLE with value index0, byte index0 and end marker space. All next-state calculations use old values.

The monitor accepts i_en only in IDLE, advancing to SELECT; it runs a full four-value report irrespective of later i_en. SELECT for indexes0–3 samples the corresponding live input, increments value index, pulses decimal-conversion enable and enters WAIT. End marker is space for indexes0–2 and LF (0A) for index3. SELECT at index4 resets value index0 and returns IDLE. WAIT advances to PARSING. PARSING waits for conversion-done then enters SENDING. SENDING holds byte-transmit enable high; whenever the serializer is idle, it accepts the current byte, increments the3-bit byte index modulo8, and if old index7 returns SELECT. Thus each value emits six conversion characters, space20, then its end marker. The final value ends with space then LF, not CRLF. Input values are sampled separately when selected, not atomically at report start.

Decimal conversion uses3-bit count,16-bit unsigned magnitude, sign, zero-test and4-bit remainder registers. At count0 it continuously captures absolute value and sign of the sampled signed input (−32768 gives unsigned32768); when conversion enable is high it advances count1. At every nonzero count, increment modulo8, magnitude=old magnitude/10, remainder=old magnitude%10, zero_test=(old magnitude=0). At counts2–7, shift existing characters toward index5; insert at index0 ASCII digit30+OLD remainder, except count>2 AND old zero_test inserts minus2D if old sign is1 or space20 otherwise, and clears sign. This forms a right-aligned six-character signed decimal field, including one zero digit for zero. Done is registered old count=7, one cycle wide. Buffer contents otherwise hold.

The byte serializer has16-bit cycle count and4-bit bit count. Idle count0 forces TX high and cycle count0. If transmit enable is high it loads bit count12 and a12-bit vector, from bit12 down to1: high idle bit, low start bit, byte bits0 through7, then two high stop bits. On each busy edge TX becomes the OLD selected vector bit. If the16-bit sum (cycle_count+1)<CLK_DIV, increment cycle count; otherwise clear it and decrement bit count. At default217 each vector bit lasts217 clocks, with the first busy edge one edge after acceptance. Bytes are serialized LSB first. CLK_DIV0 or1 advances on each busy edge. Overflow in the16-bit increment is retained for other configurations; the official case uses217. The serial output is not combinationally changed by input data or enable.
