# NVDLA CDP single register group

Implement `NV_NVDLA_CDP_REG_single`, a32-bit register interface and LUT configuration bank. Inputs: scalar rising-edge `nvdla_core_clk`, active-low asynchronous `nvdla_core_rstn`, `reg_wr_en`; `reg_offset[11:0]`, `reg_wr_data[31:0]`; live readback inputs `lut_addr[9:0]`, `lut_data[15:0]`, scalar `consumer`, `status_0[1:0]`, `status_1[1:0]`. Output `reg_rd_data[31:0]` is combinational with no read enable. The remaining outputs are the stored fields and two combinational triggers listed below; each field's width equals the width of its indicated bit range.

All stored fields reset to0 asynchronously. On each rising edge outside reset, reg_wr_en writes only the fields in the exact byte offset below from the same numbered reg_wr_data bits. All other fields hold. Unlisted write bits are ignored; unsupported or unaligned offsets do not write anything and read0. Readback packs listed fields into the indicated bits and zeros all unlisted bits. Live fields are inputs and are read-only. reg_wr_en does not gate readback. There are no strobes or partial-byte writes.

| Offset(hex) | Read/write stored output fields | Read-only live fields |
|---|---|---|
| 000 | none | status_0[1:0] in bits1:0; status_1[1:0] in17:16 |
| 004 | producer bit0 | consumer bit16 |
| 008 | lut_table_id bit16; lut_access_type bit17 | lut_addr bits9:0 |
| 00C | none | lut_data bits15:0 |
| 010 | lut_le_function bit0; lut_uflow_priority bit4; lut_oflow_priority bit5; lut_hybrid_priority bit6 | none |
| 014 | lut_le_index_offset[7:0] in7:0; lut_le_index_select[7:0] in15:8; lut_lo_index_select[7:0] in23:16 | none |
| 018 | lut_le_start_low[31:0] | none |
| 01C | lut_le_start_high[5:0] in5:0 | none |
| 020 | lut_le_end_low[31:0] | none |
| 024 | lut_le_end_high[5:0] in5:0 | none |
| 028 | lut_lo_start_low[31:0] | none |
| 02C | lut_lo_start_high[5:0] in5:0 | none |
| 030 | lut_lo_end_low[31:0] | none |
| 034 | lut_lo_end_high[5:0] in5:0 | none |
| 038 | lut_le_slope_uflow_scale[15:0] in15:0; lut_le_slope_oflow_scale[15:0] in31:16 | none |
| 03C | lut_le_slope_uflow_shift[4:0] in4:0; lut_le_slope_oflow_shift[4:0] in9:5 | none |
| 040 | lut_lo_slope_uflow_scale[15:0] in15:0; lut_lo_slope_oflow_scale[15:0] in31:16 | none |
| 044 | lut_lo_slope_uflow_shift[4:0] in4:0; lut_lo_slope_oflow_shift[4:0] in9:5 | none |

Scalar `lut_addr_trigger` equals reg_wr_en AND offset008; scalar `lut_data_trigger` equals reg_wr_en AND offset00C. These are combinational decoded write qualifiers, not registered one-cycle pulses, and are not gated by reset. Writes00C do not store lut_data. Status writes000 do nothing. High address bits remain significant: e.g.F008 is not representable on the12-bit port, while offset008 matches, and108 does not. Diagnostic simulation plusargs are outside functional hardware; with default no plusargs, unsupported writes are simply ignored. The source places this diagnostic code in translate_off, and all actual output state has explicit reset.
