# fifomem

Parameters are `DATASIZE=8`, `ADDRSIZE=4`, and `FALLTHROUGH="TRUE"`. Inputs are `wclk`, `wclken`, `waddr[ADDRSIZE-1:0]`, `wdata[DATASIZE-1:0]`, `wfull`, `rclk`, `rclken`, and `raddr[ADDRSIZE-1:0]`; output is `rdata[DATASIZE-1:0]`. Memory has `2**ADDRSIZE` words. A rising wclk writes only when `wclken && !wfull`. With exact FALLTHROUGH `"TRUE"`, rdata asynchronously reads `mem[raddr]`; otherwise a rising rclk with rclken registers that word and holds when disabled. There is no reset or initialization, and cross-clock same-address collisions are implementation dependent.
