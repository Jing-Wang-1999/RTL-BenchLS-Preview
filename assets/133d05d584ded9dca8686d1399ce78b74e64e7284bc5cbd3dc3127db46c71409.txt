# mig_axi_adapter — default configuration specification

Implement a single-outstanding 32-bit backend to 64-bit AXI memory adapter. There are no parameters. All state changes on rising clk; synchronous active-high rst clears the state to idle, all registered outputs, and the remembered read-half selector to zero. Constant outputs are unaffected by reset. Backend readiness equals init_calib_complete AND idle; busy is its complement. Calibration only gates acceptance, not an operation already underway.

A backend request is accepted on backend_valid AND backend_ready. backend_we chooses write. The 27-bit byte address is aligned down to 8 bytes; bit2 selects the upper/lower 32-bit lane and bits1:0 are ignored. Write data and four byte strobes are placed in that half, with the other half zero. The same acceptance edge asserts AWVALID, WVALID and BREADY and enters write wait. AW and W handshakes clear their valid bits independently; payloads hold. A BVALID/BREADY handshake clears BREADY, sets response data zero, and enters response state. In read acceptance, register aligned ARADDR and bit2, assert ARVALID and RREADY, enter read wait. AR handshake independently clears ARVALID. The first RVALID/RREADY handshake captures the selected 32-bit half, clears RREADY and enters response state. The following edge pulses backend_resp_valid and returns to idle; response data holds until reset or another response. Every nonreset edge defaults response-valid low. No backend response-ready exists. Idle clears all AXI valid/ready registers before optional new request assignments, which take priority.

Both address channels have ID=0, LEN=0, SIZE=3 (8 bytes), BURST=1, LOCK=0, CACHE=3, PROT=0, QOS=0. WLAST=1. BID, BRESP, RID, RRESP and RLAST are ignored: error reporting and multibeat response validation are absent. A compliant one-beat AXI response is the intended transaction domain; do not invent error status. For arbitrary input sequences, a response can advance the wait state even if the address/data valid registers remain set, and those registers clear on the next idle edge. No extra assumptions are introduced into formal comparison. AXI output data/address retain values when invalid; reset fully defines them. The design does not offer misaligned byte extraction, bursts, multiple outstanding requests or model-specific behavior.
