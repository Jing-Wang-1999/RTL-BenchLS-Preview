# Specification

`rtlpp_00961` is combinational. It has scalar output `X`; logic inputs `A_N`, `B`, `C`; and scalar power-related inputs `VPWR`, `VGND`, `VPB`, `VNB`. The power inputs are present in the interface but do not affect this behavioral RTL. The module computes `X=(~A_N)&B&C` using an inverter, a three-input AND gate, and a continuous output connection. It has no parameters, clock, reset, state, or submodule.
