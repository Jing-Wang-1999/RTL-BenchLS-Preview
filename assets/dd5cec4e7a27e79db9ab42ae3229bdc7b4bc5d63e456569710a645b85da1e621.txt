# AXI-Lite controlled I2C master project
Implement every file and module in output_contract.json. Read the unchanged original README and declaration-only interfaces. Only the selected independent design and its complete RTL closure are requested; unrelated repository components and FPGA board designs are separate designs. Rising clk edges and synchronous active-high rst apply throughout. Assert reset initially for several clocks. Transfer ready/valid signals only on a rising edge with both asserted; preserve data while stalled. Internal state encoding and buffering may differ, but externally visible data, completion and error semantics must match. Private scoring uses one complete usable upstream testbench per point; vectors inside a bench are not additional points. The original source is withheld. Curator clarifications below supplement the original documents and take precedence where explicitly correcting ambiguity.

Implement i2c_master_axil, i2c_master and axis_fifo. The AXI-Lite wrapper includes command, transmit and receive FIFOs around the I2C master. Read specification/rtl_protocol_comments.md: its register map, command sequencing, timing diagrams and open-drain connection examples are unchanged prose extracted from the original source, not RTL implementation logic.

- This case uses a 32-bit AXI-Lite register interface and 7-bit I2C addressing. AXI-Lite read/write responses are OKAY (00). The address decoder ignores address bits [1:0]. Hold AWVALID and WVALID with their fields until both channels are accepted; the wrapper couples their acceptance. Responses are held until ready.
- Byte addresses 0/4/8/12 select status/command/data/prescale as documented. Writes respect WSTRB. A command byte-1 write submits a command if any command flag is set; byte-0 updates the 7-bit address. Command fields are start bit 8, read 9, write 10, write-multiple 11, stop 12. Read and write together is invalid. Data writes with byte-0 strobe enqueue a byte; bit 9 is last only when byte-1 is strobed in the same write. Every accepted data-register read consumes a valid receive byte; bit 8 indicates validity and bit 9 last. Atomic 16/32-bit accesses preserve data/flags together.
- Status bit 3 is sticky missed-ACK, bit 10 command overflow, bit 13 write overflow, each write-one-to-clear. A simultaneous new missed-ACK remains set. Other status bits follow the upstream table. Prescale resets to DEFAULT_PRESCALE and is writable by low two byte strobes unless FIXED_PRESCALE is set. Reserved read bits are zero. Command strobes clear after acceptance; do not assume they remain latched indefinitely.
- The I2C master emits start/repeated-start, address+direction, eight-bit data MSB first, ACK/NACK and stop per documented commands, honors externally stretched SCL, and leaves lines released when idle/reset. Use the documented combined open-drain outputs: i2c_scl_t/i2c_sda_t high releases the corresponding line; *_i observes the external resolved bus. Prescale is a quarter nominal bit period in input clock cycles. Command and data streams follow ready/valid; write-multiple continues until input last, and read+stop marks output last.
- axis_fifo is the parameterized AXI-stream queue used by all three FIFOs; preserve byte/last/user payload and order under independent stalls, reset empty and implement the declared selected FIFO branches. Qualification uses wrapper defaults (all FIFOs enabled at depth 32, programmable prescale) and the original master bench. Both usable project benches are retained; axis_fifo has no separate bench in this source root and is exercised through the wrapper.
