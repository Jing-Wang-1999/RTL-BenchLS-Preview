# 55-bit single-stage register (`autovcoder_061925`)

The module has scalar input `clock`, input `io_d[54:0]`, and output `io_q[54:0]`. It has no parameters, enable, or reset.

At every rising edge of `clock`, the 55-bit register captures `io_d`; `io_q` continuously equals that register, giving one-edge storage latency. Without simulation randomization the initial value is unknown. When the supplied `RANDOMIZE_REG_INIT` macro path is enabled, an initial simulation block fills it from `$random` after the configured randomization delay. This initialization machinery does not change the per-edge capture behavior.
