This module is a single-bit flip-flop with synchronous scan and asynchronous reset.

Inputs: Clock (CLK), data (D), scan data (SCD), scan enable (SCE), and active-low reset (RESET_B). Power pins (VPWR, VGND, VPB, VNB) are for physical implementation.

Output: A single registered output (Q).

Function: On the positive clock edge, if RESET_B is low, Q is set to 0. If RESET_B is high and SCE is high, Q takes the value from SCD. If RESET_B is high and SCE is low, Q takes the value from D. The reset is asynchronous and dominant.
