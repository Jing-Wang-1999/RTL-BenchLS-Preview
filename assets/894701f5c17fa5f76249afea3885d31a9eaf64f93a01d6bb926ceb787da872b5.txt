# mg_01003

Parameter `width=8` sets the width of inputs `in0` through `in7` and output `out`. Input `sel[2:0]` selects the source combinationally: values 0, 1, 2, 3, 4, 5, 6, and 7 select `in0`, `in1`, `in2`, `in3`, `in4`, `in5`, `in6`, and `in7`, respectively. All three-bit two-state selector values are covered. There is no clock, reset, state, latency, or submodule.
