# `mg_07572`

This module is a stateless three-input lookup table. Scalar inputs `IN2`, `IN1`, and `IN0` form a three-bit unsigned index in that most-to-least-significant order. Scalar output `OUT` continuously equals `INIT[{IN2,IN1,IN0}]`. Parameter `INIT[7:0]` defines the truth table and defaults to zero, making the default output zero for every binary input combination. There is no clock, reset, storage, or submodule.
