# Block-average filter (`rtlpp_01557`)

## Interface and parameters

Inputs are scalar `clk`, active-low asynchronous reset `rstn`, scalar `sample`, and `raw_data_in[ADC_WIDTH-1:0]`. Outputs are `ave_data_out[ADC_WIDTH-1:0]` and scalar `data_out_valid`. `ADC_WIDTH` defaults to 8 and `LPF_DEPTH_BITS` defaults to 4.

## Behavior

At every rising `clk` edge the module registers `sample` through two stages and registers `raw_data_in`. An accumulation event is `sample_d1 && !sample_d2`, so one event occurs for each sampled low-to-high transition of `sample`; holding `sample` high does not cause further events. The accumulated datum is the registered `raw_data_d1` associated with that detected transition.

The `LPF_DEPTH_BITS`-bit counter advances modulo `2^LPF_DEPTH_BITS` on accumulation events. When an event occurs with counter zero, the accumulator starts a new block with that datum. On other events it adds the datum. On the counter-zero event, `ave_data_out` simultaneously captures the previous accumulator shifted right by `LPF_DEPTH_BITS`, and `data_out_valid` is high for that clock interval via the registered `result_valid`. Consequently each valid output reports the completed preceding block of `2^LPF_DEPTH_BITS` samples; the first valid event after reset reports zero while beginning the first block. Between such events, `ave_data_out` holds and `data_out_valid` is low.

When `rstn` is low, both sample-history bits, the registered input, accumulator, counter, output, and valid register clear to zero immediately.
