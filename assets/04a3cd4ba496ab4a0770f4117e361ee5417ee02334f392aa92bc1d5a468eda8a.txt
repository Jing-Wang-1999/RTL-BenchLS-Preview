# LUT2

Implement a combinational two-input lookup table with scalar inputs I0 and I1, scalar output O, and a four-bit parameter INIT whose default is 4'h0. For binary inputs, {I1,I0}=00,01,10,11 selects INIT[0], INIT[1], INIT[2], INIT[3], respectively.

For inputs containing X or Z, apply these rules in order: if all four INIT bits compare equal, return INIT[0]; otherwise, if I1 is known zero and INIT[0] equals INIT[1], return INIT[0]; otherwise, if I1 is known one and INIT[2] equals INIT[3], return INIT[2]; otherwise, if I0 is known zero and INIT[0] equals INIT[2], return INIT[0]; otherwise, if I0 is known one and INIT[1] equals INIT[3], return INIT[1]. If none of these conditions is definitely true under four-state logical equality, output X. There is no clock, reset or stored state.
