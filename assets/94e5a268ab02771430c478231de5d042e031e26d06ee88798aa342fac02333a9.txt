**Waveform Lookup Module Specification**

This module generates a predefined periodic waveform by outputting stored sample values based on an input position index.

**Inputs:**
- Clock signal for synchronization.
- Reset signal (active-high) to initialize the module.
- 8-bit position index selecting the current waveform sample.

**Outputs:**
- 8-bit constant wavelength value (44), indicating the total number of samples in the waveform.
- 16-bit output value corresponding to the waveform sample at the given position index.

**Behavior:**
The module contains a fixed 44-sample waveform stored internally. The waveform represents a full cycle of a sinusoidal signal, including both positive and negative half-cycles. Upon receiving a position index, the module outputs the corresponding 16-bit sample value. The waveform is static and does not change during operation.

**Allowed Sub-modules:**
None. This is a combinational lookup module with no internal state or dynamic behavior beyond the fixed waveform storage.
