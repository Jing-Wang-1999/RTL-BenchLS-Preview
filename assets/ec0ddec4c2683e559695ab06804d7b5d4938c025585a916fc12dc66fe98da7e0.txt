Only the selected independent design and its complete RTL closure are requested; unrelated repository components and FPGA board designs are separate designs. Rising clk edges and synchronous active-high rst apply throughout. Assert reset initially for several clocks. Transfer ready/valid signals only on a rising edge with both asserted; preserve data while stalled. Internal state encoding and buffering may differ, but externally visible data, completion and error semantics must match. Private scoring uses one complete usable upstream testbench per point; vectors inside a bench are not additional points. The original source is withheld. Curator clarifications below supplement the original documents and take precedence where explicitly correcting ambiguity.

Implement axil_register integrating axil_register_rd and axil_register_wr. This is an independent AXI-Lite register-slice design, not a width/clock converter and not a configuration of the full-AXI register project, whose burst/ID/last payload contract differs.

- Transparently convey AXI-Lite AW, W, B, AR and R payloads in their natural directions, preserving addresses, protection, data, byte strobes and response codes. Read and write paths and their component channels have independent valid/ready handshakes; retain valid payload during backpressure and never couple AW acceptance to W being simultaneously present.
- Each channel REG_TYPE=0 bypasses, REG_TYPE=1 is a single simple register with possible bubbles, and REG_TYPE=2 is a skid buffer with two entries/full-throughput capability. All five default to1. The README says skid buffers generally, but the pinned default is type1; this explicit curator clarification takes precedence. Implement parameter behavior rather than hardwiring a single default mode.
- Synchronous active-high reset clears buffered valid states; combinational bypass remains direct. Values of payload when valid is low are unspecified. Do not introduce a memory, change transaction data or synthesize responses.
- Preserve both usable original integration benches (cocotb and MyHDL) as two points for this one project. Parameterized channel mode tests remain within the case; no additional project count is assigned for changing register depth/type.
