# ct_hpcp_cntinten_reg

This module is a one-bit register. Inputs are clock `hpcp_clk`, active-low asynchronous reset `cpurst_b`, write enable `cntinten_wen_x`, and write data `hpcp_wdata_x`; output `cntinten_x` is the stored bit.

Whenever `cpurst_b` falls low, `cntinten_x` clears to 0 without waiting for a clock edge. On each rising edge of `hpcp_clk` while reset is high, an asserted `cntinten_wen_x` loads `hpcp_wdata_x`; otherwise the output retains its value. There are no submodules.
