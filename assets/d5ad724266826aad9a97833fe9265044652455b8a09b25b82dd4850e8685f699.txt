# Bidirectional I/O buffer (`mg_02965`)

## Interface and parameters

The ports are scalar input `i`, scalar input `oe`, scalar bidirectional `io`, and scalar output `o`. Parameters and defaults are: `io_standard="NONE"`, `current_strength="NONE"`, `current_strength_new="NONE"`, `slew_rate=-1`, `slow_slew_rate="NONE"`, `location="NONE"`, `enable_bus_hold="NONE"`, `weak_pull_up_resistor="NONE"`, `termination="NONE"`, `input_termination="NONE"`, `output_termination="NONE"`, and `lpm_type="alt_iobuf"`. These parameters do not alter the RTL behavior.

## Behavior

With binary controls, `oe=1` makes the module drive `io` with `i`, and `oe=0` makes its driver contribute high impedance. The driver expression is the four-state conditional `(oe == 1) ? i : 1'bz`. If `oe` is X or Z, `(oe == 1)` is X and the conditional merges `i` with Z: the driver is Z when `i` is Z and X for `i` equal to 0, 1, or X. Output `o` follows the resolved value on `io`, including externally driven values and four-state values. There is no clock, reset, or internal sequential state.
