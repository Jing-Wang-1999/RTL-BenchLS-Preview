# FP16_TO_FP32_leading_sign_23_0

This combinational module has input `mantissa[22:0]` and output `rtn[4:0]`. For two-state input, `rtn` is the unsigned count of consecutive zero bits starting at mantissa bit 22 and moving downward. A set bit 22 produces 0; a highest set bit at position k produces `22-k`; and all-zero input produces 23. There are no parameters, clock, reset, state, latency, or submodules.
