# Specification

`mg_01213` has parameter `SIZE=1`, inputs `din[SIZE-1:0]`, `clk`, `se`, `si[SIZE-1:0]`, and outputs `q[SIZE-1:0]`, `so[SIZE-1:0]`. With CONNECT_SHADOW_SCAN defined, q captures si when se else din on each rising edge, and so=q. Without it, q always captures din and so is all zero; se and si are ignored. There is no reset or initialization.
