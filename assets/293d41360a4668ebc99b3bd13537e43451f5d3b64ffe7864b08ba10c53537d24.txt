# SDP_Y_CORE_leading_sign_49_0

This combinational module has a 49-bit input `mantissa[48:0]` and a 6-bit output `rtn[5:0]`. It has no parameters, clock, reset, state, or submodules.

For a binary-valued input, `rtn` is the number of consecutive zero bits starting at `mantissa[48]` and proceeding toward `mantissa[0]`. Therefore a set `mantissa[48]` produces 0, a first set bit at position `k` produces `48-k`, and an all-zero input produces 49. The output is an unsigned 6-bit encoding of that count.
