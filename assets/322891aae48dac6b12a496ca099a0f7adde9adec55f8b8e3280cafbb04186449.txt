**Module Specification: Control Unit**

**Overview**
This module is a control unit for a simple processor. It decodes a 6-bit operation code (opcode) and generates the corresponding control signals that coordinate the operation of the processor's datapath components (e.g., register file, ALU, memory). The outputs are purely combinational, determined instantaneously by the input opcode.

**Inputs**
*   `OperationCode` (6 bits): The instruction opcode to be decoded.

**Outputs**
The module sets the following single-bit control signals (unless marked otherwise), where a `1` typically indicates an active/enabled function and a `0` indicates inactive/disabled. An `x` denotes a "don't care" condition where the signal's value is irrelevant for the current instruction.
*   `RegisterDestination`: Selects the destination register for a write operation.
*   `ALUSource`: Selects the second ALU operand (immediate value vs. register read).
*   `MemoryToRegister`: Selects the data to write to a register (ALU result vs. memory read data).
*   `RegisterWrite`: Enables writing to the register file.
*   `MemoryRead`: Enables reading from the data memory.
*   `MemoryWrite`: Enables writing to the data memory.
*   `Branch`: Enables a conditional branch operation.
*   `Jump`: Enables an unconditional jump operation.
*   `ALUOperation` (2 bits): Specifies the arithmetic/logic operation for the ALU.
*   `SignZero`: Controls whether an immediate value is sign-extended (`1`) or zero-extended (`0`) before use.

**Functional Behavior**
The module interprets the `OperationCode` and activates a specific set of control signals for each supported instruction type. The behavior for unsupported opcodes defaults to deactivating all control signals (except `ALUOperation` and `SignZero`, which are set to `00` and `0`, respectively).

The supported instruction types and their corresponding control signal patterns are:

1.  **R-Type Instructions** (Opcode `000000`): Used for register-to-register arithmetic/logic operations. The ALU's second operand comes from a register, the result is written back to a register, and no memory access occurs. The ALU performs the operation specified by its `10` code.

2.  **Load Word** (Opcode `100011`): Reads a word from data memory. An immediate value is used for the address calculation (sign-extended). The memory read data is written to a register.

3.  **Store Word** (Opcode `101011`): Writes a word to data memory. An immediate value is used for the address calculation (sign-extended). No register write occurs.

4.  **Branch on Not Equal** (Opcode `000101`): Performs a conditional branch. The ALU performs a comparison (operation `01`), and the branch is taken if the operands are not equal. The immediate offset is sign-extended. No register write or memory access occurs.

5.  **XOR Immediate** (Opcode `001110`): Performs a bitwise XOR between a register value and a zero-extended immediate constant. The result is written back to a register.

6.  **Jump** (Opcode `000010`): Performs an unconditional jump to a target address. Only the `Jump` signal is activated; most other control signals are irrelevant for this operation.

**Allowed Sub-modules**
This is a purely combinational decoder. No sub-modules are required or allowed; it must be implemented directly as a lookup table (e.g., via a case statement).
