# `SDP_Y_CORE_Y_alu_core_cfg_alu_algo_rsc_triosy_obj_cfg_alu_algo_rsc_triosy_wait_dp`
Ports are clock `nvdla_core_clk`, active-low asynchronous reset `nvdla_core_rstn`, scalar inputs `cfg_alu_algo_rsc_triosy_obj_biwt` and `cfg_alu_algo_rsc_triosy_obj_bdwt`, and scalar output `cfg_alu_algo_rsc_triosy_obj_bawt`. Let the one-bit state be `bcwt`. Combinationally, `bawt=biwt|bcwt`. A falling reset edge clears `bcwt` to 0. On each rising clock edge when reset is high, `bcwt <= (bcwt|biwt)&~bdwt`; therefore `bdwt=1` clears pending state, while `biwt=1` sets it when `bdwt=0`. No submodule is required.
