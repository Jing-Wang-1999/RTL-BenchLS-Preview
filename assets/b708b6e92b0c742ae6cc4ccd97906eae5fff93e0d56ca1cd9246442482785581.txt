# Multiplexer modules

Provide four combinational modules. `origen_016634` has 32-bit inputs `A`, `B`, and `C`, 2-bit input `sel`, and 32-bit `reg` output `out`. Select `A` for `sel=00`, `B` for `sel=01`, and `C` for `sel=10` or `11`.

`mux_2_5bit` has 5-bit inputs `A` and `B`, one-bit input `sel`, and 5-bit wire output `out`; select `A` when `sel=0` and `B` when `sel=1`. `mux2to1` has one-bit inputs `in1`, `in2`, and `sel`, and one-bit wire output `out`; select `in1` when `sel=0` and `in2` when `sel=1`. `mux2_32bit` has 32-bit inputs `b32in1` and `b32in2`, one-bit input `b32sel`, and 32-bit wire output `b32out`; apply the same two-to-one selection independently to every bit, selecting `b32in1` for zero and `b32in2` for one. All paths are combinational, with no clock, reset, storage, parameters, or latency.
