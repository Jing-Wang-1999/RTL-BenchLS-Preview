# ODIN neuron state transition

Implement combinational module `izh_neuron_state`. No clock/reset, parameters, internal storage or latency. Current state is supplied externally and next state is computed for every input combination. All arithmetic on4-bit state wraps modulo16, on3-bit counters modulo8; comparisons are unsigned. This is a phenomenological digital neuron state component, not a numerical differential-equation solver.

For compact notation below remove prefix `param_` from parameter inputs and `state_` from current-state inputs. `core_i` and `sign_i` are intermediate values, not output registers. In every ordered list take the first matching condition; otherwise hold the corresponding supplied current state. The four resonant sign codes are POS=0,NEG=1,ZERO_TO_P=2,ZERO_TO_N=3.

Compute intermediate membrane core_i:

1. If spklat_en and dapdel_cnt!=0: hold core.
2. If phasic_lock and core=0: hold core.
3. Else if event_tref: reson_en has first priority (subtract1 only when reson_sign=ZERO_TO_N); else if refrac, hold if burst_lock else add1; else if acc_en, hold if spkout_done else subtract stim_str_tmp; else if dap_en and dapdel_cnt=1 and core>0 set0; else if ovfl_leak and core!=0, add1 when core[3]=1 else subtract1; otherwise hold.
4. Else if ovfl_inh: when reson_en, add1 for NEG/ZERO_TO_N unless core=7, subtract1 for POS/ZERO_TO_P unless core=0, otherwise hold. Without reson_en hold during refrac; otherwise subtract1 except at saturation core=8 if neg_en, or core=0 if not neg_en.
5. Else if ovfl_exc: when reson_en, subtract1 for NEG/ZERO_TO_N unless core=0, add1 for POS/ZERO_TO_P unless core=7, otherwise hold. Without reson_en hold during refrac, or when class2_en and neither stim_gt_thr_exc nor stim_tmp_gt_thr_exc; otherwise add1 except hold at core=7.
6. Otherwise hold core.

Compute sign_i: if not reson_en choose POS. Else if not event_tref hold reson_sign. Else if core=0 choose POS. Otherwise map POS->ZERO_TO_N,NEG->ZERO_TO_P,ZERO_TO_P->POS; ZERO_TO_N maps to POS when core_i=0, otherwise NEG.

Compute spike, by ordered priority: if reson_sharp_en, spike=ovfl_exc AND dapdel_cnt=reson_sharp_amt; else if spklat_en, spike=event_tref AND dapdel_cnt=1; else if rebound_en, spike=stim_lone_spike_inh OR core_i=threshold_eff; else if bist_en, spike=(!bist_lock AND stim_lone_spike_exc) OR (bist_lock AND core_i=0) OR core_i=threshold_eff; else if current inhin_lock, spike=(core_i=0); else if reson_en, spike=(sign_i=POS AND core_i=threshold_eff); else spike=(core_i=threshold_eff). There is no blanket event enable on these comparisons: even no-event inputs can assert spike if state equals threshold.

The output event_out is `{spike,0[2:0],0[2:0]}` when current mixed_lock=1, otherwise `{spike,spk_ref,isi_ref}`. Its low fields can remain nonzero with spike=0. state_core_next is core_i if no spike, otherwise +{0,rfr} when dap_en OR reson_en, or its4-bit modular negative otherwise. state_reson_sign_next is NEG on spike AND reson_en, otherwise sign_i.

Remaining next-state outputs:

|Output|Ordered update rule|
|---|---|
|state_inhin_lock_next|Set1 if inhin_en AND !refrac AND four-bit(-core)=threshold_eff; else clear0 if event_tref AND current inhin_lock AND stim_zero; else hold.|
|state_refrac_next|If spike OR state_inhin_lock_next: (!dap_en AND rfr!=0 AND !reson_en); otherwise clear if core_i=0, else hold refrac.|
|state_dapdel_cnt_next|If reson_sharp_en: increment if event_tref AND dapdel_cnt!=7; else clear on ovfl_exc; else hold. Otherwise load dapdel when (dap_en AND spike) OR (spklat_en AND core_i=threshold_eff AND core!=threshold_eff); else decrement on event_tref AND dapdel_cnt!=0; else hold.|
|state_phasic_lock_next and state_mixed_lock_next|If spike AND (stim_tmp_gt_thr_exc OR stim_gt_thr_exc), set to phasic_en/mixed_en respectively. Else if event_tref AND spkout_done AND (core=0 OR refrac) AND stim_tmp_gt_thr_exc, set to those enables. Else if !stim_gt_thr_exc, clear both. Else hold both.|
|state_spkout_done_next|Clear on event_tref; else set on spike; else hold.|
|state_bist_lock_next|On event_tref AND bist_en: toggle iff stim_lone_spike_exc, otherwise hold. Else hold.|
|state_burst_lock_next|Set if event_out[6] AND event_out[5:3]!=0; else clear on burst_end; else hold.|

All mode combinations follow the stated priority. Inputs that would normally be computed by surrounding stimulation logic remain independent public inputs; do not add consistency assumptions, register any output, or reinterpret unsigned encoded state as signed comparisons.
