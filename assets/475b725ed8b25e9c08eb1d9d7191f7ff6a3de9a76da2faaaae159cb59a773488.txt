# `FL1P3DX_FUNC`

`FL1P3DX_FUNC` is a one-bit register with inputs `D0`, `D1`, `SP`, `CK`, `SD`, `CD`, `SR`, and `notifier`, and registered output `Q`. Active-high `SR` is asynchronous: its rising edge immediately clears `Q` to zero and it has highest priority. On each rising edge of `CK` while `SR` is low, `CD` clears `Q`; otherwise `SD` loads `D1`; otherwise `SP` loads `D0`; otherwise `Q` holds. Thus the priority is `SR`, `CD`, `SD`, then `SP`. `CD` is synchronous because it is absent from the sensitivity list. `notifier` is unused and has no effect. There is no specified power-up value before a qualifying event.
