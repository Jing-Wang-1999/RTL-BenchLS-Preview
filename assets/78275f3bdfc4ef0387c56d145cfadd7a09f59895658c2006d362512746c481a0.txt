# sbox1

`sbox1` is a combinational lookup table with input `in[5:0]` and output `out[3:0]`. The complete mapping for inputs 0 through 63, listed in order, is:

`15, 3, 1, 13, 8, 4, 14, 7, 6, 15, 11, 2, 3, 8, 4, 14, 9, 12, 7, 0, 2, 1, 13, 10, 12, 6, 0, 9, 5, 11, 10, 5, 0, 13, 14, 8, 7, 10, 11, 1, 10, 3, 4, 15, 13, 4, 1, 2, 5, 11, 8, 6, 12, 7, 6, 12, 9, 0, 3, 5, 2, 14, 15, 9`.

Every two-state six-bit input has an entry. There is no clock, reset, state, latency, parameter, or submodule.
