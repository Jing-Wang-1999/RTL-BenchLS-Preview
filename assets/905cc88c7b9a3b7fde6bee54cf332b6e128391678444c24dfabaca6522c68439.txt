This module is a finite state machine that detects the specific bit sequence "1011" on a serial input stream. The module operates on a clock signal and includes a reset.

Inputs:
- inp_bit: The serial input bit sampled on each clock cycle.
- reset: An active-high reset that forces the state machine to its initial idle state.
- clk: The clock signal for synchronous operation.

Output:
- seq_seen: A flag that goes high for one clock cycle when the complete sequence "1011" has been detected. It is high only when the machine is in the final detection state.

Behavior:
The machine starts in an idle state. It transitions through intermediate states as bits matching the sequence "1011" are received consecutively. If at any point an out-of-sequence bit arrives, the machine returns to idle or an appropriate earlier state (as defined by the state transitions). Specifically, after detecting "1011", if the next input bit is 1, the machine transitions to the state representing a single '1' (as this could be the start of a new sequence). If the next bit is 0, it returns to idle.

Allowed sub-modules:
Only standard flip-flops and basic combinational logic may be used. No other sub-modules are required.
