# Specification

`autovcoder_063852` has parameter `G_WIDTH=32`, clock `clk`, active-high synchronous reset `rst`; ready/valid input interface `din[G_WIDTH-1:0]`, `din_last`, `din_valid`, `din_ready`; and output interface `dout[G_WIDTH-1:0]`, `dout_last`, `dout_valid`, `dout_ready`. One register holds data plus last. Empty asserts din_ready and deasserts dout_valid. Full asserts dout_valid, holds output stable under backpressure, and asserts din_ready when dout_ready permits same-cycle consume-and-replace. On simultaneous handshakes, new input replaces old output. Reset takes effect at a rising edge, clears stored bits, and marks empty.
