# Specification

`autovcoder_142995` has clock `clk`, active-high asynchronous `reset`, request inputs `request0`..`request3`, and registered grant outputs `grant0`..`grant3`. Reset clears grants and sets `last_granted=0`. Each clock clears all grants, then tests requests beginning with `last_granted` and proceeding cyclically; it asserts at most one grant and records that index. If no request is set, the index holds. Because testing begins at the previous winner rather than its successor, a continuously asserted winner retains priority and can starve others.
