# Required original testbench ABI

All paths below are relative to the submitted veer_wrapper instance. Preserve
instance names and actual backing storage; do not emulate these as separate
harness-only copies. The fixed snapshot defines precise sizes.

| Relative path | Meaning/type |
|---|---|
| veer.dec.tlu.minstretl |32-bit retired-instruction counter low word |
| veer.dec.tlu.mcyclel |32-bit cycle counter low word |
| veer.dec.dec_i0_wen_wb, veer.dec.dec_i1_wen_wb |1-bit writeback enables |
| veer.dec.dec_i0_waddr_wb, veer.dec.dec_i1_waddr_wb |5-bit register indices |
| veer.dec.dec_i0_wdata_wb, veer.dec.dec_i1_wdata_wb |32-bit writeback data |
| veer.dec.dec_nonblock_load_wen |1-bit nonblocking load writeback enable |
| veer.dec.dec_nonblock_load_waddr |5-bit destination register |
| veer.dec.lsu_nonblock_load_data |32-bit nonblocking load data |
| mem.Gen_dccm_enable.dccm.mem_bank[b].dccm_bank.ram_core |Actual DCCM39-bit RAM words, banks0..7,2048 words per bank |
| mem.iccm.mem_bank[b].iccm_bank_lo0.ram_core |Actual ICCM39-bit RAM words, enabled bank groups,16384 words per RAM |
| mem.iccm.mem_bank[b].iccm_bank_lo1.ram_core |Same, second low RAM |
| mem.iccm.mem_bank[b].iccm_bank_hi0.ram_core |Same, first high RAM |
| mem.iccm.mem_bank[b].iccm_bank_hi1.ram_core |Same, second high RAM |

The selected8-bank ICCM configuration uses two bank groups b=0,1, each with the
four named RAMs. Public declarations and fixed snapshot provide the selected
array dimensions. The original bench writes the RAM arrays before running the
CPU and reads trace state during execution. Normal ISA-visible accesses must
use this same storage. No host callbacks are required inside candidate RTL.
