# Registered eight-bit skid buffer

Implement `skidbuffer` with default parameters `DW=8`, `OPT_LOWPOWER=0`, `OPT_OUTREG=1`, `OPT_PASSTHROUGH=0`; do not enable verification-only preprocessor macros. Inputs `i_clk`, `i_reset`, `i_valid`, `i_ready` are one bit and `i_data` is 8 bits. Outputs `o_ready`, `o_valid` are one bit and `o_data` is 8 bits. Despite its name, `i_reset` is an asynchronous **active-low** reset. All normal state transitions occur on rising `i_clk` edges.

The buffer has a registered output entry and one skid entry. Let S be skid-valid and D its eight-bit data; let V and O be the output valid and data. Reset clears S,D,V,O to zero. Combinationally `o_ready=!S`, `o_valid=V`, `o_data=O`.

At each nonreset edge use pre-edge values for these simultaneous updates:

- Set S to one if `i_valid && !S && V && !i_ready`; otherwise clear S if `i_ready`; otherwise hold S.
- Capture `i_data` into D whenever `!S`, independently of `i_valid`; otherwise hold D.
- If `!V || i_ready`, set V to `i_valid || S` and set O to D when S is set, otherwise to `i_data`. Otherwise hold both V and O.

A source transfer is sampled with `i_valid && o_ready`, an output transfer with `o_valid && i_ready`. Under normal ready/valid use the buffer preserves order and permits a transfer each clock. The equations also define behavior when a producer changes invalid data or ignores backpressure; there is no hidden input-stability assumption in equivalence. Invalid output data is still the explicitly updated O value, not forced low. All state is reset-established; nondefault low-power, bypass and unregistered modes are outside this case.
