UART_SPEC='''# UART command to AXI4 project
Implement the three-module uart2axi4 project using the unchanged bilingual original README in specification/project.md. The Chinese section 3.5 contains the complete original ASCII command grammar; both language sections are part of the input. The original document covers UART streams, buffering, byte ordering, framing and command/response behavior.

Curator clarification of the pinned configuration and documentation defects:
- uart2axi4 instantiates uart_rx and uart_tx; implement all three declared files. Clock edges are rising, reset rstn is asynchronous active-low and must be asserted initially. Standalone UART defaults remain available. Qualified whole-project configuration uses CLK_FREQ=16000000, BAUD_RATE=115200, PARITY="NONE", BYTE_WIDTH=4 and A_WIDTH=32. The second upstream bench uses 4 MHz TX / 5 MHz RX, 115200 baud, odd parity, one stop bit, a two-byte TX stream with FIFO_EA=0, and RX FIFO_EA=1.
- UART transmits start-low, eight bits LSB first, the selected parity, then STOP_BITS high stop bits. Fractional division distributes clock periods as described by the original manual. TX transmits enabled bytes least-significant byte first. All i_tkeep bits are active-high; the Chinese sentence saying i_tkeep[0]=0 selects a byte is a typo (the English section is correct). With no RX FIFO, valid is a one-cycle arrival pulse and cannot wait for ready; with buffering, unread data is held and a full queue drops a new byte, pulsing overflow.
- Commands accept either letter case for W/R and hexadecimal digits. Spaces separate words. CR or LF terminates a command; ignored leading whitespace/empty newline does not create an operation. W<address> <data>... issues one write burst; R<address> <length> issues one read burst. Use the documented legal range 1..256 words, address/data widths from the declaration, and no commands overlapping an in-progress transaction. AXI LEN is the number of beats minus one. Write data is ordered exactly as the command; LAST accompanies its final beat. Address and data valid/ready handshakes determine acceptance. BREADY is permanently high. Read ends on the requested beat count or RLAST, whichever arrives first. No WSTRB, IDs or response-status ports exist in this simplified interface.
- For BYTE_WIDTH=4, successful writes return the eight-character word "okay    ", followed by an extra space and LF; invalid commands return "invalid ", followed by an extra space and LF. Read data is lowercase fixed-width hexadecimal, eight characters per word, separated by spaces; a trailing space precedes the final LF. Other documented BYTE_WIDTH values truncate/pad these fixed little-endian response words to 2*BYTE_WIDTH characters. Exact response formatting is a curator clarification of the original prose's okay/invalid examples.
- The public contract requires initial reset. Reference-only initial assignments duplicating reset values and the parameter diagnostic printing section are removed; every original file is retained. No functional state transition or data equation is changed. This case excludes malformed numeric overflow and traffic exceeding UART reply-buffer capacity, whose behavior is not fully specified upstream.

Scoring uses both original benches, with explicit failure assertions, response checks and added observation of public AXI address/data ports. One bench is one point; configurations and vectors do not increase the case count. Finite verification is not exhaustive protocol proof.
'''
FPU_SPEC='''# Double-precision floating-point unit project
Implement the seven-module non-pipelined fpu project described by the original Readme.txt and Double_FPU.PDF in specification/. The separate pipeline directory is another design and is excluded. The original documentation supplies the IEEE binary64 representation, supported arithmetic, rounding modes, denormal handling, exceptional values, architecture and enable/ready API.

Curator port/configuration clarification from the pinned release:
- fpu in fpu_double.v is the top. Required arithmetic helpers are fpu_add, fpu_sub, fpu_mul, fpu_div, fpu_round and fpu_exceptions, with their declaration-only interfaces. Inputs opa/opb and output out are 64-bit IEEE binary64 encodings. fpu_op=0/1/2/3 selects add/subtract/multiply/divide; other opcodes are outside this case. rmode=0 is nearest ties-to-even, 1 toward zero, 2 toward positive infinity, 3 toward negative infinity.
- All state uses rising clk and synchronous active-high rst. Assert reset across at least two edges before work. Hold operands, operation and rounding mode stable while asserting enable for two clock edges, then deassert it. Do not overlap operations; wait for ready before starting the next. ready and top output/status registers clear on reset. Completed output is held until the next operation result. The original 20/21/24/71-cycle arithmetic latencies are descriptive; the qualified upstream transactions allow 80 clocks after enable is deasserted, so a different internal pipeline is permitted within that finite completion budget.
- Preserve the document's binary64 rounding, denormal support, signed arithmetic and output status signals underflow/overflow/inexact/exception/invalid. The private upstream bench compares 50 binary64 results across all four operations and rounding modes; it does not independently establish exhaustive status-flag or IEEE754 conformance. The PDF's prose binary exponent for 3.5 omits a zero: the correct stored 11-bit exponent is 10000000000, as its accompanying diagram shows.
- Internal arithmetic helper boundaries remain part of the required project closure; implement their roles in operand alignment, arithmetic, normalization, rounding and exception selection. Their state encodings are unrestricted. No vendor primitive is required by the pinned implementation.
'''

def source(slug):
 p=list((ROOT/'scope2/common/projects').glob('*/'+slug+'/project.json'))
 assert len(p)==1
 return Path(json.loads(p[0].read_text())['source']['local_path'])

def uart_benches(src):
 t=strip_comments((src/'SIM/tb_uart2axi4.v').read_text())
 t=t.replace('module tb_uart2axi4 ();','module tb;')
 t=re.sub(r'initial\s+\$dumpvars\([^;]*;','',t)
 t=t.replace('$stop;','$fatal(1,"upstream watchdog");')
 t=t.replace('$finish;', 'begin if(chars!=48 || aw_count!=1 || ar_count!=1 || w_count!=3) $fatal(1,"incomplete UART/AXI transactions chars=%d aw=%d ar=%d w=%d",chars,aw_count,ar_count,w_count); $display("RTL_BENCHLS_PASS"); $finish(0); end')
 t=t.replace('$write("%c", byte_from_dut);','begin if(chars>=48 || byte_from_dut !== response[8*(47-chars)+:8]) $fatal(1,"UART response byte %d",chars); chars=chars+1; end')
 # Whitespace is normalized by ignoring ASCII spaces/CR/LF. Compare substantive
 # response characters rather than forcing implementation-specific padding.
 t=t.replace('if (en_from_dut)','if (en_from_dut && byte_from_dut!=8\'h20 && byte_from_dut!=8\'h0a && byte_from_dut!=8\'h0d)')
 t=t.replace('chars!=48','chars!=43').replace('chars>=48','chars>=43').replace('47-chars','42-chars')
 t=t.replace('wire        uart_from_dut;', '''integer chars=0,aw_count=0,ar_count=0,w_count=0;
reg [8*43-1:0] response="okay12345678123456781234567812345678invalid";
wire awvalid,arvalid,wvalid,wlast; wire [31:0] awaddr,araddr,wdata; wire [7:0] awlen,arlen;
always @(posedge clk) if(rstn) begin
 if(awvalid)begin if(awaddr!==32'h12f || awlen!==2)$fatal(1,"write address/length");aw_count=aw_count+1;end
 if(arvalid)begin if(araddr!==32'h12f || arlen!==3)$fatal(1,"read address/length");ar_count=ar_count+1;end
 if(wvalid)begin
  case(w_count)
   0:if(wdata!==32'habc || wlast!==0)$fatal(1,"write beat0");
   1:if(wdata!==32'h32 || wlast!==0)$fatal(1,"write beat1");
   2:if(wdata!==32'h9876 || wlast!==1)$fatal(1,"write beat2");
   default:$fatal(1,"extra write");
  endcase
  w_count=w_count+1;
 end
end
wire uart_from_dut;''')
 for signal in ['awvalid','awaddr','awlen','arvalid','araddr','arlen','wvalid','wlast','wdata']:
  t,n=re.subn(r'\.'+signal+r'\s*\(\s*\)', '.'+signal+'('+signal+')',t);assert n==1
 u=strip_comments((src/'SIM/tb_uart.v').read_text()).replace('module tb_uart ();','module tb;')
 u=re.sub(r'initial\s+\$dumpvars\([^;]*;','',u)
 u=u.replace('$write("%02x ", rx_tdata);','received=received+1;')
 u=u.replace('$display("***error : RX data not increase");','$fatal(1,"UART receive order");').replace('$stop;',';')
 u=u.replace('$display("\\nrx overflow");','$fatal(1,"UART overflow");')
 u=u.replace('reg [7:0] expect_byte','integer received=0;\nreg [7:0] expect_byte')
 u=u.replace('$finish;','begin if(received<256)$fatal(1,"insufficient UART traffic");$display("RTL_BENCHLS_PASS");$finish(0);end')
 u+='\n'+(src/'SIM/tb_axis_inc_source.v').read_text()
 return [('uart2axi4','uart2axi4',t),('uart_increment','uart_rx',u)]

def fpu_bench(src):
 s=strip_comments((src/'fpu_TB.v').read_text()).replace('module fpu_tb;','module tb;\ninteger checked=0;')
 s,n=re.subn(r'\$display\(\$time,"ps Answer is correct %h", out\);','checked=checked+1;',s);assert n==50
 s,n=re.subn(r'\$display\(\$time,"ps Error! out is incorrect %h", out\);','$fatal(1,"binary64 result mismatch");',s);assert n==50
 s=s.replace('$finish;','if(checked!=50)$fatal(1,"incomplete FPU vectors");$display("RTL_BENCHLS_PASS");$finish(0);')
 return [('upstream50','fpu',s)]

def specs():
 u=source('wangxuan95_fpga-uart');f=source('arithmetic_core_double_fpu_verilog')
 return [dict(case_id='github_wangxuan95_uart2axi4_direct_v1',project='wangxuan95_fpga-uart',top='uart2axi4',instruction=UART_SPEC,configuration_record=dict(configuration_id='uart2axi4',top_module='uart2axi4',source_closure=['RTL/uart2axi4.v','RTL/uart_rx.v','RTL/uart_tx.v'],specification_paths=['README.md']),tests=uart_benches(u),original_tests=[str(u/'SIM'/n) for n in ['tb_uart2axi4.v','tb_uart.v','tb_axis_inc_source.v']],mutations=[('axi_address_corrupt','RTL/uart2axi4.v','assign awaddr  = addr;','assign awaddr  = addr ^ 1;'),('rx_data_corrupt','RTL/uart_rx.v','o_tdata <= buffer[rptr_next[EA-1:0]];','o_tdata <= buffer[rptr_next[EA-1:0]] ^ 1;')]),dict(case_id='opencores_double_fpu_direct_v1',project='arithmetic_core_double_fpu_verilog',top='fpu',instruction=FPU_SPEC,configuration_record=dict(configuration_id='fpu',top_module='fpu',source_closure=['fpu_double.v','fpu_add.v','fpu_sub.v','fpu_mul.v','fpu_div.v','fpu_round.v','fpu_exceptions.v'],specification_paths=['Readme.txt','Double_FPU.PDF']),tests=fpu_bench(f),original_tests=[str(f/'fpu_TB.v')],mutations=[('result_corrupt','fpu_double.v','out <= except_enable ? out_except : out_round;','out <= (except_enable ? out_except : out_round) ^ 1;')])]

def main():
 rows=[]
 for spec in specs():
  spec['builder_source']=str(Path(__file__).resolve());spec['point_timeout_seconds']=60
  candidate_draft=TASK/'project_pool/drafts'/spec['case_id']
  if candidate_draft.exists():
   target=BASE/'preserved_attempts'/spec['case_id'];target.parent.mkdir(exist_ok=True)
   assert not target.exists();candidate_draft.rename(target)
  draft=build(spec);case=json.loads((draft/'case.json').read_text());src=source(spec['project'])
  if spec['top']=='uart2axi4':
   for name in ['uart_rx.v','uart_tx.v']:
    p=draft/'private/reference/RTL'/name;s=p.read_text();assert '// parameter checking' in s
    s=s.split('// parameter checking')[0]+'\nendmodule\n'
    # These single-statement initializations duplicate explicit reset values.
    s,n=re.subn(r'\binitial\s+(?:\{[^}]+\}|\w+)\s*=\s*[^;]+;','',s)
    assert n==(3 if name=='uart_rx.v' else 2),(name,n)
    p.write_text(s)
    case['normalizations'].append(dict(path='RTL/'+name,rule='remove simulation-only parameter diagnostics; remove reset-redundant initial assignments; mandatory initial reset',removed_initial_assignments=n,original_sha256=digest(draft/'private/original_reference/RTL'/name),normalized_sha256=digest(p)))
  review=dict(review_date='2026-09-11',reviewer='Codex direct_misc original-document/RTL review',decision='pass_with_explicit_curator_clarifications',original_document_coverage=('UART stream/framing/FIFO contracts and bilingual ASCII AXI command grammar' if spec['top']=='uart2axi4' else 'binary64 algorithms, rounding/exception modes, architecture, enable/ready and reset API'),original_prose_rewritten=False,original_documents=[dict(path=n,sha256=digest(src/n)) for n in spec['configuration_record']['specification_paths']],instruction_sha256=digest(draft/'public/instruction.md'),clarification_scope=('configuration, active-high keep typo, finite response formatting, reset normalization, supported legal commands' if spec['top']=='uart2axi4' else 'op/round encoding, reset polarity, non-pipelined boundary, latency envelope, PDF exponent typo'),unresolved_material_findings=[],limitations='Manual engineering screening and finite upstream behavioral tests; no exhaustive formal proof.')
  write_json(draft/'private/specification_review.json',review);write_json(draft/'case.json',case)
  out=draft/'private/qualification';gold=evaluate(draft,draft/'private/reference',out/'golden');print(spec['case_id'],'golden',gold,flush=True);assert gold['full_project_pass']
  controls=[]
  for label,name,old,new in spec['mutations']:
   sub=out/label/'candidate';shutil.copytree(draft/'private/reference',sub);p=sub/name;s=p.read_text();assert old in s,(name,old);p.write_text(s.replace(old,new))
   score=evaluate(draft,sub,out/label/'evaluation');print(label,score,flush=True);assert score['compile_pass'] and not score['full_project_pass']
   controls.append(dict(name=label,compile_pass=True,detected=True,failed_points=[p['id'] for p in score['points'] if not p['passed']]))
  write_json(out/'review.json',dict(golden_score=1,golden_points=gold['passed_points'],total_points=gold['total_points'],controls=controls,specification_review='private/specification_review.json',scoring_unit='one whole upstream bench per point; all original vectors retained'))
  shutil.copyfile(TASK/'pipeline/evaluate_case_v2.py',draft/'private/verification/evaluate_case_v2.py')
  case.update(status='finalized',clarification_provenance='Unchanged original paired documents plus explicitly marked curator interface/configuration clarification.',readiness_review=dict(approved=True,reviewer='Codex direct_misc engineering qualification 2026-09-11',evidence_paths=['private/specification_review.json','private/qualification/review.json']))
  case['artifacts']={str(p.relative_to(draft)):digest(p) for p in sorted(draft.rglob('*')) if p.is_file() and p.name!='case.json'}
  write_json(draft/'case.json',case)
  dest=BASE/'sealed_cases'/spec['case_id'];dest.parent.mkdir(exist_ok=True);assert not dest.exists();draft.rename(dest)
  replay=evaluate(dest,dest/'private/reference',BASE/'sealed_replay'/spec['case_id']);assert replay['full_project_pass']
  row={k:case[k] for k in ['case_id','project_id','configuration_id']};row.update(path=spec['case_id'],manifest_sha256=digest(dest/'case.json'));rows.append(row)
  (BASE/'sealed_cases/index.jsonl').write_text(''.join(json.dumps(r,sort_keys=True)+'\n' for r in rows))
  write_json(BASE/'admission_summary.json',dict(cases=rows,passed_cases=len(rows),total_points=sum(json.loads((BASE/'sealed_replay'/r['case_id']/'score.json').read_text())['total_points'] for r in rows),model_evaluation_cases=0))
 print(validate(BASE/'sealed_cases'))

if __name__=='__main__':main()
