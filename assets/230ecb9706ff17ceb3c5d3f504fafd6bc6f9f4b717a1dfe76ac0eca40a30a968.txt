# ad_iobuf

`ad_iobuf` is a parameterized bidirectional I/O buffer array with `DATA_WIDTH = 1`. Inputs `dio_t` and `dio_i`, output `dio_o`, and bidirectional port `dio_p` are each `DATA_WIDTH` bits wide.

Independently for each bit `n`, `dio_o[n]` continuously observes `dio_p[n]`. When `dio_t[n]=0`, the module drives `dio_p[n]` with `dio_i[n]`; when `dio_t[n]=1`, it releases `dio_p[n]` to high impedance. The module is combinational and has no clock, reset, or state.
