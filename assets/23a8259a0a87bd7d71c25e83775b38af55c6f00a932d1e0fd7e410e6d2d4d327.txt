# NV_NVDLA_RT_cmac_b2cacc: default-configuration specification

Implement a three-stage retiming pipeline with eight independent176-bit data lanes,8-bit mask,8-bit mode,9-bit PD and a scalar PVLD. There are no parameters. All captures use rising nvdla_core_clk. Active-low asynchronous nvdla_core_rstn resets each stage PVLD and MASK to0; all stage PD, MODE and DATA are unreset, with no invalid-data zero or power-up guarantee.

Number source as stage0 and internal stages1..3. The public destination is stage3. On each nonreset edge, every stage captures the preceding stage PVLD and MASK unconditionally, including MASK when PVLD0. At every clock edge, including reset edges, each stage captures predecessor PD and MODE only when predecessor PVLD1, otherwise holds. For each lane i=0..7, stage DATA[i][43:0] captures predecessor DATA[i][43:0] only when predecessor MASK[i]1. DATA[i][175:44] captures predecessor upper bits only when predecessor MASK[i] AND predecessor MODE[i] are both1. These data enables do not include PVLD or reset. Disabled fields retain prior content even as mask/valid pipeline advances; there is no global stall or ready port.

All stages use preedge predecessor values, so a source word presented with PVLD and appropriate MASK/MODE reaches destination after three rising edges. A mask-active lane can update despite PVLD0; its upper-lane gating uses mode retained under the PVLD-qualified mode pipeline. Preserve this exact behavior instead of treating PVLD as a universal gate. For four-state simulation an unknown capture enable explicitly makes the corresponding captured field unknown; normal synthesized equivalence uses binary inputs and does not require resolving unknown payload. No arithmetic or computation is performed on the data. Raw601 lines represent repeated lane/stage capture logic, so this is a wide retimer rather than601 lines of independent algorithmic complexity.
