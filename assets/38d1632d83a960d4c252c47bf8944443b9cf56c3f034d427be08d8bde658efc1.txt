# Reviewed public diagnostic-port mapping
Derived from the original reset-manager public-port definition; internal names and state encoding are not required, but the public debug values are.

| Bits | Meaning |
|---|---|
| 11 | Reset pending |
| 10 / 9 / 8 / 7 | Request / source / destination / SG internal active-low resets |
| 6 / 5 / 4 / 3 | Request / synchronized source / destination / SG enabled state |
| 2:0 | Externally reported state: 0 resetting, 1 reset, 2 disabled, 3 startup, 4 enabled, 5 shutdown |

When disabled and drained in the qualified non-SG configuration, the original tests expect 0x701. This requirement is a public diagnostic encoding, not a requirement to reuse internal hierarchy names.
