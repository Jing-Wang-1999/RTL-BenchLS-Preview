# ColorBin2Channels

Parameters `color_width=8` and `color_channels=3` define the channel width and count. Input `b` is one bit. Output `channels[color_channels*color_width-1:0]` contains `color_channels` adjacent slices, where channel `i` occupies bits `(i+1)*color_width-1` down to `i*color_width`. Combinationally, every channel slice is all ones when `b=1` and all zeros when `b=0`. There is no state, clock, reset, latency, or submodule.
