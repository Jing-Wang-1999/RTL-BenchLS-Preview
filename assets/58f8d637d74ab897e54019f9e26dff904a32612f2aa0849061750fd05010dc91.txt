# 64-bit streaming Mersenne Twister — rtlpp_02379

Implement `rtlpp_02379`, without parameters. One-bit inputs: `clk`, `rst`, `output_axis_tready`, `seed_start`. Unsigned input: `seed_val[63:0]`. Outputs: unsigned `output_axis_tdata[63:0]`, one-bit `output_axis_tvalid`, and one-bit `busy`.

All state changes occur at rising clk edges. `rst` is synchronous active high and overrides all normal operations. Require at least one reset edge before use; no declaration-initializer or pre-reset power-up behavior is part of this contract. Reset makes busy and output valid/data zero, selects idle mode and the unseeded index sentinel 313, clears the seed multiplier state and sets both memory read pointers to zero. Reset does **not** clear the 312-entry 64-bit state memory, saved word, or registered read data. These retained/arbitrary values cannot be used as an initialized generator state; a full seeding sequence is required before output.

The following behavior defines both the number sequence and cycle timing. All arithmetic on words is unsigned modulo 2^64; right shifts are logical. The state contains memory M[0…311], index i, a saved word s, two read pointers pa/pb and their registered data a/b. Memory reads occur on every non-reset edge, reading the **old** memory at the pointers' newly selected values (read-before-write if addresses collide). Pointers and read data may continue updating even when no output is produced. Outputs data/valid are registered.

On every normal edge, valid initially becomes old valid AND NOT ready, and output data initially holds. Any number-generation operation below overrides valid to one and replaces data. Thus a stalled valid output remains unchanged, including during a reseed. Starting a seed does not discard an outstanding valid output. Busy is one exactly while in seed mode; it is zero in idle mode, including during number generation.

In idle mode, an asserted seed_start has priority over ready: write seed_val to M[0], save it in s, set i=1, initialize the serial multiply described below, and enter seed mode. If seed_start is low and ready is high while i=313, perform the identical initialization using default seed 5489. If both seed_start and ready are low, hold the generator state. If idle, ready is high and i is not 313, perform one number-generation step described below. Seed requests are ignored while already in seed mode. There is no queued reseed request.

Seeding uses constant F=6364136223846793005. A serial multiplication is initialized with accumulator P=0, multiplicand U=s XOR (s>>62), multiplier V=F and countdown n=63. On each seed-mode edge with n nonzero, conditionally add U to P if V's low bit is one, then shift U left one and V right one, and decrement n. On an edge with n=0:

* If i<312, compute s=P+i, write s to M[i], increment i, set read pointer pa=0, and initialize another multiplication with the new s and countdown 63. The other read pointer holds.
* If i=312, finish: set i=0, save old registered read value a in s, set pa=1 and pb=156, and enter idle. No memory write or output generation occurs on this finishing edge.

The constant F has bit 63 zero, so 63 shift-add iterations implement its full low-64-bit product. Seeding M[i] therefore implements F*(M[i-1] XOR (M[i-1]>>62))+i modulo 2^64. The schedule deliberately includes a final unused multiplication before the finishing edge: busy deasserts 19,968 clock edges after the seed acceptance edge. Output generation may occur on the following edge if ready is high. Ready never stalls seed mode. All 312 entries have been written and the read pipeline has been established before a valid generated output can occur.

For each idle generation step, use pre-edge s,a,b and i:

1. Form z by concatenating s[63:31] with a[30:0]. Form w=b XOR (z>>1) XOR (0xB5026F5AA96619E9 if z bit 0 is one, otherwise zero).
2. Temper w successively: t=w XOR ((w>>29) AND 0x5555555555555555); u=t XOR ((t<<17) AND 0x71D67FFFEDA60000); v=u XOR ((u<<37) AND 0xFFF7EEE000000000). Publish data=v XOR (v>>43), with valid=1.
3. Write w to M[i], save a in s, increment i modulo 312, and increment each of pa and pb modulo 312. Remain idle. The registered memory reads use these incremented pointers and pre-write memory.

Generation depends on ready, even when valid is zero; do not precompute an output while ready is low. A high ready can simultaneously consume a prior valid value and produce the next value. Data holds while seeding or idle without generation, even if its valid bit clears. Reset aborts seeding and returns to the unseeded sentinel; it does not preserve sequence continuity. All external seed values, reseeding while a prior output is stalled, and arbitrary ready stalls are supported under the reset-first contract.
