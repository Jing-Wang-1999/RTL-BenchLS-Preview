This module is a 4-bit BCD to 7-segment display decoder.

**Inputs:**
- A 4-bit binary-coded decimal (BCD) input signal, `bcd`, representing values 0 through 15.

**Outputs:**
- A 7-bit output signal, `seg`, where each bit directly controls one segment (a through g) of a common-cathode 7-segment display. A logic '1' illuminates the corresponding segment.

**Function:**
The module converts the 4-bit BCD input into the appropriate 7-segment pattern for displaying hexadecimal digits (0-9, A-F). The output is purely combinational, updating immediately whenever the input changes.

**Mapping:**
The input values 0 through 15 are mapped to their standard hexadecimal representations on the display:
- 0-9: Displays digits 0 through 9.
- 10-15: Displays letters A through F (A, b, C, d, E, F).
For any undefined input state, all segments are turned off (display blank).

**Allowed Sub-modules:**
None. The function must be implemented directly as combinational logic.
