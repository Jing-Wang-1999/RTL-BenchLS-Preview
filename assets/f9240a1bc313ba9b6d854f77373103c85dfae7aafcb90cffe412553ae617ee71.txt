### Module Specification: Input Monitor with LED Display

**Function**
This module provides a hardware-level input monitoring system that visualizes the status of various peripheral signals using four on-board LEDs. It operates by directly connecting specific input lines to LED outputs, allowing real-time observation of signal activity without any processing or state logic.

**Inputs**
- **Clock and Reset**: A 50 MHz clock (CLK_50) and an active-low reset signal (RESET, mapped to KEY0).
- **PS/2 Ports**: Separate clock and data lines for a keyboard (PS2_KEYBOARD_CLK, PS2_KEYBOARD_DAT) and a mouse (PS2_MOUSE_CLK, PS2_MOUSE_DAT).
- **UART Interface**: Receive (UART_RXD) and transmit (UART_TXD) serial communication lines.
- **Joystick**: Six directional and button inputs (JOY1_UP, DOWN, LEFT, RIGHT, B1_P6, B2_P9) and one output control signal (JOYX_SEL_O).
- **Pmod MicroSD**: An 8-bit bidirectional port (PMOD1[7:0]) for SD card communication.

**Outputs**
- **Board LEDs**: A 4-bit output (BOARD_LEDS[3:0]) where each LED directly reflects the logical state of selected input signals.

**Behavior**
The module functions as a passive signal router. Each LED is statically assigned to mirror one or more input signals based on the implemented configuration. The default configuration connects:
- LED0 to the keyboard clock.
- LED1 to the keyboard data line.
- LED2 to the mouse clock.
- LED3 to the mouse data line.

Alternative commented configurations allow flexible reassignment. LEDs can display individual signals (e.g., UART lines, joystick buttons) or combined logical OR of multiple inputs, optionally including the inverted reset signal. The selection determines whether the LEDs show raw signal values, aggregated activity, or test patterns.

**Allowed Sub-modules**
None. The design consists solely of direct continuous assignments.

**Key Characteristics**
- Purely combinational; no clock-dependent logic or internal state.
- Supports modular signal mapping via configuration changes.
- Serves as a diagnostic or demonstration tool for observing peripheral signal integrity.
