The module implements a traffic light controller with three states: Red, Green, and Yellow. It operates on a clock signal and an asynchronous reset.

Inputs:
- Clock (clk): Synchronizes all operations.
- Reset (reset): When asserted, immediately sets the state to Red and clears the internal counter.
- Green Time (green_time): A 4-bit value defining the duration of the Green state.
- Yellow Time (yellow_time): A 4-bit value defining the duration of the Yellow state.
- Red Time (red_time): A 4-bit value defining the duration of the Red state.

Output:
- State (state): A 2-bit output encoding the current light: 00 for Red, 01 for Green, 10 for Yellow.

Behavior:
On each clock cycle, if reset is not active, the module counts up using an internal 4-bit counter. It remains in the current state until the counter reaches the programmed duration for that state. When the duration is met, it transitions to the next state in the sequence Red -> Green -> Yellow -> Red and resets the counter to zero. The durations are loaded from the green_time, yellow_time, and red_time inputs. The system is fully synchronous to the positive clock edge, with reset taking priority.
