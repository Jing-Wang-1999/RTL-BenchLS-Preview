**Module Specification: rtlpp_10243**

**Overview**
This module is a synchronous, pipelined digital signal processing block that computes a fixed linear transformation of a signed input sample. It operates on a single input stream, producing a transformed output after a fixed latency. The implementation uses a hardwired multiply-accumulate (MAC) structure with constant coefficients derived from shifts and additions of the input.

**Interface**
*   **Clock (`clk`)**: Positive-edge triggered system clock.
*   **Reset (`reset`)**: Active-low asynchronous reset. When low, all internal registers and the output are cleared to zero.
*   **Input (`X`)**: A signed data input with configurable bit width (`word_size_in`, default 8 bits).
*   **Output (`Y`)**: A signed data output with configurable bit width (`word_size_out`, default 20 bits). The output is registered and updates on each positive clock edge when reset is inactive.

**Functional Behavior**
1.  **Reset**: When `reset` is asserted (low), the module initializes all internal accumulator registers (`MAC_0` through `MAC_20`) and the output register `Y` to zero.
2.  **Normal Operation**: On every rising clock edge with `reset` deasserted (high):
    *   The input `X` is processed through a fixed network of scaled values. This network generates 21 constant-coefficient multiplication (SCM) terms (`SCM_0` to `SCM_20`). Each SCM term is a signed, scaled version of `X` (e.g., `X`, `-X`, `X*4`, `X*9`, `-X*19`), implemented via hardwired bit shifts and additions/subtractions.
    *   These 21 SCM terms are fed into a 21-stage pipelined accumulator chain. The chain operates as a shift register with addition: each accumulator register (`MAC_i`) takes the value of the next register in the chain (`MAC_{i+1}`) and adds its corresponding SCM term (`SCM_i`). The final stage (`MAC_20`) is simply loaded with `SCM_20`.
    *   The value of the first accumulator (`MAC_0`) is assigned to the internal signal `Y_in`.
    *   The output register `Y` is updated with the value of `Y_in`.
3.  **Latency**: After reset release, a new input sample presented at `X` will propagate through the 21-stage accumulator pipeline. The output `Y` will reflect the transformed result for that input after a fixed latency of 21 clock cycles. Once the pipeline is full, a new result is produced every clock cycle.

**Key Characteristics**
*   **Fixed Function**: The transformation coefficients are hardwired and cannot be changed via parameters.
*   **Signed Arithmetic**: All internal operations use signed (two's complement) arithmetic.
*   **Internal Bit Widths**: Intermediate signals and accumulator registers use carefully sized bit widths to prevent overflow during the specific computation, culminating in a final 20-bit result.
*   **Pipelined Structure**: The design is fully pipelined for throughput of one sample per clock cycle.
*   **Allowed Sub-modules**: The implementation is purely combinatorial and sequential logic; no instantiated sub-modules (like explicit multipliers or adders) are required or allowed—the shifts, additions, and accumulations are implemented directly with operators.

**Summary**
The module `rtlpp_10243` is a clocked, resettable linear filter or transformer with a fixed 21-tap response. It accepts a signed input sample per cycle and, after a 21-cycle latency, delivers a signed output computed as a weighted sum of the last 21 inputs, where the weights are predetermined constants.
