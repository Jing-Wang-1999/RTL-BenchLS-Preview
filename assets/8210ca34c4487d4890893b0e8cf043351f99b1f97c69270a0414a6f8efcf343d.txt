This module implements a two-input OR-AND-INVERT (O21BA) logic gate with integrated power handling.

Inputs are signals A1, A2, and an active-low B1 (B1_N). The primary output is X. The function computes: X = (A1 AND A2) OR (NOT B1_N).

Four additional power supply inputs are provided: VPWR (positive power), VGND (ground), VPB (positive bulk), and VNB (negative bulk). The output X is valid only when VPWR is high; otherwise, it is pulled to VGND.

The design uses only basic gates: AND, OR, and NOT. No sequential elements or complex sub-modules are permitted.
