# AXI register-slice project
Implement every file and module in output_contract.json. Read the unchanged original README and declaration-only interfaces. Only the selected independent design and its complete RTL closure are requested; unrelated repository components and FPGA board designs are separate designs. Rising clk edges and synchronous active-high rst apply throughout. Assert reset initially for several clocks. Transfer ready/valid signals only on a rising edge with both asserted; preserve data while stalled. Internal state encoding and buffering may differ, but externally visible data, completion and error semantics must match. Private scoring uses one complete usable upstream testbench per point; vectors inside a bench are not additional points. The original source is withheld. Curator clarifications below supplement the original documents and take precedence where explicitly correcting ambiguity.

Implement axi_register integrating axi_register_rd and axi_register_wr. This is a complete AXI register-slice IP, independently usable between any compatible AXI endpoints.

- Forward all five AXI channels without changing addresses, data, strobes, IDs, burst metadata, last flags or responses. AW/W/AR travel S->M; B/R travel M->S. Each channel is independent and must retain payload until a valid/ready handshake. Enabled user fields propagate and disabled user outputs are zero. All burst types are transported transparently.
- Each channel *_REG_TYPE independently selects 0 combinational bypass, 1 simple register (one entry, may insert bubbles), or 2 skid buffer (two entries allowing full throughput and registered backpressure). Preserve these public timing modes; arbitrary transparent wiring is not a substitute for a requested register. Defaults are AW/B/AR type1 and W/R type2.
- Reset clears the buffered valid state synchronously. Bypass channels remain direct wires and are not independently reset-gated. Empty payload values are unspecified. No transaction is created or duplicated during stalls or reset release.
- Both usable original integration benches are retained: cocotb and MyHDL. There is no independent scored submodule bench in this closure; the read and write halves are evaluated through the complete wrapper. Register-mode parameter variations remain within this single case.
