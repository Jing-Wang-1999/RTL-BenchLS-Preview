# 16-bit instruction control FSM

Implement `rtlpp_05323`. Inputs: scalar `clk`, active-high asynchronous `reset`, `N`, `Z`, `C`; `IR[15:0]`. Outputs: three3-bit register addresses `W_Adr`,`R_Adr`,`S_Adr`; scalar `adr_sel`,`s_sel`,`pc_ld`,`pc_inc`,`pc_sel`,`ir_ld`,`mw_en`,`rw_en`; `alu_op[3:0]`; `status[7:0]`. Output logic is combinational in the current state and live IR; IR is not captured internally. Internal state and stored flags P=(PN,PZ,PC) update on rising edges; reset sets state RESET and flags000.

Default state parameters: RESET0,FETCH1,DECODE2,ADD3,SUB4,CMP5,MOV6,INC7,DEC8,SHL9,SHR10,LD11,STO12,LDI13,JE14,JNE15,JC16,JMP17,HALT18,ILLEGAL_OP31. RESET advances FETCH, FETCH advances DECODE. DECODE selects by live IR[15:9]:70 ADD,71 SUB,72 CMP,73 MOV,74 SHL,75 SHR,76 INC,77 DEC,78 LD,79 STO,7A LDI,7B HALT,7C JE,7D JNE,7E JC,7F JMP (hex); other opcode enters ILLEGAL_OP. Every instruction execution state returns FETCH except HALT/ILLEGAL_OP which stay forever until reset.

Let D=IR[8:6],R=IR[5:3],S=IR[2:0]. All control outputs are zero except those listed in the table. Addresses are as shown; alu_op is hexadecimal. For operation rows status concatenates OLD stored flags P in bits7:5 with listed low5 bits. Flag capture occurs at the following rising edge, not combinationally from new N/Z/C. Flags hold in states not marked capture, except RESET,HALT and ILLEGAL_OP which clear them at each edge.

All binary instruction inputs have defined decode behavior. State encodings19–30 cannot be reached after reset with default parameters; no default assignment is specified for a corrupted internal state. Inputs need not be held stable outside a consumer's own protocol: live IR changes combinational addresses while executing a state. No instruction datapath or arithmetic result is implemented here.
