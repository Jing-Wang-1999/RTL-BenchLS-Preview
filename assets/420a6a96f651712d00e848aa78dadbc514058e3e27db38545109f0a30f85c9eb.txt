# [rv_core_ibex] Reintroduce assert that PC does not advance when Ibex is disabled

An assert to add this was merged in this PR: https://github.com/lowRISC/opentitan/pull/15101
However, this caused multiple failures in the top level tests, which are tracked in this issue: https://github.com/lowRISC/opentitan/issues/15148
@engdoreis has created a PR to remove the assert temporarily with this PR: https://github.com/lowRISC/opentitan/pull/15218 (previously https://github.com/lowRISC/opentitan/pull/15216)
This issue is here to track that we need to reintroduce this assert when we figure out how to connect up the enable signal properly.
