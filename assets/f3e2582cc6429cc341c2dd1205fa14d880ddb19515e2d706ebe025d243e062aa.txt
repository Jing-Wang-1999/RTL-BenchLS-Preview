# `mg_02274`

This module has 3-bit input `RX_CLK_COR_CNT`, clock input `USER_CLK`, and registered one-bit output `CHANNEL_BOND_LOAD`. Parameter `CHANNEL_BOND_LOAD_CODE` is 3 bits and defaults to `3'b101` (decimal 5). On every rising edge of `USER_CLK`, `CHANNEL_BOND_LOAD` captures one when `RX_CLK_COR_CNT` equals `CHANNEL_BOND_LOAD_CODE` and captures zero otherwise. There is no reset, enable, or hold condition: the comparison is sampled on every rising edge. The initial output value is unspecified until the first rising edge. The defined `DLY` macro is unused and introduces no delay.
