# Buffered 8-bit SPI master

Implement `tiny_spi` with the following interface and declared parameters. Qualification uses defaults only: BAUD_WIDTH=8, BAUD_DIV=0, SPI_MODE=0, BC_WIDTH=3, DIV_WIDTH=(BAUD_DIV ? $clog2(BAUD_DIV/2-1) : BAUD_WIDTH); state constants IDLE=0, PHASE1=1, PHASE2=2. External chip select is not generated.

| Direction | Ports | Width |
|---|---|---:|
| Input | rst_i, clk_i, stb_i, we_i, MISO | 1 each |
| Input | dat_i | 32 |
| Input | adr_i | 3 |
| Output | dat_o | 32 |
| Output | int_o, MOSI, SCLK | 1 each |

All storage changes at rising clk_i. Active-high rst_i asynchronously resets the transfer state to IDLE and the pending-buffer flag to zero. It does **not** reset shift data, buffer data, baud configuration, interrupt enables, control configuration, or counters. These retain their ordinary clocked update behavior while reset is asserted; do not introduce reset-to-zero values for them. Configure baud and IRQ enables before relying on timed transfers/interrupts. This initialization advice does not remove any input histories from the equivalence check.

The memory interface has zero wait states: every edge with stb_i && we_i is a write, regardless of address stability across preceding edges. adr_i is a register index, not a byte address. Reads are combinational and independent of stb_i/we_i. At index0 dat_o[7:0] is the shift register; at1 it is the combined transmit/receive buffer; at2 bits1:0 are {transfer_ready, transfer_empty}. Other bits and addresses return zero. Writes at1 replace the 8-bit buffer and set its pending flag; at2 set the two IRQ enables from dat_i[1:0]; at3 set the stored {CPOL,CPHA} from dat_i[1:0]; at4 set the divider reload from dat_i[7:0]. Other writes do nothing. Stored CPOL/CPHA are ignored in the default fixed mode0. transfer_ready is the inverse pending flag; transfer_empty means IDLE. int_o is the OR of each status bit AND its matching enable. MOSI always exposes bit7 of the shift register, even when idle.

Use the following cycle recurrence to specify exact transfer timing. Let C be the 8-bit half-period counter, B the 3-bit bit counter, Q the 8-bit shift register, U the 8-bit buffer, P its pending flag, and D the baud reload. All expressions below read pre-edge values. Default next C=D, next B=B, load=0, shift=0. SCLK is a combinational function of the current state. State progression and C/B updates happen at each clk_i edge, independently of configuration or data writes at that edge.

| State | SCLK in fixed mode0 | Next state and controls |
|---|---:|---|
| IDLE | 0 | If P: B'=7, load=1, next PHASE2; else remain IDLE. |
| PHASE2 | 0 | If C=0: next PHASE1, C'=D. Else C'=C-1, remain PHASE2. |
| PHASE1 | 1 | If C!=0: C'=C-1 and remain. If C=0: shift=1, B'=B-1 modulo8, C'=D; when B!=0 go PHASE2; when B=0 and P=0 go IDLE; when B=0 and P=1 set B'=7, load=1 and go PHASE2. |

Thus each half-phase lasts D+1 system clocks. At a load edge Q'=U, with priority over shifting; otherwise a shift edge gives Q'={Q[6:0],MISO}. If no buffer write occurs, a load puts old Q into U when the pre-edge state is IDLE, or {old Q[6:0],MISO} into U during a chained transfer. A buffer write has priority over this receive capture and uses dat_i[7:0]. A buffer write also has priority over clearing P on a load. Consequently a write coincident with loading transmits the *old* buffer and leaves the newly written byte pending. A write while P is already1 overwrites that pending byte; there is no overflow protection. With no queued next byte, the final received byte remains in Q, not U.

Changing the divider during a transfer affects the next counter reload; it does not immediately replace the live counter. For nondefault fixed SPI modes the PHASE2/PHASE1 clock levels are CPOL XOR CPHA and its inverse; IDLE is CPOL. Parameter sweeps are outside this release. Preserve ordinary unsigned truncation and pre-edge priority. Do not add chip select, synchronization, an acknowledge port, default register initialization, or backpressure.
