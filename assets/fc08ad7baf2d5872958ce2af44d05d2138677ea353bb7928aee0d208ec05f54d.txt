# Standard JPEG luminance AC prefix decoder

Implement combinational `jpeg_dht_std_y_ac`. Input `lookup_input_i[15:0]` is a lookahead word with the next code bit at bit15. Outputs are `lookup_width_o[4:0]` and `lookup_value_o[7:0]`. There is no clock, reset, state or latency. Match the most significant W input bits to a table code, ignoring the remaining16-W low bits; produce W and the listed8-bit value. Codes are prefix-free. An unmatched input produces width0 and value0. The table defines the complete binary-input behavior, including end-of-block value00 and zero-run valueF0. Values are run/size tokens; this block does not consume amplitude bits or track blocks.
