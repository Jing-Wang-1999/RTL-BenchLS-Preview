# mg_03551

This combinational 16-bit ALU has unsigned inputs `x[15:0]` and `y[15:0]`, one-bit controls `zx`, `nx`, `zy`, `ny`, `f`, and `no`, output `out[15:0]`, and one-bit flags `zr` and `ng`.

First set the working X operand to zero when `zx=1`, otherwise to `x`, then bitwise complement it when `nx=1`. Independently set the working Y operand to zero when `zy=1`, otherwise to `y`, then bitwise complement it when `ny=1`. If `f=1`, form the low 16 bits of their sum; if `f=0`, form their bitwise AND. Bitwise complement that result when `no=1`. Drive the final value to `out`; set `zr=1` exactly when it is `16'h0000`; and set `ng` to its most significant bit `out[15]`. There is no clock, reset, state, parameter, or submodule.
