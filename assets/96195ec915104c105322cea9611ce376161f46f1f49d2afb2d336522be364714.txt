# AXI-Lite clock-domain crossing project
Implement every file and module in output_contract.json. Read the unchanged original README and declaration-only interfaces. Only the selected independent design and its complete RTL closure are requested; unrelated repository components and FPGA board designs are separate designs. Both clock domains use rising edges and their own synchronous active-high reset. Assert both resets initially for several local clock cycles. Transfer ready/valid signals only on a rising edge with both asserted; preserve data while stalled. Internal state encoding and buffering may differ, but externally visible data, completion and error semantics must match. Private scoring uses one complete usable upstream testbench per point; vectors inside a bench are not additional points. The original source is withheld. Curator clarifications below supplement the original documents and take precedence where explicitly correcting ambiguity.

Implement axil_cdc integrating axil_cdc_rd and axil_cdc_wr. The README child names accidentally omit the l; the actual required children are axil_cdc_rd/wr.

- Bridge AXI-Lite S and M interfaces with identical widths across unrelated s_clk and m_clk. There is no frequency/phase relationship. s_rst and m_rst are synchronous active-high resets in their respective domains; assert both before traffic and allow synchronization after release. Reset in the middle of a transaction is outside the scored envelope.
- Retain source AW, W and AR requests until accepted. AW and W may arrive independently; issue one destination write only once both are captured. Keep destination payload stable until its corresponding handshake. Transfer the B response back and retain it until source BREADY. Capture one read request, transfer AR to the destination, then return RDATA/RRESP stably until source RREADY. Reads and writes have independent state and may overlap.
- Transfer every accepted address, protection field, write byte strobe and data byte without loss, duplication or reordering. Synchronize control handshakes across clock domains while holding multibit payload stable; directly sampling a changing bus across domains is not a valid implementation. Only one outstanding transaction per direction is required, and admission may stall until response consumption.
- Both original integration benches (cocotb and MyHDL) are retained with independent clocks and traffic stalls. The two RTL halves are not counted separately. Clock ratios and resets are configurations of this one project.
