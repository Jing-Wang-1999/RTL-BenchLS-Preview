**Module Specification: SDP_Y_INP_mgc_out_stdreg_wait_v1**

This module implements a simple pass-through register interface with handshaking signals for data flow control. It has two configurable parameters: a resource identifier (rscid) and data width.

**Inputs:**
- `ld`: Load signal indicating data is ready to be loaded
- `d`: Input data bus of configurable width
- `vz`: Valid signal from downstream indicating readiness to accept data

**Outputs:**
- `vd`: Valid signal passed through
