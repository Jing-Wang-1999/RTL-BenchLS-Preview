# `ecc_raw_data_64bit`

The module extracts 64 data bits from input `c[71:0]`. The extracted vector, from output bit 63 down to 0, is formed from input bits 70–64, 62–32, 30–16, 14–8, 6–4, and 2 in descending order; bits 71, 63, 31, 15, 7, 3, 1, and 0 are omitted.

Parameter `REGISTER` defaults to 0. When `REGISTER` is 0, output `d[63:0]` follows the extracted vector combinationally; `clk` and `rst` have no effect. When `REGISTER` is nonzero, `d` captures the extracted vector on each rising edge of `clk`. In registered mode, asserting active-high `rst` asynchronously clears `d` to zero and has priority over capture. There is no enable: every rising clock edge captures when reset is inactive.
