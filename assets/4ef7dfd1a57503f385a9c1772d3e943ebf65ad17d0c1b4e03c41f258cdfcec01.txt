# Amiga CIA8520 replacement project
Implement cia (the physical-pin integration wrapper), cia8520 and its six component modules. Read the unchanged cia/README and CIA hardware specification. This is the independently usable CIA chip replacement, not the entire Amiga chipset.

- Implement two8-bit bidirectional GPIO ports, two16-bit interval timers,24-bit TOD counter/alarm, serial shift input/output, FLAG/PC handshake and interrupt/control registers. Register indices0..15 are PRA,PRB,DDRA,DDRB,TA low/high,TB low/high,TOD low/mid/high,extension,SDR,ICR,CRA,CRB. Additional original module documentation is exported as prose comments. Respect CPU read/write side effects, timer latch/force-load/one-shot behavior, TOD latching and serial clock/handshake operation in the original hardware specification.
- Physical nRES and nCS are active-low, RW=1 reads. Drive DB only when selected for read; otherwise high impedance. DDRA/DDRB bits select driven output vs released input pins. SP/CNT output enables follow serial output mode; external pullups are part of the board/test environment. The core uses both ECLK edges as documented rather than assuming a single edge; timers and control strobes must follow that dual-phase contract.
- Reset clears DDR/control/interrupt masks and reloads timers to0xffff; GPIO input reads observe resolved pins. ICR source flags occupy bits0..4, bit7 summarizes enabled pending interrupts; writing bit7 selects set-mask vs clear-mask for indicated source bits. Reading ICR acknowledges flags according to the pinned two-phase implementation. Control bit4 is a force-load strobe, not a persistent stored flag. Preserve optional extension register behavior; its default is compatibility mode.
- This historical native bench observes timer/serial submodule signals through cia.ciai. Keep the explicitly listed observer names in specification/native_observers.txt: timer count, run pipeline stage, force-load, pulse/underflow and port output, plus serial pin signals. They are public requirements of the retained native harness. Implement their natural timer/serial meanings; arbitrary hidden state names elsewhere are free.
- One complete upstream bench exercises both CIA instances and their interactions. Its86 diagnostic OK messages are completion evidence for this one point, not86 testpoints. The single weak read comparison is strengthened from != to !== so unknown read data cannot silently pass; all original stimuli/expected values and original unmodified bench are retained. Pass requires normal finish, exactly86 OK reports and no read error/ERROR/FATAL/timeout.

Simulation I/O, delays, force/release, final blocks and external includes are forbidden. Constant elaboration functions ($clog2, $unsigned, $signed, $bits) and synthesizable storage initialization are permitted. Save all RTL under the exact required paths; only those files are collected.
