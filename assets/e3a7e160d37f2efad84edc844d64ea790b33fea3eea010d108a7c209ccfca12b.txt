# `mg_03579`

This stateless combinational module compares unsigned 32-bit inputs `I_dataA` and `I_dataB`, with signed interpretation only for the signed operations. Input `I_branchOp[2:0]` selects output `O_doBranch`: 0 selects equality, 1 inequality, 2 unsigned greater-than, 3 unsigned greater-than-or-equal, 4 signed greater-than, 5 signed greater-than-or-equal, 6 passes `I_Cin`, and 7 produces one. All eight selector values are covered, so no default or retained state is required. There is no clock, reset, storage, or latency.
