# `mg_07248`

`mg_07248` is a 64-bit enabled register with clock `clk`, active-high load input `ld`, data input `d[63:0]`, and registered output `q[63:0]`. On each rising edge of `clk`, `q` captures `d` when `ld` is high and otherwise holds its previous value. There is no reset. In normal compilation, the initial value of `q` is unspecified. When the `RANDOM_INIT` macro is defined, a simulation-specific initial block invokes `$random_init("q")`; this does not change the clocked update rule.
