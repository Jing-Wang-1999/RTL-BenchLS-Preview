# cntr_modulus

Parameters are `WIDTH=16` and `MOD_VAL=50223`. Inputs are scalar `clk`, `ena`, active-high asynchronous `rst`, `sload`, `sclear`, and `sdata[WIDTH-1:0]`; output register is `q[WIDTH-1:0]`. Reset immediately clears q. On each rising edge with reset low, `ena=0` holds. With ena high, synchronous clear has priority, then synchronous load, then count: if old q equals `MOD_VAL-1`, load zero; otherwise add one modulo `2**WIDTH`. No range correction occurs for loaded/out-of-range q, and valid configurations require a positive representable MOD_VAL. No submodule exists.
