The module `mg_10069` is a simple arbiter implemented as a finite state machine (FSM). It is designed to manage two request signals and grant access to one of them based on a priority scheme. The module operates with the following inputs and outputs:

### Inputs:
1. **clock**: A clock signal that synchronizes the state transitions of the FSM.
2. **reset**: A signal that initializes or resets the FSM to its default state.
3. **req_0**: A request signal from the first requester.
4. **req_1**: A request signal from the second requester.

### Outputs:
1. **gnt_0**: A grant signal indicating that the first requester has been granted access.
2. **gnt_1**: A grant signal indicating that the second requester has been granted access.

### Internal States:
The FSM has three states, each represented by a 3-bit code:
- **IDLE**: The default state where no requests are granted.
- **GNT0**: The state where the first requester (`req_0`) is granted access.
- **GNT1**: The state where the second requester (`req_1`) is granted access.

### Behavior:
- **IDLE State**: The FSM starts in the IDLE state. If `req_0` is asserted (i.e., becomes high), the FSM transitions to the GNT0 state, granting access to the first requester. If `req_1` is asserted while in the IDLE state and `req_0` is not, the FSM transitions to the GNT1 state, granting access to the second requester. If neither request is asserted, the FSM remains in the IDLE state.

- **GNT0 State**: In this state, the FSM continues to grant access to the first requester as long as `req_0` remains asserted. If `req_0` is deasserted, the FSM transitions back to the IDLE state.

- **GNT1 State**: In this state, the FSM continues to grant access to the second requester as long as `req_1` remains asserted. If `req_1` is deasserted, the FSM transitions back to the IDLE state.

### Reset Behavior:
When the reset signal is asserted, the FSM is initialized to the IDLE state, ensuring that no grants are active.

### Output Logic:
- In the IDLE state, both `gnt_0` and `gnt_1` are deasserted, indicating no active grants.
- In the GNT0 state, `gnt_0` is asserted
