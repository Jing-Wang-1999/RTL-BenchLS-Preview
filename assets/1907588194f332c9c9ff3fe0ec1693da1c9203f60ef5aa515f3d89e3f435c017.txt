# Module Specification: mg_06631

## Purpose
This module implements a framebuffer coordinate counter that generates sequential x-y coordinates for accessing a 2D framebuffer memory.

## Parameters
- **FB_X_MAX**: Maximum horizontal resolution (default: 1280 pixels)
- **FB_Y_MAX**: Maximum vertical resolution (default: 1024 lines)

## Inputs
- **clk**: Clock signal for synchronous operation
- **pixel_count**: 12-bit pixel count input (not used in current implementation)
- **line_count**: 12-bit line count input (not used in current implementation)
- **fb_reset**: Synchronous reset signal to initialize coordinates to (0,0)
- **fb_enable**: Enable signal to advance the coordinate counter

- **x**: 12-bit horizontal coordinate (0 to FB_X_MAX-1)
