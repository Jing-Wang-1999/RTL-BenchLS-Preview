# HLS_fp32_sub_core_chn_a_rsci_chn_a_wait_dp

Inputs are `nvdla_core_clk`, active-low asynchronous `nvdla_core_rstn`, `chn_a_rsci_oswt`, `chn_a_rsci_biwt`, `chn_a_rsci_bdwt`, and `chn_a_rsci_d[31:0]`. Outputs are `chn_a_rsci_bawt`, `chn_a_rsci_wen_comp`, and `chn_a_rsci_d_mxwt[31:0]`.

Let internal valid/hold flag be `bcwt`. Combinationally, `bawt=biwt|bcwt`, `wen_comp=~oswt|bawt`, and data output selects buffered data when bcwt is one and live input otherwise. Reset clears bcwt and the buffer. Each rising edge otherwise sets `bcwt=(bcwt|biwt)&~bdwt` and stores the current mux output. Thus bdwt has clear priority and buffered data remains selected while bcwt is set. The only helper is an internal function implementing the mux.
