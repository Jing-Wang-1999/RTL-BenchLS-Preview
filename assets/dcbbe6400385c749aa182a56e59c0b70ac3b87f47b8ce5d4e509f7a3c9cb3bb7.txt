# `mg_02619`

This stateless combinational byte selector has 64-bit input `inword`, three-bit selector `sel`, and eight-bit output `outbyte`. Selector values 0, 1, 2, 3, 4, 5, 6, and 7 choose slices `[7:0]`, `[15:8]`, `[23:16]`, `[31:24]`, `[39:32]`, `[47:40]`, `[55:48]`, and `[63:56]`, respectively. A default branch assigns all unknown bits, which is relevant only when the selector contains non-binary simulation values. There is no clock, reset, state, or submodule.
