# `rtlpp_00214`

This module implements sixteen 32-bit storage entries, two independent asynchronous read ports, and one synchronous write port. Inputs are `clk`, asynchronous active-low `rst_n`, `write_enable`, `write_select[3:0]`, `write_value[31:0]`, `read_a_enable`, `read_a_select[3:0]`, `read_b_enable`, and `read_b_select[3:0]`. Outputs `read_a_value[31:0]` and `read_b_value[31:0]` are combinational.

Asserting `rst_n` low asynchronously clears all sixteen physical entries. On a rising edge of `clk` while reset is inactive, `write_enable` writes `write_value` to the selected entry; otherwise all entries hold. Writes to physical entry zero are allowed, but both read ports always return zero for address zero, hiding its stored value.

Each enabled read port returns zero for address zero or the current physical entry for addresses 1–15. A disabled read port drives all 32 output bits to high impedance. Both ports operate independently. For a simultaneous rising-edge write and enabled read of the same nonzero address, the read initially reflects the old stored value and changes to the new value after the nonblocking write update in the same simulation time step. There is no registered read latency.
