# addsub

`addsub` has parameters `WIDTH = 16` and `METHOD = 1`, one-bit input `sub`, unsigned `WIDTH`-bit inputs `a` and `b`, and unsigned `WIDTH+1`-bit output `o`.

When `METHOD=0`, `o` is `a+b` when `sub=0` and `a-b` when `sub=1`, using Verilog unsigned expression sizing and assignment into `WIDTH+1` bits. When `METHOD=1`, the carry-chain implementation produces the same selected addition or two's-complement subtraction result in `o`. Other `METHOD` values instantiate no driver for `o` and are unsupported. The module is combinational and has no clock, reset, state, or submodule.
