# Specification

`mg_00095` is a combinational hexadecimal decoder with `HEXnumber[3:0]` and active-low `Segments[7:0]`. Values 0 through F map respectively to C0,F9,A4,B0,99,92,82,F8,80,90,88,83,C6,A1,86,8E hexadecimal. Every 4-bit value is covered; the syntactic default 00 is unreachable for known binary input and would turn all active-low segments on. No clock, reset, parameter, or state exists.
