# origen_079863

This combinational address decoder has parameters `ADDR_WIDTH = 32` and `NUM_DEVICES = 8`, input `virtual_addr[ADDR_WIDTH-1:0]`, output `phys_addr` of the same width, and `device_en[NUM_DEVICES-1:0]`. The intended supported configuration requires `ADDR_WIDTH >= 20` and `NUM_DEVICES >= 6`.

Inclusive 64-KiB ranges 0x00000000–0x0000FFFF through 0x00050000–0x0005FFFF select device bits 0 through 5 respectively. ROM (range zero) passes virtual_addr as phys_addr; every other range subtracts its low address, yielding an offset 0–0xFFFF. Outside all ranges both outputs are zero. At most one device bit asserts. There is no clock, reset, state, or submodule.
