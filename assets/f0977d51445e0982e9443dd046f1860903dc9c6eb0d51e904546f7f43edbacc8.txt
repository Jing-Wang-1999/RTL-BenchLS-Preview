# OBUF

## Interface

`OBUF` has scalar input `I` and scalar output `O`. Parameters are `CAPACITANCE="DONT_CARE"`, integer `DRIVE=12`, `IOSTANDARD="DEFAULT"`, and `SLEW="SLOW"`; when `XIL_TIMING` is defined, `LOC=" UNPLACED"` is also present.

## Behavior

The internal global tristate control is tied low. A low-controlled tristate buffer therefore continuously drives `O` with `I`; `O` is never intentionally high impedance. The parameters carry implementation attributes and do not change this RTL logic. The module is combinational and has no clock, reset, state, or latency.
