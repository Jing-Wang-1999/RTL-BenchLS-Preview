# mc_timing: default-configuration specification

Build the timing/control sequencer of the OpenCores Wishbone memory controller. It generates SDRAM, burst SRAM, asynchronous chip-select memory and synchronous chip-select memory commands, control handshakes, read-valid and byte-packing strobes. It does not contain a memory data path, address decoder, bank/row table or refresh scheduler; these are connected through the explicit public ports. All ports are scalar except csc/tms32, cs8 and page_size11. The complete interface is below. In particular par_err and any_bank_open are unused inputs in this module, not hidden error checks.

Use the supplied mc_defines.v defaults: power-on delay enabled with250, initialization refresh count2, memory types SDRAM0/SRAM1/ACS2/SCS3; bus widths8=0/16=1/32=2. No extra defines. The exposed state parameters retain their declared one-hot66-bit values (POR is bit0, IDLE bit1, through SCS_ERR bit65). State encoding changes are outside this case. Other memory type codes do not start a memory sequence. bus-width codes2 and3 follow the neither-8-nor-16 path. csc[3:1] selects memory type, csc[5:4] bus width, csc[10] keep-row-open K; other csc bits are unused. cs_a is OR of cs. single_write=tms[9] OR tms[2:0]==0, using live tms rather than the timing override below.

Clock/reset contract: clk is the controller clock; mc_clk is a separate public memory-clock input and must not be tied to clk. Its rising edge releases the first reset synchronizer stage after asynchronous rst assertion. A rising clk then releases the second stage from the first. An internal half-rate phase M resets asynchronously to0 from that second stage and otherwise toggles every clk. Commands/timers qualified by !M use its old value. No relative phase/frequency constraint is added to formal inputs. rst is active-high asynchronous for the state and the explicitly reset registers below; several pipelines and timer2 deliberately lack reset. The source's #1 assignments are simulation propagation annotations, not extra hardware cycles. Startup is reset-first; no declaration-only initialization is promised. POR waits for the registered timer-done flag before entering IDLE.

Define command4 as {cs_en,ras_,cas_,we_}: NOP=0111, PC=1010, ACT=1011, WR=1100, RD=1101, BT=1110, ARFR=1001, LMR=1000, XRD=1111, XWR=1110. These are complete command values; cs_en is the command-valid bit, not an inverted chip select. The command bus is combinational command4 for reads/non-write cycles and the two-clk-delayed command4 for wr_cycle=1. Command delay stages reset to NOP. cmd_a10 is the combinational address10 selection described in the state table, not delayed with command4. Default a10 is auto-precharge A, where A captures (timing_override[2:0]==0 AND !K) whenever burst-load is asserted, reset0.

Registered control and output timing (all listed updates are simultaneous from old values on clk; an omitted reset means unspecified until established by the update):

| State/output | Update and reset |
|---|---|
| state | rst=>POR; otherwise next state every clk |
| mc_c_oe | rst=>0; otherwise control mc_c_oe_d (normally1) |
| cs_le, delay cs_le_r1, delay cs_le_r | Three consecutive registers of combinational cs_le_d; no reset |
| lookup_ready1,lookup_ready2 | reset0; next=old cs_le AND wb_cyc_i AND wb_stb_i; next2=old lookup_ready1 AND same live bus controls |
| lmr_ack | register lmr_ack_d, no reset |
| rfr_ack | reset0; register rfr_ack_d |
| oe_ | reset1; otherwise inverse of oe_d |
| data_oe | reset0; otherwise data_oe_d for non-write, or old second delay of data_oe_d for wr_cycle. Its two preceding delay stages also reset0 |
| command_seen1,command_seen2 | reset0; only when !M, sample command4[3], then old seen1 respectively; hold on M |
| cke_r,cke_,cke_o_r1,cke_o_r2,cke_o_del | Unreset pipeline: cke_r'=cke_d; cke_'=old cke_r AND cke_rd; the last three successively delay cke_ |
| wb_wait_r2,wb_wait_r | Unreset consecutive samples of wb_wait |
| wr_cycle | reset0; set-control has priority over clear-control; otherwise hold |
| wb_cycle | reset0; set-control has priority, else clear if !wb_cyc_i OR not_mem_cyc, else hold |
| no_wb_cycle | reset0; otherwise !wb_read_go AND !wb_write_go |
| mem_ack_r | reset0; sample public mem_ack every clk |
| ack_count | reset0; else if old no_wb_cycle clear; else add1 for dv&&!mem_ack_s, subtract1 for !dv&&mem_ack_s; four-bit wrapping; simultaneous dv/ack holds |
| toggle C | Unreset register of Cnext (normally0) |
| susp_req_r,resume_req_r | reset0; sample respective public inputs |
| suspended | reset0; register suspended_d |
| susp_sel | reset0; set-control priority over clear-control, otherwise retain |
| mc_adv_r1,mc_adv_r | reset0; sample mc_adv, then old mc_adv_r1 only on !M |
| dv_r | reset0; sample dv |
| pack_le0/1/2 | Unreset samples of respective combinational packing controls |
| cmd_a10_r | Unreset sample of cmd_a10 |
| wb_write_go_r | Unreset sample of wb_write_go |
| wb_stb_first | reset0; clear on mem_ack; else set on wb_first&&wb_stb_i; otherwise hold |

mem_ack_s=(ack_count!=0) AND !wb_wait AND !mem_ack_r AND wb_read_go AND !(wb_we_i&&wb_stb_i). Public mem_ack=(state-control mem_ack_d OR mem_ack_s) AND (wb_read_go OR wb_write_go). err is the combinational err_d; par_err does not contribute. dv is the combinational read-data-valid control, including the burst patterns below. row_sel, next_adr, bank_set/clr/clr_all, mc_adsc, mc_adv, mc_bg, init_ack and cs_le_d are also combinational state controls. Their registered/pipelined consumers are separate from these public immediate outputs.

Timing override T equals all32 ones if rfr_ack_d OR registered rfr_ack OR susp_sel OR !mc_c_oe; otherwise T=tms. Timing field changes are used live. Main timer is8-bit, asynchronously reset250. At every clk take the first asserted load in this exact priority list: WR2=T[15:12]; RDZ=T[11:8]; RDV=T[7:0]; WR=(T[16:15]+T[23:20]) modulo16; RP=T[23:20]; RCD=T[19:17]; CL=T[5:4]; RFC=T[27:24]; AVAV=3; XSR=7. Without load, decrement by1 iff nonzero AND !M; otherwise hold. Main done D resets0 and otherwise samples old timer==0 every clk, including load cycles. Loads therefore do not instantly clear D.

Second timer is9-bit with no reset. Load priority is CSTO=T[24:16], SRDV=4, WPW=T[15:12], WD=2*T[19:16], WWD=T[25:20], RDZ=2*T[11:8]+1, RDV=2*T[7:0]+1. Without load decrement each clk while nonzero. Its registered done D2 resets0; otherwise it is old timer2==0 AND no CSTO/WPW/WD/WWD/RDZ/RDV load. SRDV load is deliberately absent from the done inhibit. WDzero means live T[19:16]==0.

The four-bit initialization-refresh counter loads2 when IRload, otherwise decrements modulo16 when IRdec. Its unreset done flag IDone registers old count==0. The11-bit burst counter loads4 when Bload4, else Bload loads Bvalue, else decrements on (wr_cycle?mem_ack_d:dv), with wrap and no independent reset. Bvalue is1/2/4/8/page_size for T[2:0]=0/1/2/3/7; for reserved codes4/5/6 the last Bvalue is retained by the incomplete selector. No invented reserved-code default is added. Bactive=(burst_count!=0 AND T[2:0]!=0). Bread is an unreset one-clk sample of burst_count!=0. The full-page flag captures T[2:0]==7 on Bload, reset0, but has no functional use in subsequent logic.

State control notation: every table row begins with defaults next=state; command=NOP; a10=A; cke_d=cke_rd=1; mc_c_oe_d=1; every other combinational control=0 (including Cnext=0). Assignments in a row override defaults in order. Unmentioned controls stay at their defaults rather than retaining the previous state's values. Loads refer to the timer names above; S1/S2 are command_seen1/2; W is wb_wait; Wr is its two-stage delayed wb_wait_r; R/WG mean wb_read_go/wb_write_go; cycle means registered wb_cycle; write_cycle means wr_cycle; RACK means registered rfr_ack; LEold means the third cs_le register cs_le_r. State transition conditions are evaluated from the old registers and live inputs. Outputs do not wait for state transition unless explicitly stated. Set/clear labels refer to the register control rules above.

| State | Combinational controls and next state |
|---|---|
| POR | If D, go IDLE |
| IDLE | cs_le_d=wb_stb_first; Bload; clear wr_cycle. For SCS load CSTO; for SRAM load SRDV. Apply priority dispatcher below |
| IDLE_T | a10=cmd_a10_r. If D&&cycle&&!W assert cs_le_d. If D go IDLE |
| IDLE_T2 | If D2&&(!W OR !cycle), cs_le_d=cycle; if LEold OR !cycle go IDLE |
| SCS_RD | XRD, oe_d=1, load RDV. If mc_ack go SCS_RD1, else if D2 go SCS_ERR |
| SCS_RD1 | XRD, oe_d=1. If D, assert mem_ack_d, load RDZ and go SCS_RD2 |
| SCS_RD2 | Load RDZ; go IDLE_T |
| SCS_WR | XWR,data_oe_d=1,load WR2. If mc_ack go SCS_WR1, else if D2 go SCS_ERR |
| SCS_WR1 | data_oe_d=1. If D assert mem_ack_d and go IDLE_T; otherwise XWR |
| SCS_ERR | mem_ack_d=1,err_d=1; go IDLE_T2 |
| SRAM_RD | XRD,oe_d=1,mc_adsc=1,load SRDV,Bload4. If S1 go SRAM_RD0 |
| SRAM_RD0 | mc_adv=1,oe_d=1. If D2 set mc_adv=!W and go SRAM_RD1 |
| SRAM_RD1 | If delayed mc_adv_r then dv=!dv_r. mc_adv=!W. If !Bactive OR !R go SRAM_RD2, otherwise oe_d=1 |
| SRAM_RD2 | If ack_count==0&&R go SRAM_RD3; else if !R assert mc_adsc and go SRAM_RD4 |
| SRAM_RD3 | If !R assert mc_adsc and go SRAM_RD4; else if !W assert cs_le_d and go SRAM_RD |
| SRAM_RD4 | cs_le_d=cycle,mc_adsc=1; go IDLE |
| SRAM_WR | XWR,mc_adsc=1,data_oe_d=1. If S1: W=>SRAM_WR0; else !WG=>SRAM_RD4 with mc_adsc=1; else mem_ack_d=!mem_ack_r |
| SRAM_WR0 | If W hold; else if !WG assert mc_adsc and go SRAM_RD4; else data_oe_d=1 and go SRAM_WR |
| ACS_RD | XRD,oe_d=1,load timer2 RDV; go ACS_RD1 |
| ACS_RD1 | XRD,oe_d=1. When D2, assert next_adr for8/16-bit bus; go ACS_RD_8_1 for8, ACS_RD_8_5 for16, otherwise ACS_RD2A |
| ACS_RD_8_1 | pack_le0_d=1,XRD,oe_d=1,load timer2 RDV; go ACS_RD_8_2 |
| ACS_RD_8_2 | XRD,oe_d=1; if D2 assert next_adr and go ACS_RD_8_3 |
| ACS_RD_8_3 | pack_le1_d=1,XRD,oe_d=1,load timer2 RDV; go ACS_RD_8_4 |
| ACS_RD_8_4 | XRD,oe_d=1; if D2 assert next_adr and go ACS_RD_8_5 |
| ACS_RD_8_5 | pack_le2_d for8-bit, pack_le0_d for16-bit; XRD,oe_d=1,load timer2 RDV; go ACS_RD_8_6 |
| ACS_RD_8_6 | XRD,oe_d=1; if D2 go ACS_RD2 |
| ACS_RD2A | XRD,oe_d=1; go ACS_RD2 |
| ACS_RD2 | XRD; go ACS_RD3 |
| ACS_RD3 | mem_ack_d=1,load timer2 RDZ; go IDLE_T2 |
| ACS_WR | XWR,data_oe_d=1,load WPW; go ACS_WR1 |
| ACS_WR1 | If !S1 load WPW. XWR,data_oe_d=1. If D2 load WD and go ACS_WR2 |
| ACS_WR2 | Go ACS_WR3; unless WDzero, command=XRD and data_oe_d=1 |
| ACS_WR3 | If D2 go ACS_WR4; otherwise XRD |
| ACS_WR4 | load WWD,mem_ack_d=1; go IDLE_T2 |
| PRECHARGE | PC,load RP. If RACK: rfr_ack_d=1,a10=1,bank_clr_all=1; otherwise a10=0,bank_clr=1. If S1 go PRECHARGE_W |
| PRECHARGE_W | rfr_ack_d=RACK; if D go REFR when RACK, otherwise ACTIVATE |
| ACTIVATE | If !Wr assert row_sel,load RCD,command=ACT. Independently if S1 go ACTIVATE_W |
| ACTIVATE_W | row_sel=1; set wr_cycle if WG OR (wb_we_i&&wb_stb_i); bank_set=K. If D: WG=>mem_ack_d=!mem_ack_r,a10=A OR(single_write&&!K), next SD_WR; otherwise if !Wr go SD_RD |
| SD_RD_WR | Set wr_cycle if WG OR (wb_we_i&&wb_stb_i). If WG&&!W: data_oe_d=1,mem_ack_d=!mem_ack_r,a10=A OR(single_write&&!K),next SD_WR. Else if !W and (!K OR !Wr), go SD_RD |
| SD_WR | data_oe_d=1,load WR,Cnext=!C,command=WR,a10=A OR(single_write&&!K). cke_d=!W if !C&&cycle&&Bactive else old cke_r. If S1: mem_ack_d=!mem_ack_r&&WG&&!W&&cycle&&Bactive; next IDLE_T if cycle&&!Bactive, else SD_WR_W if WG, else BT if Bactive&&!single_write, else BT_W if !A, else IDLE_T |
| SD_WR_W | load WR,Cnext=!C; WR only when single_write&&cycle. a10=A OR(single_write&&!K),data_oe_d=1; mem_ack_d=!mem_ack_r&&WG&&!W&&write_cycle&&Bactive; cke_d=!W if !C else cke_r. Apply write-wait dispatcher below |
| SD_RD | RD,a10=A,load CL; if S1 go SD_RD_W |
| SD_RD_W | If D go SD_RD_LOOP |

| SD_RD_W2 | If WG OR ack_count==0: !A&&!K=>BT_W; otherwise if !W&&!mem_ack_r go IDLE_T |

| REFR | cs_le_d=1,ARFR,load RFC,rfr_ack_d=1. If S1 clear susp_sel and go IDLE_T |
| LMR0 | lmr_ack_d=1,PC,a10=1,bank_clr_all=1,load RP; if S1 go LMR1 |
| LMR1 | lmr_ack_d=1; if D go LMR2 |
| LMR2 | bank_clr_all=1,LMR,load RFC,lmr_ack_d=1; if S1 go IDLE_T |
| INIT0 | cs_le_d=1; go INIT |
| INIT | init_ack=1,PC,a10=1,bank_clr_all=1,load RP,IRload; if S1 go INIT_W |
| INIT_W | init_ack=1; if D go INIT_REFR1 |
| INIT_REFR1 | init_ack=1,ARFR,load RFC; if S1 assert IRdec and go INIT_REFR1_W |
| INIT_REFR1_W | init_ack=1; if D go INIT_LMR when IDone, else INIT_REFR1 |
| INIT_LMR | init_ack=1,LMR,bank_clr_all=1,load RFC; if S1 go IDLE_T |

| BG1 | mc_bg=1,cs_le_d=1,mc_c_oe_d=0; go BG2 |
| BG2 | cs_le_d=1; mc_bg=!R&&!WG&&!rfr_req&&!init_req&&!lmr_req&&!susp_req_r; load AVAV; mc_c_oe_d=mc_br; if !mc_br go IDLE_T |
| SUSP1 | PC,a10=1,bank_clr_all=1,load RP; if S1 go SUSP2 |
| SUSP2 | If D go SUSP3 |
| SUSP3 | cke_d=0,ARFR,rfr_ack_d=1; if S1 go SUSP4 |
| SUSP4 | cke_rd=0,suspended_d=1,load XSR; if resume_req_r go RESUME1 |
| RESUME1 | suspended_d=1,load XSR; go RESUME2 |
| RESUME2 | suspended_d=1; if D go REFR |

IDLE dispatcher uses strict priority:

1. rfr_req: rfr_ack_d=1, next PRECHARGE.
2. init_req: cs_le_d=1,next INIT0.
3. lmr_req&&lookup_ready2: lmr_ack_d=1,cs_le_d=1,next LMR0.
4. susp_req_r&&!cycle: cs_le_d=1,set susp_sel,next SUSP1.
5. cs_a&&(R OR WG)&&lookup_ready2: set wb_cycle, then type-specific dispatch. SDRAM requires !W; set wr_cycle for WG OR(wb_we_i&&wb_stb_i); if K&&bank_open&&row_same go SD_RD_WR, else if K&&bank_open go PRECHARGE, else ACTIVATE. ACS requires !W, sets cs_le_d, then WG=>data_oe_d=1,ACS_WR; otherwise ACS_RD. SCS requires !W, sets cs_le_d, then WG=>XWR,data_oe_d=1,load WR2,SCS_WR; otherwise XRD,oe_d=1,load RDV,SCS_RD. SRAM requires !W, sets cs_le_d, then WG=>data_oe_d=1,mem_ack_d=1,SRAM_WR; otherwise XRD,oe_d=1,mc_adsc=1,SRAM_RD. Other type values remain IDLE, but wb_cycle set still applies.
6. mc_br&&!S2: next BG0,mc_c_oe_d=0.

SD_WR_W transition dispatcher is enabled when (single_write&&cke_r) OR (!single_write&&!C&&!W) OR (!single_write&&C&&cke_r). When enabled, use priority: single_write&&!cycle=>IDLE_T; else Bactive&&!single_write&&!wb_write_go_r=>command BT and next BT; else !Bactive&&!A=>BT_W; else !Bactive=>IDLE_T; else !wb_write_go_r&&R=>IDLE_T; otherwise remain. All other row controls remain in effect even if no transition is enabled.

Invalid one-hot state values retain that state and produce the default combinational controls; the simulation diagnostic has no hardware output. Timing and bus inputs are not silently latched beyond the registers stated above. Protocol-level success depends on the surrounding data path, bank bookkeeping, memory acknowledgement and Wishbone scheduler using these strobes correctly; this isolated case specifies the sequencer's actual complete pin-level behavior without adding a full memory model. Arbitrary inputs are not constrained away. Partial byte packing applies to ACS reads only; outputs not asserted in the table remain at the stated defaults. Dynamic reset can clear some outputs immediately while unreset pipelines continue clocking; the specification does not promise all pins zero during reset.
