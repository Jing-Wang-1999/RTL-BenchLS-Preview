**Module Specification: origen_063434**

This module implements a serial interface controller compatible with SD card SPI-like communication. It manages data transfers between a host system and an external device via a serial peripheral interface (SPI).

**Primary Signals:**
- **Clock & Reset:** CLOCK provides the main timing reference. nRESET initializes internal state when low.
- **Control Inputs:** CLKEN gates clock-dependent operations. ENABLE activates the controller when high. nWR distinguishes write (low) from read (high) operations. DUMMY selects between standard and extended timing modes.
- **Data Bus:** DI (8-bit input) carries data from host to controller. DO (8-bit registered output) returns received data to host.
- **Status:** DONE indicates completion of a data transfer cycle.
- **Serial Interface:** SD_CS (chip select) is asserted when system is not in reset. SD_CLK provides serial clock. SD_MOSI outputs serial data. SD_MISO receives incoming serial data.

**Internal Registers:**
- A 5-bit counter sequences transfer operations.
- A 9-bit shift register handles serialization and deserialization.
- An 8-bit input register latches data from DI for transmission.

**Functional Behavior:**

On reset, all internal registers initialize to preset idle states (counter = 15, shift register = all 1s, DO = all 1s, DONE = 0).

When enabled with CLKEN=1 and ENABLE=1:
- The counter increments each cycle.
- If nWR is low and counter is zero, DI is latched into the input register and the shift register is loaded with {DI, 1'b1} (data plus start bit).
- Otherwise, the shift register shifts left, inserting SD_MISO at LSB.
- The most significant bit of the shift register drives SD_MOSI.
- The LSB of the counter generates the serial clock SD_CLK.

DONE asserts when:
- Counter reaches 15 and DUMMY=0 (standard timing), or
- Counter reaches 17 and DUMMY=1 (extended timing).
At assertion, the lower 8 bits of the shift register (received data) are captured into DO.

When not enabled (ENABLE=0), the counter resets to 15 and DONE deasserts.

**Key Timing:**
Transfers require 16 clock cycles in standard mode (DUMMY=0) or 18 cycles in extended mode (DUMMY=1) from counter zero to completion.

**Allowed Sub-modules:** None – this module is self-contained.
