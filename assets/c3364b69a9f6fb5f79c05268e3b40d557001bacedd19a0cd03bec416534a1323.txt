# Hazard3 instruction decode and PC sequencing

Implement `hazard3_decode` with declared defaults: RESET_VECTOR0,W_ADDR=W_DATA32,W_REGADDR5,W_ALUOP6,W_ALUSRC1,W_MEMOP5,W_BCOND2,W_EXCEPT4,W_MULOP3. A,C,M extensions and mandatory/trap machine CSRs enabled. E, optional bit manipulation, custom features, Zcmp/Zilsd, fence.i, debug, user mode and branch predictor disabled. Other parameters retain upstream defaults and do not affect this module's default logic. Decode input is **already expanded** to a32-bit instruction even when fd_cir_is_32bit=0; this module does not decompress raw16-bit opcodes.

Inputs: clk,rst_n; fd_cir[31:0],fd_cir_err[1:0],fd_cir_predbranch[1:0],fd_cir_vld[1:0],fd_cir_is_32bit,fd_cir_invalid_16bit,fd_cir_is_uop,fd_cir_uop_nonfinal,fd_cir_uop_no_pc_update,fd_cir_uop_atomic; debug_mode,m_mode,trap_wfi,debug_dpc_wdata[31:0],debug_dpc_wen,x_stall,f_jump_now,f_jump_target[31:0],x_jump_not_except,d_btb_target_addr[31:0]. Outputs: df_cir_use[1:0],df_cir_flush_behind,df_uop_stall,df_uop_clear,df_lspair_phase_next,d_pc[31:0],debug_dpc_rdata[31:0],d_starved,d_imm[31:0],d_rs1/d_rs2/d_rd[4:0],d_funct3_32b[2:0],d_funct7_32b[6:0],d_alusrc_a/b,d_aluop[5:0],d_memop[4:0],d_mulop[2:0],d_csr_ren,d_csr_wen,d_csr_wtype[1:0],d_csr_w_imm,d_branchcond[1:0],d_addr_offs[31:0],d_addr_is_regoffs,d_except[3:0],d_sleep_wfi,d_sleep_block,d_sleep_unblock,d_no_pc_increment,d_uninterruptible,d_lspair_offset[31:0],d_fence_i,d_fence_d. Unannotated ports scalar.

All decode outputs are combinational; PC and one lock bit update on rising clk with asynchronous active-low rst_n. Reset PC=0 and lock=0. Let starved=(fd_cir_vld==0) or (fd_cir_vld[0] and fd_cir_is_32bit); stall=x_stall or starved or fd_cir_uop_nonfinal. d_starved=starved,df_uop_stall=x_stall or starved,d_no_pc_increment=fd_cir_uop_nonfinal. d_uninterruptible,df_lspair_phase_next,d_lspair_offset,d_sleep_block,d_sleep_unblock,d_fence_i are0 in this configuration.

Let assert_lock=f_jump_now and x_jump_not_except and stall; finish=!stall; deassert=finish or (f_jump_now and !x_jump_not_except); combinational lock=(old_lock and !deassert) or assert_lock. At each edge old_lock takes lock. df_cir_flush_behind=assert_lock and !old_lock; df_uop_clear=f_jump_now and !df_cir_flush_behind. df_cir_use=0 when stall, otherwise2 for32-bit input or1 for16-bit. Both d_pc and debug_dpc_rdata equal PC.

PC priority each edge: debug_dpc_wen writes debug_dpc_wdata; else debug_mode holds; else if (f_jump_now and !hold_lock) or (old_lock and finish and !fd_cir_uop_no_pc_update), write f_jump_target, where hold_lock=assert_lock and !(fd_cir_is_uop and !fd_cir_uop_no_pc_update and !x_stall); else if !f_jump_now and fd_cir_uop_nonfinal and !fd_cir_uop_no_pc_update and !x_stall, write f_jump_target; else if !stall and !lock, increment PC by4 or2 according to fd_cir_is_32bit; else hold. Arithmetic wraps32 bits. Disabled feature inputs can still participate in these raw interface equations; do not tie them off.

Let I=fd_cir. Immediate forms are sign-extended RISC-V I(bits31:20),S({31:25,11:7}),B({31,7,30:25,11:8,0}),J({31,19:12,20,30:21,0}), and U={31:12,12'b0}. d_funct3_32b=I[14:12],d_funct7_32b=I[31:25] always. d_addr_offs is chosen solely from I[6:2]:11011=>J,11000=>B,01000=>S,11001 or00000=>I immediate,01011=>0; other opcodes have don't-care/unknown offset. This offset remains so even on illegal/starved decode. fd_cir_predbranch,d_btb_target_addr are ignored because prediction disabled.

Default raw decode: rs1=I[19:15],rs2=I[24:20],rd=I[11:7],imm=I immediate,ALU A source=rs1(0),B source=rs2(0),alu=ADD,mem=NONE,mul=0,CSR read/write0,type0,immediate-CSR0,branch=NEVER,register-offset0,except=NONE,sleep0,fence_d0. Each recognized instruction modifies only fields explicitly listed below. Unrecognized instructions mark invalid and otherwise keep defaults.

ALU numeric selectors hex: ADD00,SUB01,LT02,LTU04,AND06,OR07,XOR08,SRL09,SRA0a,SLL0b,MULDIV0c,RS2=0d,MAX29,MAXU2a,MIN2b,MINU2c. Source1 means PC for A, immediate for B. Memory hex selectors LW00,LH01,LB02,LHU03,LBU04,SW05,SH06,SB07,LR08,SC09,AMO0a,NONE10. Branch NEVER0,ALWAYS1,ZERO2,NZERO3. Exception NONE=f,INSTR_FAULT1,ILLEGAL2,EBREAK3,MRET=a,ECALL_M=b.

Final suppression: fault=(fd_cir_vld>0 and fd_cir_err[0]) or (fd_cir_vld>1 and fd_cir_is_32bit and fd_cir_err[1]); invalid=fd_cir_invalid_16bit or invalid decode. If fault,invalid or starved, force rs1,rs2,rd0,memNONE,branchNEVER,CSR read/write0,exceptNONE,sleep0,fence_d0,aluADD. Other raw outputs remain unchanged, including immediate,CSR type/immediate selector,mul,address mode and offset. Then except is INSTR_FAULT if fault (even if starved), else ILLEGAL if invalid and !starved, else NONE. Finally old_lock forces branchNEVER. x_stall alone does not suppress raw decode. No reset value is promised for combinational decode independent of its current inputs; only PC/lock are reset state. Unknown offset bits are intentional don't-cares, not fabricated zero requirements.
