# FP17_ADD_mgc_in_wire_wait_v1

Parameters are integer `rscid=1` and integer `width=8`. Inputs are scalar `ld`, scalar `vz`, and `z[width-1:0]`; outputs are scalar `vd`, scalar `lz`, and `d[width-1:0]`. The module is an unconditional combinational conduit: `d=z`, `lz=ld`, and `vd=vz` for every input combination. The data path is not gated by either handshake signal. `rscid` does not affect behavior. There is no clock, reset, state, latency, or submodule.
