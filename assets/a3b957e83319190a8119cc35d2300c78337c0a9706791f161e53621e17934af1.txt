# Programmable traffic-light controller (`autovcoder_128283`)

Inputs are scalar `clk`, active-high asynchronous `reset`, and unsigned 4-bit `green_time`, `yellow_time`, and `red_time`. Registered output `state[1:0]` uses parameter defaults `RED=2'b00`, `GREEN=2'b01`, and `YELLOW=2'b10`.

Reset immediately selects RED and clears the 4-bit counter. Otherwise, on each rising edge, the active state's counter increments while it is strictly less than that state's live time input. Once it is greater than or equal to the input, the state advances RED→GREEN→YELLOW→RED and the counter clears. Starting with counter zero, a stable time value N therefore keeps a state for N+1 rising edges before the transition; zero transitions on the first rising edge. Time inputs are not latched and changes take effect on the next edge. No default state branch is provided, so an illegal state holds its state and counter.
