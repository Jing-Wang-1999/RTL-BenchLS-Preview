# Module Specification: mg_10431

## Overview
This module is an 8-bit magnitude comparator with registered outputs that compares two input values on each clock edge.

## Inputs
- **INP**: 8-bit positive input value
- **INN**: 8-bit negative input value
- **CLK**: Clock signal
- **PWRDN**: Power-down control signal (unused in current implementation)

## Outputs
- **GREATER**: Registered output indicating magnitude comparison result
- **EQUAL**: Registered output indicating equality

## Behavior
On each active clock edge (configurable as rising or falling), the module:
1. Compares INP against INN
2. Sets GREATER based on comparison mode: either strictly greater-than or greater-than-
