# gf_mult_by_50

Input `i[7:0]` and output `o[7:0]` are unsigned bit vectors. This is a fixed combinational GF(2) linear transform with no parameters, clock, reset, state, latency, or submodule. For each output bit k from 0 through 7, XOR the following input-bit indices: o[0]={2,4,6,7}, o[1]={3,5,7}, o[2]={2,7}, o[3]={2,3,4,6,7}, o[4]={0,2,3,5,6}, o[5]={1,3,4,6,7}, o[6]={0,2,4,5,7}, o[7]={1,3,5,6}. Here braces denote XOR reduction, not concatenation.
