# 31-channel registered round-robin DMA arbiter

Implement `wb_dma_ch_arb` with inputs `clk`, active-low asynchronous `rst`, `req[30:0]`, `advance`, and output `gnt[4:0]`. Default 5-bit parameters `grant0` through `grant30` encode channel numbers0 through30 respectively; use these default encodings.

Reset drives `gnt` to0. At each rising clock edge, let g be the previous grant. If req[g] is1 and advance is0, retain g. Otherwise scan channels g+1 through30 followed by0 through g-1, selecting the first asserted request. If none is asserted, retain g. The current channel is omitted from the scan: advancing when only the current channel requests therefore retains it. There is no combinational grant or validity output; all changes are registered. No requests parks at the last grant. State31 is unreachable after reset; if encountered, it holds. Before reset, state is unspecified. Source `#1` annotations denote simulation settling only, not additional architectural cycles. The included DMA definitions do not affect this module's default logic.
