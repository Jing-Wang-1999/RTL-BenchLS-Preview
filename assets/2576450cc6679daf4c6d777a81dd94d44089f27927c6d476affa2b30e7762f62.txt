This module transforms a 32-bit data word based on a 4-bit byte mask. The mask is passed through unchanged from input to output.

The 4-bit mask (iSRC_MASK) corresponds to the four bytes of the 32-bit input data (iSRC_DATA), where bit 0 is the least significant byte. The module performs a specific byte reordering and zeroing operation depending on the mask value.

The output data (oDEST_DATA) is generated as follows:
*   If the mask is 0xF (all bytes active), the output is the input with its byte order fully reversed (big-endian to little-endian conversion).
*   If the mask is 0x3 (lower two bytes active), the lower two bytes of the input are swapped, placed into the lower two bytes of the output, and the upper two bytes are set to zero.
*   If the mask is 0xC (upper two bytes active), the upper two bytes of the input are swapped, placed into the upper two bytes of the output, and the lower two bytes are set to zero.
*   If the mask is 0x1 (only the least significant byte active), that byte is placed into the least significant byte of the output, and the upper three bytes are set to zero.
*   If the mask is 0x2 (only the second byte active), that byte is placed into the second byte position of the output, and all other bytes are set to zero.
*   If the mask is 0x4 (only the third byte active), that byte is placed into the third byte position of the output, and all other bytes are set to zero.
*   For any other mask value (implicitly 0x8, or only the most significant byte active), the most significant byte of the input is placed into the most significant byte of the output, and the lower three bytes are set to zero.
