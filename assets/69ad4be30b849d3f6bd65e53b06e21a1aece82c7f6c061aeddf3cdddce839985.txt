### Module Specification: Dual-Port Synchronous RAM with Independent Clock Domains

**Overview**  
This module implements a dual-port synchronous random-access memory (RAM) with two independent clock domains. Each port can independently perform read or write operations to a shared memory array. The design uses synchronous control signals and does not implement high-impedance (tri-state) outputs.

**Parameters**  
- `DW`: Data width (bits per word). Default is 32 bits.  
- `DD`: Memory depth (number of words). Default is 1024 words.  
- `AW`: Address width (bits). Default is 10 bits (addressing 1024 words).

**Inputs**  
- **Clock Signals**:  
  - `clk0`: Clock for Port 0 (positive-edge triggered).  
  - `clk1`: Clock for Port 1 (positive-edge triggered).  

- **Control Signals (Active-Low)**:  
  - `n_cs0`, `n_cs1`: Chip select for each port. The port is active when low.  
  - `n_we0`, `n_we1`: Write enable for each port. Write occurs when low; read when high.  
  - `n_oe0`, `n_oe1`: Output enable for each port (unused in this implementation; outputs are always driven).  

- **Address and Data Inputs**:  
  - `ad0[AW-1:0]`, `ad1[AW-1:0]`: Address inputs for each port.  
  - `di0[DW-1:0]`, `di1[DW-1:0]`: Data inputs for each port.

**Outputs**  
- `do0[DW-1:0]`, `do1[DW-1:0]`: Data outputs for each port. Outputs are always driven (not tri-stated).

**Functional Description**  
1. **Memory Array**:  
   - A shared RAM array of size `DD` words × `DW` bits.  
   - Both ports access the same memory locations.

2. **Port Operation (Per Clock Domain)**:  
   - Each port operates synchronously to its respective clock (`clk0` for Port 0, `clk1` for Port 1).  
   - Operations occur on the rising edge of the clock when the port is selected (`n_cs = 0`).  
   - If the port is not selected (`n_cs = 1`), the internal data register for that port retains its previous value.

3. **Read Operation**:  
   - When `n_cs = 0` and `n_we = 1` (read mode):  
     - The word at the current address is read from the RAM array.  
     - The read data is stored in an internal data register for the port.

4. **Write Operation**:  
   - When `n_cs = 0` and `n_we = 0` (write mode):  
     - The input data (`di`) is written to the RAM array at the current address.  
     - The same input data is also stored in the internal data register for the port (write-through behavior).

5. **Output Behavior**:  
   - Each port’s output (`do`) continuously reflects the value stored in its internal data register.  
   - The `n_oe` signals are ignored; outputs are never set to high-impedance.

**Concurrent Access Handling**  
- The two ports operate independently and asynchronously.  
- Simultaneous accesses to the same address from both ports are not arbitrated; such conflicts may result in undefined data in the RAM array or outputs.

**Allowed Sub-Modules**  
- None. The implementation must use only the described internal registers and combinational logic.

**Timing**  
- All operations (read/write) are synchronous to the rising edge of the respective port’s clock.  
- Outputs update asynchronously with respect to changes in the internal data registers.
