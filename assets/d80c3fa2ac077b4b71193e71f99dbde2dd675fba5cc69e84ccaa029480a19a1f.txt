# ct_f_spsram_128x104

Top parameters are `ADDR_WIDTH=7` and `WRAP_SIZE=26`; fixed ports are `A[6:0]`, active-low `CEN`, `CLK`, `D[103:0]`, active-low `GWEN`, `WEN[103:0]`, and `Q[103:0]`. Default parameter values are required by the fixed port widths. Four 26-bit RAM banks use whole-bank write enables `!CEN && !GWEN && !WEN[25]`, then WEN bits 51, 77, and 103. Other WEN bits are ignored. While CEN is low, live A addresses RAM and a rising edge saves A; while high, the saved address is used. Each bank has write-first registered output on write and otherwise registers memory data each clock. There is no reset or initialization, so held address, memory, and outputs initially are unspecified. Four `fpga_ram` submodules implement the banks.
