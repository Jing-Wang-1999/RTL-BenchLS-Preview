# `regr`
`regr` has parameter `N=1`, inputs `clk`, `clear`, `hold`, `in[N-1:0]`, and registered output `out[N-1:0]`. At each rising edge of `clk`, `clear=1` synchronously writes all zeros and has highest priority; otherwise `hold=1` retains `out`; otherwise `out` captures `in`. There is no asynchronous reset, declaration initialization, or submodule, so `out` is unknown before the first clearing or loading edge.
