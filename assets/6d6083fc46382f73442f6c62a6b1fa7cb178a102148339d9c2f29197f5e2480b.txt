**Clock Divider Specification**

This module divides an input clock frequency by 128 to generate a slower output clock. It accepts a clock input and an active-high reset signal. The output clock toggles state every 128 input clock cycles.

On reset, the output clock is set low, and the internal counter resets. During normal operation, the counter increments each clock cycle. When the counter reaches 127, it resets, and the output clock toggles. Allowed sub-modules: none.
