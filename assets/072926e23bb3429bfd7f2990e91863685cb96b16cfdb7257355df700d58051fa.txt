# gray_to_bin

`gray_to_bin` is a combinational Gray-to-binary converter with parameter `WIDTH = 8`. Input `gray` and output `bin` are each `WIDTH` bits wide.

The most significant output bit is `bin[WIDTH-1] = gray[WIDTH-1]`. For each lower position `i` from `WIDTH-2` through 0, `bin[i] = bin[i+1] ^ gray[i]`. Equivalently, each output bit is the XOR reduction of `gray[WIDTH-1:i]`. There is no clock, reset, state, latency, or submodule.
