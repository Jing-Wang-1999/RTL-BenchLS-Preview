# uart_apb_reg: default-configuration specification

Implement the module interface below. All arithmetic is fixed-width unsigned unless explicitly stated. Sequential updates use pre-edge values and occur on the stated clock edge. Preserve externally observable cycle timing, including outputs outside valid transactions wherever defined. No golden RTL is provided to the implementation model.

## Register block and reset

This is a UART register bank and interrupt/status adapter, not a serial transmitter. Rising `sys_clk`, asynchronous active-low `rst_b`. Reset clears divisor bytes, transmit and receive bytes, interrupt-enable nibble, LCR and DLAB, receiver flags and sampled busy. It sets transmitter-holding empty to1 and interrupt identification to1 (no interrupt). All state is reset.

APB access is selected only when `psel && penable`; `pwrite` selects write versus read. Address decoding uses only `paddr[7:2]`; all other address bits and write-data bits31:8 are ignored. Read data is combinational with high24 bits zero; low8 bits are unknown/don't-care outside an active read. There is no ready/error output.

| Word address / byte offset | Read | Write |
|---|---|---|
| 0 / 00 | DLL when DLAB, otherwise received byte | DLL when DLAB and sampled busy=0; otherwise THR only when DLAB=0 |
| 1 / 04 | DLH when DLAB, otherwise low3 IER bits zero extended | DLH when DLAB and sampled busy=0; otherwise low4 IER bits when DLAB=0 |
| 2 / 08 | Low4 interrupt ID | Ignored |
| 3 / 0C | `{DLAB,00,LCR[4:0]}` | DLAB=data7, LCR=data4:0, regardless of busy |
| 5 / 14 | `{0,TEMT,THRE,0,FE,PE,OE,DR}` | Ignored |
| 31 / 7C | Sampled busy in bit0 | Ignored |
| Other | Zero | Ignored |

Parameters RBR/THR/DLL=0, DLH/IER=1, IIR=2, LCR=3, LSR=5, USR=31 are used at defaults. `reg_ctrl_dllh_data={DLH,DLL}`, `reg_ctrl_ier_enable=IER[2:0]`, LCR outputs DLS=bits1:0, stop=2, parity enable=3, even parity select=4. `reg_ctrl_lcr_wen` is the combinational LCR write qualification; `reg_ctrl_set_dllh_vld` is either accepted divisor write. `reg_ctrl_threint_en` pulses combinationally on an IER write with incoming bit1 set; it is not a stored enable.

## Data/status priorities

An accepted THR write stores the byte and clears THRE even if `ctrl_reg_thr_read` is simultaneously high. Otherwise that read input sets THRE. `reg_ctrl_thr_vld=!THRE`, and `reg_ctrl_thr_data=THR`. TEMT is live `ctrl_reg_thsr_empty && THRE`.

`ctrl_reg_rbr_write_en` always captures receive data, even when receiver flags prevent marking it valid. DR is set on this write when the *old* PE and FE are clear; otherwise an active non-DLAB RBR read clears DR. A qualifying write has priority over simultaneous read. `reg_ctrl_rbr_vld=DR`. FE, PE and OE are separate sticky flags set by their respective `ctrl_reg_*` inputs, with setting taking priority over LSR-read clear. `ctrl_reg_busy` is sampled into a single busy register each edge; divisor write gating uses its previous value.

## Interrupt priority and acknowledgement

An incoming ID is accepted only if `ctrl_reg_iid_vld` and the priority condition below. Accepted write wins over simultaneous clear. Current ID1 or7 accepts any incoming ID. Current ID2 accepts when incoming bit2=1 and bit0=0. Current ID4 accepts when incoming bits2:0=6. Current ID6 and all other codes reject incoming IDs. Accepted value contains all4 input bits.

Without an accepted ID, clear to1 under these conditions: current2 and either THRE=0 or IIR read; current4 and RBR read outside DLAB; current6 and LSR read; current7 and USR read. Other IDs hold. `uart_vic_int` is high exactly for current IDs2,4,6. The interrupt priority is implemented here; generating the incoming IDs is the upstream controller's responsibility.
