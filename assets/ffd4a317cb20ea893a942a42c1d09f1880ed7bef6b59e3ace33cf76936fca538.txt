**Module Specification: Coin-Operated Purchase Controller**

**Overview**  
This module is a finite state machine (FSM) that controls a coin-operated purchase system. It manages transaction states based on coin value, user actions, and cancellation signals, producing control outputs for operation start, indicator lights, and status flags.

**Inputs**  
- **clk**: System clock; state transitions occur on the rising edge.  
- **reset**: Asynchronous reset; when asserted, the FSM returns to the idle state and all outputs are cleared.  
- **cancle_flag**: Cancellation signal; when asserted, the FSM returns to the idle state from any active state.  
- **coin_val[9:0]**: 10-bit unsigned value representing the inserted coin amount.  
- **get_ind**: “Get item” indication; when asserted in an active purchase state, the transaction completes and the FSM returns to idle.  
- **buy_flag**: Purchase request signal; initiates a transaction when asserted in the idle state.

**Outputs** (all synchronous, registered)  
- **op_start**: Operation start signal; asserted when a transaction is active (states S1, S2, S3).  
- **light**: Main activity light; asserted when the system is in any active transaction state.  
- **light_one**: First auxiliary indicator; asserted in states S2 and S3.  
- **light_two**: Second auxiliary indicator; asserted only in state S3.  
- **hold_ind**: Hold indication; asserted when the system is in an active transaction state (S1, S2, S3).  
- **not_enough**: Insufficient funds flag; asserted only in state S1 (coin value below threshold with buy request).

**Behavior**  
The FSM has four states:  
- **S0 (Idle)**: All outputs are low. Waits for a buy_flag.  
  - If cancle_flag is asserted, remains in S0.  
  - If buy_flag is asserted:  
    - If coin_val ≥ 100, transition to S3 (sufficient funds).  
    - If coin_val < 100, transition to S2 (insufficient funds).  
- **S1 (Insufficient funds, no buy)**: This state is not directly reachable from the given RTL; the design logic implies S2 handles insufficient funds with buy_flag.  
- **S2 (Active – insufficient funds)**:  
  - op_start, light, light_one, and hold_ind are asserted.  
  - not_enough is deasserted.  
  - If cancle_flag asserted, return to S0.  
  - If get_ind asserted, return to S0.  
  - Otherwise, remain in S2.
