# Flip-flop modules

`origen_087979` has scalar inputs `clock`, `data`, active-low asynchronous `preset`, and active-low asynchronous `reset`, with registered output `Q`. A falling `preset` sets `Q` to one. Otherwise a falling `reset` clears it to zero. On a rising clock edge with both controls inactive, `Q` captures `data`. If preset and reset are asserted together, preset has priority.

`lab_TFF` has the same clock, preset, reset, output, and priority. On a rising clock edge, input `t=1` toggles `Q`, while `t=0` holds it.

`lab_JKFF` has scalar inputs `clock`, `J`, `K`, preset, and reset, with the same asynchronous priority. On a rising clock edge it holds for `J,K=00`, clears for `01`, sets for `10`, and toggles for `11`. None of the modules defines a power-up value before a preset, reset, or qualifying clock edge.
