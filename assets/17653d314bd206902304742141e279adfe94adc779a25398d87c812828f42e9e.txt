# `FP17_ADD_leading_sign_23_0`

Combinational ports are `mantissa[22:0]` and `rtn[4:0]`. `rtn` is the unsigned count of zero bits preceding the most significant 1 in `mantissa`: it is 0 when bit 22 is 1, 1 when bit 22 is 0 and bit 21 is 1, continuing through 22 when only bit 0 is the first 1; all-zero input produces 23. No clock, reset, state, or submodule is used.
