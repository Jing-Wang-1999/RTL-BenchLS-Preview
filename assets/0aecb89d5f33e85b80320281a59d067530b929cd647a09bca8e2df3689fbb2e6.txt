This specification describes three digital flip-flop modules: origen_087979, lab_TFF, and lab_JKFF. Each module is designed to store and manipulate binary data based on clock signals and control inputs.

1. **origen_087979 Module**: 
   - **Inputs**: 
     - `clock`: A signal that triggers data storage on its rising edge.
     - `data`: The binary input to be stored.
     - `preset`: An active-low signal that sets the output to 1.
     - `reset`: An active-low signal that clears the output to 0.
   - **Output**: 
     - `Q`: A register that holds the stored data.
   - **Behavior**: On the rising edge of the clock, if `preset` is low, `Q` is set to 1. If `reset` is low, `Q` is set to 0. Otherwise, `Q` follows the `data` input.

2. **lab_TFF Module**: 
   - **Inputs**: 
     - `clock`: A signal that triggers toggling on its rising edge.
     - `t`: A toggle control input.
     - `preset`: An active-low signal that sets the output to 1.
     - `reset`: An active-low signal that clears the output to 0.
