# AXI-Lite register-interface project
Implement every file and module in output_contract.json. Read the unchanged original README and declaration-only interfaces. Only the selected independent design and its complete RTL closure are requested; unrelated repository components and FPGA board designs are separate designs. Rising clk edges and synchronous active-high rst apply throughout. Assert reset initially for several clocks. Transfer ready/valid signals only on a rising edge with both asserted; preserve data while stalled. Internal state encoding and buffering may differ, but externally visible data, completion and error semantics must match. Private scoring uses one complete usable upstream testbench per point; vectors inside a bench are not additional points. The original source is withheld. Curator clarifications below supplement the original documents and take precedence where explicitly correcting ambiguity.

Implement axil_reg_if integrating axil_reg_if_rd and axil_reg_if_wr. This is a complete adapter from AXI-Lite to the simpler downstream register read/write interfaces documented in the README. The external register bank is an endpoint, not missing required RTL.

- Capture AW and W independently; assert reg_wr_en only after both are present and no preceding B response blocks issue. Present their unmodified byte address, data and byte strobes on reg_wr_*. Hold the register request until ack or timeout, then generate one B response. A read captures AR and asserts reg_rd_en with its address; on ack or timeout, capture reg_rd_data and emit a stable R response.
- reg_*_wait pauses timeout countdown; it does not override an asserted ack. Timeout is a finite fallback for an unacknowledged register address. Reload the timer to TIMEOUT-1, decrement on enabled non-waiting cycles while nonzero, and complete an already-enabled request when ack is high or the counter is zero. Default TIMEOUT=4. On timeout the read still samples reg_rd_data; it does not manufacture a zero value.
- Both AXI response codes are always OKAY, including timeout. This is a curator clarification of the pinned RTL, not an implied AXI error on timeout. AWPROT/ARPROT are ignored because the simple register interface has no protection ports. Reg read and write channels proceed independently; ready/valid outputs tolerate backpressure. Reset clears pending/response-valid and reg enable state synchronously.
- The complete original cocotb integration bench is the one usable testpoint. It covers the register interface through its Python endpoint; no additional native submodule benches exist. Multiple internal read/write transactions are not separate points.
