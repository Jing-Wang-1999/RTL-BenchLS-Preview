# Oversampled 8-bit UART receiver

Implement `sirv_uartrx` with scalar inputs `clock`, `reset`, `io_en`, `io_in`; input `io_div[15:0]`; scalar output `io_out_valid`; output `io_out_bits[7:0]`. All state changes on rising clock edges; reset is active-high asynchronous and clears every functional register to0. No parity/error/ready output is present. The output byte is the receive shift register even when valid is0.

Use three states IDLE0, START1 and DATA2. At every edge use previous register values. A2-bit debounce count in IDLE increments modulo4 while io_in is low and decrements toward0 while high. io_en=0 clears this count; it does not abort or directly inhibit the FSM or sampling. In IDLE, low input with old debounce3 starts reception, enters START and loads a5-bit timer with8. Consequently deasserting io_en at that exact edge still permits a start; continuous disable subsequently prevents new debounced starts.

A12-bit prescaler reloads from io_div[15:4] on a start or sampling pulse. A pulse occurs when prescaler=0 and state is START or DATA. Otherwise it decrements modulo4096 when busy and holds when idle. The low4 divider bits are ignored; changing the divider affects the next reload. On each pulse a3-bit sample history shifts left and inserts io_in at bit0. The decision bit is the majority of the three OLD samples. A timer-expiry event requires pulse and old timer0. Timer decrements modulo32 on pulses unless reloaded below. START expiry always reloads timer15; a low majority enters DATA and loads a4-bit bit counter8, while high majority returns IDLE.

Each DATA expiry decrements the bit counter modulo16. If its old value is nonzero, shift the majority bit into bit7 of the byte while bits7:1 move down, keep DATA and reload timer15. This assembles the eight data bits LSB first. When old counter0 expires, retain the byte, return IDLE, and assert io_out_valid for exactly that next clock interval; timer decrements to31. The sampled stop interval is not checked for a high level. Valid clears on every other edge. No new frame is accepted while busy. All state/register holds and modulo effects above remain defined for arbitrary binary inputs; no stable-divider or valid-stop assumption is required.
