# One-shot variable-width pulse (`origen_098224`)

Inputs are scalar `clk`, active-low asynchronous `rst_n`, `wrt`, and unsigned `SPEED[10:0]`; output `PWM` is registered. There are no parameters.

Reset immediately clears synchronized SPEED/wrt, the 14-bit down-counter, and PWM. Every rising edge registers SPEED and wrt. When the pre-edge registered wrt is high, the counter loads `3*SPEED_ff + 14'h186A` (all possible values fit 14 bits) and PWM sets high; therefore an input wrt pulse takes effect one clock later using the SPEED sampled with it. With no registered write, a nonzero counter decrements. PWM clears on an edge whose pre-edge counter is zero and otherwise holds. Consequently, after loading N, PWM stays high while the counter counts down and clears one edge after the counter first becomes zero. Another registered write has priority and reloads/reasserts the pulse.
