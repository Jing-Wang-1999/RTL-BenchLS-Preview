# SDRAM host-side request and data controller

Implement `hostcont` with the declaration below. Qualify only the upstream default configuration with align_data_bus disabled and independent32-bit read/write buses. Constants are HI=1, LO=0 and default mode-register value0x020 (CAS latency2, sequential single-word burst). No optional alignment path is included. Use rising sys_clk and asynchronous active-low sys_rst_l.

This is the host-side sub-block: external inputs do_read_ack/do_write_ack/do_modeset_ack acknowledge requests from a separate SDRAM command sequencer. It does not itself emit RAS/CAS commands or generate refresh timing.

## Address and data paths

`reg_mp_addx` continuously equals mp_addx. `sd_data_out` continuously equals mp_data_in; there is no write-data queue or address latch in this configuration. `reg_mp_data_mux` is0 when mp_data_mux is1, otherwise mp_data_in. The32-bit `reg_sd_data` captures sd_data_in on each sd_rd_ena edge and asynchronously resets to0; mp_data_out continuously equals reg_sd_data.

The11-bit `reg_modeset` asynchronously resets0. Each non-reset edge first honors pwrup, loading0x020. Otherwise if sdram_mode_set_l=0, mp_cs_l=0 and mp_wr_l=0, capture mp_data_in[10:0], irrespective of sequencer state; otherwise hold. modereg_cas_latency is bits6:4 and modereg_burst_length is bits2:0.

Combinational SDRAM address:

| Selector | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
|sd_addx10_mux -> sd_addx[10]|mp_addx[20]|0|reg_modeset[10]|1|
|sd_addx_mux -> sd_addx[9:0]|mp_addx[19:10]|{2'b0,mp_addx[9:2]}|reg_modeset[9:0]|0|
|sd_addx_mux -> sd_ba|mp_addx[22:21]|mp_addx[22:21]|0|0|

`decoded_dqm` uses mp_size and current low address bits: size0 ->0000 (32-bit); size2 ->1100 for address[1]=0 else0011 (16-bit); size1 ->1110/1101/1011/0111 for address[1:0]=0/1/2/3 (8-bit). Size3 is explicitly unspecified in the source (four X bits), not a promised deterministic mask. The formal harness must retain and disclose the tool's X interpretation; no additional assumptions restricting mp_size are authorized by this specification.

## Request state machine

Maintain states IDLE=0, DELAY=1, READ_WAIT=2, WRITE_WAIT=3, READ_RELEASE=4, WRITE_RELEASE=5, MODE_WAIT=6; a busy-enable B; and request outputs do_read/do_write/do_modeset. Asynchronous reset clears requests, selects IDLE and sets B=1. On non-reset edges retain registers unless these rules update them:

- IDLE accepts in priority order: mp_rd_l=0 and mp_cs_l=0 sets do_read; else mp_wr_l=0 and mp_cs_l=0 and sdram_mode_set_l=1 sets do_write; else the same write/select with sdram_mode_set_l=0 sets do_modeset. Any acceptance enters DELAY. Otherwise remain IDLE.
- DELAY clears B. Choose WRITE_WAIT if old do_write, else READ_WAIT if old do_read, else MODE_WAIT if old do_modeset; if none remains DELAY. Acknowledgements in DELAY do not clear requests.
- READ_WAIT holds until do_read_ack, then clears do_read and enters READ_RELEASE.
- WRITE_WAIT holds until do_write_ack, then clears do_write and enters WRITE_RELEASE.
- MODE_WAIT holds until do_modeset_ack, then clears do_modeset and enters WRITE_RELEASE.
- READ_RELEASE holds until mp_rd_l=1, then sets B=1 and enters IDLE.
- WRITE_RELEASE holds until mp_wr_l=1, then sets B=1 and enters IDLE.

The active-low busy output is the inverse of: do_read OR (NOT mp_rd_l AND B) OR do_write OR (NOT mp_wr_l AND B) OR (doing_refresh AND NOT mp_cs_l) OR (do_modeset AND NOT mp_cs_l). The raw read/write contributions involving B are **not gated by chip select**. Reset sets B but does not force busy_l high independently of inputs. Read has priority over a simultaneous write/mode request. A held-low request cannot be accepted again until the release state has observed its deassertion.

Host software/controller must hold address, data and controls for its transaction while busy is asserted because this default design passes them through. This usage description does not add input assumptions to equivalence checking. Outputs and FSM response for arbitrary control combinations are as defined above.

## Public declaration

```verilog
module hostcont (
                    sys_rst_l,
                    sys_clk,
                    mp_addx,
                    mp_data_in,
                    mp_data_out,
                    mp_rd_l,
                    mp_wr_l,
                    mp_cs_l,
                    sdram_mode_set_l,
                    sdram_busy_l,
                    mp_size,
                    sd_addx,
                    sd_data_out,
                    sd_data_in,
                    sd_ba,
                    sd_addx10_mux,
                    sd_addx_mux,
                    sd_rd_ena,
                    do_read,
                    do_write,
                    doing_refresh,
                    do_modeset,
                    modereg_cas_latency,
                    modereg_burst_length,
                    mp_data_mux,
                    decoded_dqm,
                    do_write_ack,
                    do_read_ack,
                    do_modeset_ack,
                    pwrup,
                    reg_mp_data_mux,
                    reg_mp_addx,
                    reg_sd_data,
                    reg_modeset
             );
input           sys_rst_l;
input           sys_clk;
input   [22:0]  mp_addx;
input   [31:0]  mp_data_in;
output  [31:0]  mp_data_out;
input           mp_rd_l;
input           mp_wr_l;
input           mp_cs_l;
input           sdram_mode_set_l;
output          sdram_busy_l;
input   [1:0]   mp_size;
output  [10:0]  sd_addx;
input   [31:0]  sd_data_in;
output  [31:0]  sd_data_out;
output  [1:0]   sd_ba;
input           pwrup;
input   [1:0]   sd_addx10_mux;
input   [1:0]   sd_addx_mux;
input           sd_rd_ena;
output          do_write;
output          do_read;
input           doing_refresh;
output          do_modeset;
output  [2:0]   modereg_cas_latency;
output  [2:0]   modereg_burst_length;
input           mp_data_mux;
output  [3:0]   decoded_dqm;
input           do_write_ack;
input           do_read_ack;
input           do_modeset_ack;
output  [31:0]  reg_mp_data_mux;
output  [22:0]  reg_mp_addx;
output  [31:0]  reg_sd_data;
output  [10:0]  reg_modeset;
```
