# Specification

The queued top `origen_071564` has input `clk`, `data_in[63:0]`, and registered output `data_out[63:0]`. `data_out` initializes to zero and captures `data_in` on every rising edge. The same source also defines independent tops `id_ex` (178 bits), `ex_mem` (155 bits), and `mem_wb` (117 bits), each with the same initial-zero and positive-edge capture behavior. There is no reset or enable.
