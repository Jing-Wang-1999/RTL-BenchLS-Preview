# gf_mult_by_57

Input `i[7:0]` and output `o[7:0]` are unsigned bit vectors. This is a fixed combinational GF(2) linear transform with no parameters, clock, reset, state, latency, or submodule. For each output bit k from 0 through 7, XOR the following input-bit indices: o[0]={0,2,4}, o[1]={0,1,3,5}, o[2]={0,1,6}, o[3]={1,4,7}, o[4]={0,4,5}, o[5]={1,5,6}, o[6]={0,2,6,7}, o[7]={1,3,7}. Here braces denote XOR reduction, not concatenation.
